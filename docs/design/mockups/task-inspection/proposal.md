# 任务检查与依赖浏览

本原型保留依赖检查和详情阅读的视觉及交互基线，数据采用引入外部依赖分类前的示例。当前普通分量和显式边性质见[外部依赖原型](../external-dependencies/index.html)，完整检查机制由[检查设计](../../daynight-task-inspection.md)定义。任务链点击打开图浮层的当前入口与尺寸由[Web 设计](../../daynight-web.md#项目详情-projectsprojectid)拥有，本原型保留此前的页面入口基线。示例包含完整小图及具有分支、共享前置、外部上下文的大图；待审批单独统计，可开始与被阻塞只统计待处理任务。

## 渐进展示

完整任务图同时不超过 50 个任务和 100 条依赖时全部显示。更大的图从示例所选入口出发，以稳定广度优先顺序选择概览：每个任务先访问直接后续，再访问直接前置；概览最多保留 50 个任务及 100 条真实依赖。

链内任务与外部前置采用相同的折叠规则。卡片上的“展开前置”和“展开后续”只补充当前未显示的直接相邻任务，每次最多新增 20 个。按钮显示本次将新增的准确任务数与依赖数；只有显式展开能够超过概览限制。“收起到概览”恢复当前概览并让画布适应概览范围。

所有连线都对应真实的直接依赖。图中不创建聚合任务或替代依赖路径。完整任务链的进度与统计不随可见任务变化，外部前置不计入链内进度。

## 依赖高亮

点击任务卡片计算全部传递上游，仅高亮已显示的上游与沿途连线，并提示去重后的未显示上游数量。再次点击同一卡片或点击画布空白处清除。选择和打开详情均不展开任务、不改变节点位置、连线路径及画布视口。

依赖连接线保留节点布局，以前置右侧中心和后续左侧中心为端口。不同高度的 rank 间通道由完整三次贝塞尔曲线连接，两个控制点位于列间中线及起止高度，出入切向水平向右；穿过中间列时使用距卡片至少16单位的水平自由通道。同高段保持直线，保留前置到后续的箭头方向、外部依赖5/4虚线和检查高亮。

## 居中详情

独立的详情入口打开居中浮层。描述使用 Markdown，附件链接按当前任务附件根目录解析。详情中的关系导航只替换浮层内容；关闭时恢复原详情入口焦点与原画布状态。

## 验收

- 小图完整显示，大图初始概览同时满足 50 个任务及 100 条真实依赖限制。
- 链内与外部任务均能通过独立按钮分批展开直接前置及后续，按钮计数与实际新增量一致。
- 分支、共享前置、跨链前置和已完成前置按完整依赖关系计算高亮，未显示上游数量去重。
- 选择、打开详情及详情内关系导航保持可见集合、节点几何和画布视口。
- 收起到概览恢复初始可见集合，完整链进度保持不变。
- 键盘能够独立选择、展开任务、查看详情、访问关系和附件。
- 附件在详情浮层内预览；任务详情和全屏图按 Escape 逐层关闭。
- 320px 下正文不溢出，表格与代码块在自身区域滚动。
