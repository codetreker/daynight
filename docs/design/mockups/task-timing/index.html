Each project keeps its own saved threshold; drafts do not affect warnings. Card body selects inspection; the independent Details control opens exact timestamps.

默认 60 分钟。任务耗时等于阈值时不提醒；超过阈值后提醒。保存后应用到当前项目允许 Agent 的进行中任务。

Preview controls · Simulated lifecycle

The running fixture starts at 45 minutes. The public lifecycle only advances proposed → todo → in_progress → done. Reset and threshold buttons load independent preview fixtures; they are not public task transitions. At equality auto time pauses; advance 1 second to cross the boundary. Same-transition attempts are rejected; title edits preserve timestamps.
