# 完成时间展示设计

[完成时间规格](../spec/daynight-completion-time.md)定义任务、任务链与 Goal 的完成事实、文案和访问要求。Web 使用共享时钟展示 Task、任务链和 Goal 的完成时间，详情提供精确值。Goal 显示自身的完成事实，不以子任务时间代替 Goal 自身时间；子任务开始时的状态联动遵守 [Goal 需求](../spec/daynight-goals.md)。

## 完成事实与时间读取

`features/task-completion/` 拥有完成事实、显示分段和提示交互。`completedAtFor` 只在当前状态为 `done` 且真实 `completedAt` 已知时返回该值，不依赖 `startedAt`。`latestScopedCompletion` 对非空成员集合要求每个 ID 存在于图索引、全部为 `done` 且完成时间已知，再以纳秒精度选择最晚原始时间。未完成或未知时间返回 `null`，缺失成员 ID 是装配错误。完整链使用完整分量成员，范围链使用该行统计的范围成员，筛选、分页和外部前置不改变聚合范围。代表 Task 的自身时间与链汇总时间分别计算。

`timestampNanoseconds` 由 `src/time/timestamp.ts` 共享。完成时间按不足一分钟、分钟、小时、天和七天后的本地日期分段，向下取整；短暂负差显示为零但不改变事实。绝对列表值精确到分钟，同一本地年份省略年份，跨年包含年份。中英文使用各自格式；详情和提示使用包含年份与秒的本地时间。

`useCompletionTime` 消费项目共享 `TaskExecutionClockProvider`，缓存分段语义，只在读取结果变化时更新。在线参考来自快照的 `observedAt` 加接收后的单调时间差；缓存预览使用本机时间锚点，在线样本到达后切换。空快照不制造时间样本。完成距今与运行中执行耗时共享可见页面的一个定时器，但完成执行耗时仍从持久起止端点计算并冻结。时钟、可见性与 Provider 生命周期由[执行计时设计](daynight-task-timing.md)拥有。

## 列表与详情

`StandaloneTaskRow`、`TaskMemberRow` 和 `GoalItem` 以非交互 `time` 显示各自完成时间，与执行耗时并列。项目 Goal 展开区为全部直接成员复用 `TaskMemberRow`，详情不重复列出 Task。标签不参与按钮名称或增加焦点停靠点；唯一的精确时间 description 与既有执行耗时 description 并存。Task 行的详情入口承担键盘提示；Goal 行的独立详情按钮承担键盘提示，展开按钮包含时间标签，提示 DOM 位于该按钮之外且不触发展开。Task 和 Goal 详情在已完成且时间已知时直接显示完整“完成时间”字段，即使时钟样本尚不可用也能读取。`GoalDetailSurface` 从 `completedAtFor(detail)` 读取 Goal 自身事实，在公共元信息行显示精确本地时间；它与描述侧栏的创建／修改时间和子任务进度独立，三个阅读页签均可查看。

`ChainList` 和 `ScopedTaskChainRow` 使用各自完整的统计成员计算汇总。链摘要以非交互容器组织标题和次要信息，链时间按钮放在标题下方，与负责人或子任务数及 Worker 信息并列；进度、状态和图入口保留各自的职责。原生展开按钮与时间按钮是独立控件，展开入口保留 ID、展开状态、控制关系及焦点恢复。时间按钮名称为本地化的“查看 {title} 的完成时间”；相对时间不参与名称。展开后的代表详情入口另用代表 Task 自身事实。点击时间按钮不展开、选择任务或打开图。

行的完成标签支持鼠标悬停，Task 行及 Goal 独立详情按钮获得焦点时支持键盘访问；触屏用户可从详情入口读取 Task 或 Goal 精确时间。链汇总没有独立详情，因而提供同级时间按钮供鼠标、键盘和触屏使用。悬停或聚焦显示提示；链时间按钮点击或触屏激活可固定提示，再次激活、焦点离开或外部 pointerdown 关闭，外部操作仍正常执行。鼠标可从标签移到提示上阅读。blur、来源失效或导航清理原提示。

提示属于行或弹窗的 DOM 子树，以手动原生 popover 脱离裁剪，并以 `role="tooltip"` 提供描述；它不转移焦点、不包含交互子控件，也不注册 modal。打开时根据触发器及所属可见区域定位，监听滚动、视口和尺寸变化并合并同帧更新。鼠标提示保持靠近时间标签，便于移入阅读；链时间的触屏固定提示向上放置时避开链摘要，以免遮挡展开入口。关闭或卸载释放监听、观察器与待执行帧。活动 owner 内的 Escape 先关闭提示，避免同次事件关闭外层；Tab 正常离开。进入其他 owner 或背景变为 inert 时清理旧提示。语言、事实或相对文案变化更新内容而不重挂触发器；已固定提示跨时间推进保持打开，来源不再满足显示条件时关闭。提示不使用 live region。

完成时间与执行耗时分别表示何时完成及执行用了多久，不能互相代替。320px 下次要信息和链时间控件自然换行，保留标题和原操作空间；不因展示改变排序、筛选、分页或写入。

## 验证职责

纯模型测试负责状态、未知值、成员范围、纳秒比较和时间分段边界；时钟与 hook 测试负责共享调度、样本切换、可见性和资源释放。组件和浏览器 fixture 验证真实消费者的来源、描述组合、节点和操作身份、鼠标/键盘/触屏、窄屏及时间推进中的状态保持。真实产品流程验证服务事实传播；受控 fixture 或原型不能代替它。Goal 的完成事实和子任务进度分别验证；项目 Goal 展开区的子任务时间使用各成员自身事实；链汇总只聚合该链行的实际范围。Goal 详情的精确完成时间以自身状态和字段验证，不通过已移除的详情 Task 列表或链头验证。
