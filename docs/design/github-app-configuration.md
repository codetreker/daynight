# GitHub App 配置与删除

App 配置更新和删除使用独立 App 根事务。当前 App 管理员必须提交原配置版本；原权限和版本先于同值判断。名称保持原文，秘密省略表示保留，秘密不进入公开元数据。私钥或 Webhook secret 实际变化时，服务先在事务外以拟保存的完整凭据证明 GitHub App 身份，并记住管理员关系版本；提交时重新核对该关系和原配置版本。移除后重新加入的管理员不能提交旧证明。

秘密实际变化推进 App credentialVersion 和所有相关连接的 generation，清除旧领取与提示，保留连接和同步意愿，并为启用同步的连接安排访问核对。App 根锁保护配置和影响集合；连接按项目 ID 顺序锁定，包含操作者不可见的项目。仅名称变化不调用 GitHub，同值保留配置版本。

删除要求配置版本和影响版本均匹配，在同一事务中移除管理员和邀请、撤销授权、解除所有连接并关闭同步。PR 和非秘密 App 身份墓碑保留，私钥和 secret 被擦除，本地 App UUID 与已撤销的授权 UUID 不可复用。影响预览的可见明细仍由原有项目权限过滤；隐藏项目参与完整清理和 fence。成功返回有限回执，未知事务结果不得自动重放。

配置和删除 adapter 随[独立 App 登记](github-app-registration.md)组件由生产 mux 提供。45 秒预算覆盖凭据更新的请求体、远端证明和提交；请求体读取上限为 15 秒；本地名称更新与删除的总预算也是 15 秒。
