# Web 单序列柱状图设计

## 调用契约

有序的非负整数序列使用公共 [`BarChart`](../../packages/daynight-web/src/ui/bar-chart/index.tsx)。调用方提供图表的可访问名称，以及按展示顺序排列的非空 `points`。每项包含稳定且唯一的 `key`、完整的 `label` 和 `bigint` 类型的 `value`；可选的 `axisLabel` 只用于横轴展示，缺省时使用完整标签。图表不改变点的顺序，也不负责读取、筛选或聚合数据。空数据、加载和错误由调用方呈现。

`domainMax` 是调用方提供的非负整数上界，不能小于任一点的值。在同一统计范围内比较筛选结果时，调用方保持上界稳定，使相同数值对应相同柱高；[项目每日统计](daynight-web.md#项目每日统计)以对应范围的未筛选最大值为上界。图表拒绝空序列、重复键及越界值。全零序列有效，并保留可交互的零值标记。计算柱高时先以整数求比例，再将有界比例转换为显示数值，避免先转换原始计数损失精度。调用方的 `formatValue` 统一格式化纵轴最大值、零值和逐点读数，可使用当前应用语言。

## 读数与交互

图表使用有名称的横向 `listbox`，每柱是一个选项，可访问名称包含完整标签及格式化后的值。整个绘图区只有一个 Tab 停靠点；Tab 和 Shift+Tab 进入或离开图表，方向键按序切换且不循环，Home 和 End 到首尾。键盘聚焦或切换到不可见的选项时，只滚动图表内部以显示该项。

悬停显示指针下的完整读数，但不改变选择；指针离开后恢复选中项读数。点击或轻触选中该项并聚焦绘图区。读数区域以 `aria-live="polite"` 通报变化。数据更新后若选中键仍存在则保留该项，否则回到首项；只更新计数或悬停不会主动移动滚动位置。

## 轴标签与验证

横轴显示最多五个按序分布的标签，首尾对齐绘图区两端，中间标签居中于对应的柱；只有一项时标签左对齐。标签预留互不重叠的展示宽度，过长时省略；滚动后只显示完全落在可见范围内的标签。标签行预留一个实际行高及顶部间距，避免放大文字后发生纵向裁切。窄屏或粗指针环境下，柱列保留最小宽度；容纳不下时，柱和横轴共享局部横向滚动，纵轴保持在绘图区之外，页面不横向溢出。

[浏览器用例](../../packages/daynight-web/tests/navigation/bar-chart.browser.ts)验证桌面及 320px 宽度下的标签几何、放大、滚动和触控读数，也覆盖键盘顺序、筛选后稳定的轴上界和选择、大整数及全零序列。
