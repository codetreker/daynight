# 助手共享会话视图

## 范围与身份

本页定义助手会话所需的呈现与行为，不以规格存在表示界面已经交付。助手视图复用[共享 Session View](task-sessions.md) 的 `conversation` 默认模式、显示偏好、原生交互、资源和全屏能力。接入使用已认证 Bot 管理结果中的 `ownerUserId`、`botId`、真实 `sessionId` 和 `testExecutionId`；不伪造 Task、claim 或独立执行身份。独立 Session 返回的账号、会话和执行必须与绑定一致；不匹配响应不得准入该执行。HTTP 协议解析失败显示错误并阻止远端提交，已确认的身份或权限失效按清理规则处理。只读显示快照遵守下文的账号确认与隔离要求，不作为实时接入或操作身份。

本模块提供 Session 绑定容器与页面缓存，供助手列表、详情和删除页面组合。列表、创建表单、删除服务、Worker 托管和正式入口由各自模块负责；组件可用不等于完整助手产品已启用。

## 呈现范围与阅读列

助手页使用显式选择的独立呈现样式。未选择助手样式的普通 Task、Test 与独立历史阅读入口保持既有外观和行为；助手内转入只读归档可保留助手样式，但不能恢复任何写入能力。呈现只改变布局，不新增 Session 客户端、执行身份、操作或 Provider 能力。助手工作区、列表、统一标题与详情布局由[助手管理页规格](bot-management-web.md)定义。

正文与输入框共享居中的阅读列，最大宽度均为 760 CSS px，左右边界对齐。可用空间不足时随实际会话容器收缩，不以窗口宽度替代容器宽度；打开详情、改变全局导航或进入专注模式后仍遵守相同上限。窄屏左右约 18px 留白，不为头像保留独立空列。长内容不得撑宽页面，输入和发送不依赖滚动到消息末尾。

正文使用系统字体栈，覆盖 PingFang SC、Segoe UI；常规字号 16px，紧凑及窄屏为 14–15px，中文行高 1.8。回复首句的视觉强调为约 17px、字重 600，不能为了强调而拆散 Markdown 结构或改变正文。背景为近白冷中性色，正文深灰；Daynight 紫色用于主操作、选中态和必要品牌标记。颜色不能成为错误、审批或操作状态的唯一表达。

| 内容 | 所需呈现与边界 |
| --- | --- |
| 用户消息 | 靠右、按内容宽度展开的浅紫气泡，长文本在阅读列内换行，保留原始内容与顺序。 |
| 助手回复 | 长回复直接排版，不套满宽卡片；段落、列表、引用、标题和链接保留安全 Markdown 语义。任务链接仍为普通链接，不从示例排版新增任务状态卡或业务读取。 |
| 代码与工具文本 | 代码保留缩进和换行，过宽内容在自身区域滚动；普通工具日志仍按原文显示，不改作 Markdown，不丢失截断或大小限制提示。 |
| 表格 | 保留表头和单元格关系，在局部区域横向滚动，键盘可进入并阅读，不使整个页面横向溢出。 |
| 图片与文件资源 | 已登记资源继续按原消息顺序、可见性、鉴权、完整性和读取错误规则呈现；尺寸变化保持阅读锚点，文件名和错误不溢出阅读列。 |

资源排版不增加上传协议或扩大资源权限。输入区保留能力驱动的附件接入槽，支持附件区增长；图片输入和持久草稿遵守[图片输入规格](session-image-input.md)，显示、预览与归档遵守[图片历史规格](session-image-history.md)。这些图片要求仍为待实现规格；未接入并验证真实能力时不显示可点击的假上传按钮，不宣称图片上传已经可用。

## 显示模式、阅读与空对话

缺省使用 `conversation`，保留 `standard` 选项及已有保存偏好。助手样式不覆盖用户已保存的 Standard，不增设另一套模式存储。模式仍按已认证账号与稳定 `sessionId` 隔离，读取或保存失败、重试和同页同步遵守[共享显示规则](task-sessions.md#session-显示模式)。

Conversation 保留用户与助手消息的完整 parts、todo、计划、审批、问题、表单、已完成交互及真实错误；reasoning、compaction、普通工具及其输出资源按共享分类隐藏。显示选择不改变原始条目、资源索引、历史游标、操作回执或当前能力，不以精简呈现隐藏需要回应的信息。切换模式保留客户端、连接、Composer、保留消息节点、草稿与阅读意图。

列表、消息与详情分别滚动。正文保留“回到最新”入口；用户上读、键盘阅读旧内容或跳转脚注后，流式更新、资源尺寸变化、详情开关、模式或宽度变化不得强行跳到底部。跟随最新、文字锚点、自动补屏、历史分页失败和显式重试均沿用共享阅读规则；稳定布局下 prepend 前后同一可见文字偏差不得超过 1 CSS px。

只有已确认绑定且历史读取足以确认初次空对话时，显示简短欢迎语与三项文本建议。建议通过键盘和触屏均可操作，点击只填入当前助手草稿并聚焦输入，绝不自动发送、启动原生执行或更改设置。没有助手时引导创建；尚未选择、绑定加载中、历史加载中、历史失败、已删除或撤权分别保留实际状态，不展示可发送的假会话。

Conversation 过滤后无可见条目仍显示模式专用的无内容提示，不把隐藏的历史判定为初次空对话；存在更早历史时按共享视口需求继续分页。历史错误和重试不被欢迎内容遮盖。只读归档不提供填入或发送建议的入口。

## 固定输入区与原生操作

输入区在会话布局底部保持可达，窄屏位于可见视口底部。输入文本、设置入口、活动状态与动作共用清楚的边界，圆角约 16px、细边框；输入聚焦有紫色可见焦点，按钮保留各自焦点。文本区随内容增长，到上限后内部滚动。模型与权限位于下方左侧，发送与停止位于右侧；容器不足时分组换行，不能截断或覆盖输入、状态和动作。

模型、权限等动态 Provider 选择字段使用公共原生选择控件，设置值在原生确认或回读前保持已确认值；待定边框不表示新值已经生效。精细指针下，选择字段在实际 Bot 阅读容器宽度大于 600px 时采用 38px 表单高度，600px 及以下至少 44px；粗指针下高度至少 44px、字号为 16px；宽桌面中的窄面板同样适用。普通 Task/Test 不因窄视口自动启用 Bot 触控尺寸。交互表单保留布尔值、应用层必填校验与多选数组；多选为可滚动的原生列表，无下拉箭头。

快捷键说明靠近操作并按需显示，不增加常驻重复说明。打开模型、权限或命令菜单时，输入、关闭入口和底部动作仍可访问；错误靠近受影响的操作。按钮 busy、disabled 与选中状态表达正常进度，真实错误、未知结果和恢复受阻不能被简化为通用离线。

| 当前状态 | 输入与动作要求 |
| --- | --- |
| 可发送的空闲会话 | Enter 与 Send 使用同一发送或命令分类，Shift+Enter 换行；仅在真实发送门禁允许时提交。 |
| 正在生成且可补充 | 输入仍可编辑，保留独立的 Add to current turn 动作；Enter 仅在发送与 steer 门禁允许、且存在当前 turn 时补充，不触发停止。 |
| 正在生成且不可补充 | 不提供可执行的补充动作；保留草稿，Enter 不发送也不停止。停止是否可用由独立取消门禁决定。 |
| 可取消的当前轮次 | 右侧发送位置呈现独立 Interrupt 动作，必须经用户明确点击或键盘激活；普通 Enter 提交不能落到该动作。请求或处理中防止重复取消，不将取消确认当作任务完成或进程停止。 |
| 发送、命令或设置待确认 | 保留待确认目标、回执与草稿，按原门禁限制提交；未知结果只能检查原 operation，不能自动重发。设置待确认不能额外阻断本可执行的审批或取消。 |
| 断连或临时身份核验 | 对仍允许显示的同身份会话保留草稿编辑和阅读，暂停受限提交；不凭 Bot ready 或列表连接颜色恢复发送。 |
| 只读归档、删除或权威撤权 | 沿用只读与清理规则；所有发送、补充、审批、设置、命令和中断均不可执行。 |

发送、补充、响应、设置和取消分别使用当前 Session 的真实 `capabilities`、`operations`、同步状态、执行身份、生命周期与未决操作门禁。生成状态不等于可取消，连接成功不等于可发送；不能按 Provider 名称硬编码补充能力，也不能用统一禁用状态误伤仍允许的审批或取消。

IME composition 期间的 Enter 不发送、不补充、不停止，也不选择命令；保留现有组合状态和键码保护。命令菜单的 Enter、Tab、Shift+Tab 和 Escape 行为沿用共享规则；斜杠入口只消费当前会话实际命令目录，不把原型示例变成通用命令。普通文本、未知 slash 与绝对路径仍按原分类和能力提交。

发送确认只清理已提交的草稿版本，保留之后输入的新文本；未知回执保留原 operation 身份。成功后的焦点恢复不能抢走审批或其他控件焦点，也不能使隐藏 pane 获得焦点。模型、reasoning effort 和权限按原生能力发现，待确认目标与已生效值必须可区分；只有原生确认或回读才更新实际值，保留生效范围、失败和未知状态，不猜默认值、不自动重复设置或提高权限。Send、Add to current turn、Interrupt、Permissions 及原生活动标签继续使用共享规格规定的英文文案和可访问名称，周边说明与错误跟随页面语言。

## 焦点、专注与可访问性

专注模式保留同一会话实例、关键 DOM、输入、未决审批、显示偏好与阅读锚点；不能因隐藏外部布局重建客户端。详情、审批和其他浮层仍位于同一焦点边界；Escape 先关闭最上层，之后才退出专注模式，单次按键不跨层关闭，IME Escape 保留输入法行为。设置或 Timeline 交互表单的原生选项菜单打开时，首次 Escape 只取消原生菜单，保留设置面板、表单值、文本草稿和专注状态；之后的非 popup Escape 才按既有层级关闭并恢复焦点。录制缩放的原生菜单在全屏中遵守同一规则。

图标有可访问名称，hover 与键盘 focus 均可读取说明；视觉顺序与键盘遍历一致。窄屏发送、返回和关闭等关键触控目标至少 44 CSS px。320px、390px、桌面窄容器、矮屏、缩放及软键盘改变可见区域时，正文不横向溢出，输入与退出入口保持可达。过渡以 150–200ms 的颜色或显隐变化为限，尊重 reduced-motion，不添加装饰动画。

## 切换与缓存

### 三类入口与稳定框架

选择新助手时，在同一次渲染中撤下旧目标的可交互内容并关闭旧目标的新操作准入；不能继续向旧助手输入。外层标题、正文与输入区结构保持稳定，只展示当前账号下目标自己的内容。显示优先级为当前目标已初始化的实时视图、同身份仍驻留的最近可读视图、本地近期显示快照、完全无缓存时的骨架。

| 入口 | 等待详情、Session 与历史期间的呈现 |
| --- | --- |
| 同身份驻留 pane 命中 | 立即恢复原 DOM、客户端、消息、草稿、未决操作和阅读位置；后台详情复核不隐藏、重挂或用骨架覆盖原内容，不强制跟随最新。 |
| 无驻留 pane，但有本账号目标的合法本地快照 | 刷新、重新打开页面或 pane 淘汰后先展示只读历史预览，再后台复核；不等待本次 `getBot`、`current` 或 channel 完成。显示低干扰的“上次保存的对话”，不把它当作实时状态。 |
| 驻留与本地均未命中 | 立即显示目标标题、稳定正文骨架与不可提交的输入占位；绑定验证后接入真实共享 Composer，沿用原草稿，不创建另一套临时草稿。 |

无 Bot 绑定、已有绑定但尚无 Session snapshot、snapshot 已到达但首屏历史尚未接纳三个阶段均遵守此优先级。没有可读内容时，前两阶段保留正文与底部输入占位；真实 Composer 挂载后，历史占位仅占 Timeline 区域，不因历史等待卸载 Composer。骨架不能覆盖已有可读 entries、真实错误、不可用原因、未注册提示或归档只读状态，也不能提前显示欢迎语、假模型值或假活动状态。

`historyLoaded` 表示当前 Session fence 与 `historyEpoch` 下已接纳首批合法历史，包括合法空页与成功读到的离线历史。普通复核、认证暂停和同历史身份重连不清除此事实；替换历史身份、关闭或失效时重置。不能以 `current` 返回、`!historyReady` 或可见条目数判断首次历史是否完成；模式过滤为空不等于尚未加载。欢迎语仍须满足足以确认初次空对话的条件。

可保存历史还要求当前替换和 hydration 已结束且没有待恢复缺口。历史已经读过但仍在替换时，保留最后成功快照，不保存真实旧行与新事件混合的中间状态。在线分页资格与这些已读事实分别判定，离线合法历史仍可提供近期显示快照。

普通刷新和可恢复网络失败保留目标自己的可读视图，局部显示真实错误与按实际资格提供的重试。冷加载失败保留目标标题、返回和局部错误，不能无限骨架；不可重试时不提供虚假重试入口，不新增前端网络超时语义。初次内容只替换正文占位，可采用不超过 200ms 的短暂 opacity 过渡，reduced-motion 下直接替换；热切换不强制延时，不借用前一助手画面掩盖等待。

### 驻留连接与轻量恢复状态

最近三个助手保留各自 pane、DOM、客户端和连接；非当前 pane 隐藏且不可交互，身份仍有效时允许原连接同步回原 pane。访问第四个助手时淘汰最近最少访问的非当前 pane，关闭其连接、取消请求并释放驻留消息、资源和 DOM。详情缓存仅保留这三席对应详情及当前冷目标的一份待定详情，不复制完整历史。

淘汰保留轻量草稿文本、revision/submission、原未决 operation 及阅读书签。`sessionStorage` 获取、读取、枚举、写入或删除抛错时，同页内存仍能跨淘汰恢复这些信息。未知发送只能查询原 operation，不得通过重新发送求证。独立持久显示快照不计入三席连接，也不替代这些恢复记录。

草稿、回执与阅读书签的冷恢复只使用已确认的同账号、Bot、Session 和执行 fence；generation 变化使旧草稿与回执不能作为新执行的输入资格。既有纯文字冷缓存按原身份规则失效；含图冻结草稿和 unknown 操作仍保留原身份及结果查询证据，不因换代删除后重新发送。旧操作仅在原读取授权仍有效时查询，不能自动附到新目标。图片冷 pane 淘汰只释放页面 lease，不删除仍由持久草稿或冻结操作引用的 Blob。轻量阅读书签还必须匹配 `historyEpoch`，不得在书签内保存完整 Timeline、原始 key 集合、DOM 或资源。

目标不在尾页时按现有分页逐页查找，成功进度与连接代次共同决定是否继续。分页失败保留锚点并允许局部重试；中途浏览器断线重连或同一 channel 内 Controller 连接替换后仍能继续，运行时尚未同步时保持原恢复目标。只有确认完整历史边界或书签身份失效，才按[共享阅读规则](task-sessions.md)降级。尚未完成的恢复目标在隐藏、尾页加载中或再次淘汰时仍须保留。实时视图转为归档并替换 Timeline 时，尚未完成且身份仍有效的恢复目标必须继续；完整归档中确实缺失的目标按共享规则降级。用户选择返回最新后取消冷恢复，后续归档替换不得重新应用该目标。

### 浏览器近期显示快照

使用独立、带版本号的 `localStorage` 命名空间保存近期显示快照，不复用草稿或 operation 存储键。每账号最多六个近期目标，每份最多 150 条完整 entry，单份 JSON 最多 750,000 个 UTF-16 code unit，总计最多 1,500,000 个；超限先删除最旧完整 entry，再淘汰最久未访问目标。无法放入一条合法记录时跳过该次写入，不能破坏已有可读快照；不复制完整原生历史或扩大连接上限。

快照包含 `schemaVersion`、`ownerUserId`、`botId`、`lastKnownBinding`、目标名称、Session fence、`historyEpoch`、观察到的 `lastEventSeq`、已验证 entries、必要资源描述符、`savedAt`，以及可选阅读锚点。读取须验证外层存储键与内层身份一致、版本与尺寸合法、entries 及资源引用通过现有协议校验。序列号按现有十进制字符串合同精确比较，不能转为可能丢失精度的 Number。

登录恢复后必须先确认当前账号，再读取该账号目标的快照；账号未确认时不展示历史，不能由本地存储自称的账号恢复登录。`lastKnownBinding` 仅验证本地数据身份，不能据此创建可操作 client、发送目标或调用 `createBotSessionApi`。实时显示绑定仅来自本次已验证详情或当前有效账号 scope 内的已有 pane；随后权威详情确认绑定不同或明确无 Session 时，立即撤下旧快照。

持久写入只接受同身份下已初始化并通过协议校验的真实历史。空壳、未完成替换和缓存预览不能覆盖上次可读快照；权威空历史允许替换旧数据。合并变化后约每两秒写入一次，`pagehide`、页面隐藏和释放观察者时尽力写入剩余变化；最后一次写入不保证成功。存储拒绝、损坏、禁用或配额不足降级为内存或实时读取，不阻断正常会话及草稿；读取失败作为缓存未命中。

保存候选在排队前取得同一 store 的观察 lease，异步返回后重新核对账号、完整绑定、历史身份和撤销代次。清理或淘汰使候选失效后直接放弃；不得换新 lease 重试旧 payload。只有重新确认的真实历史能建立新的观察。账号和冷目标清理先同步撤资格，再执行物理清理；物理清理失败须保留撤销与诊断，不能报告已经删除磁盘记录。

快照不能恢复 transport cursor、channel admission、capabilities、active turn、pending interactions、outbox、operation 查询身份或发送目标。历史审批、工具和活动状态只作记录阅读，不能成为当前可操作请求；不显示缓存 Working 或继续旧计时。草稿和操作账本仍由原 owner 管理。

资源快照只保存描述符与显示必需的元数据，不保存图片字节、Blob URL、临时签名 URL 或上传草稿。纯预览可保留图片占位及尺寸，但禁止自动图片加载、资源请求和下载入口；仅设置 `active=false` 不足以满足此要求。接入已准入的实时内容后，在线受保护资源仍按有效身份与绑定读取，不能把描述符当作离线可读字节。

### 预览接续实时内容

只有相同完整绑定、fence 与 `historyEpoch` 的首屏历史已接纳后，才以实时内容接续预览；`current` 返回不等于历史已经可读。预览不能注入 live reducer。新消息按 `entryId` 合并、更新按 `revision` 替换，去重并保持确定顺序；实时首屏未覆盖的缓存范围继续明确标为未复核预览，不能冒充实时状态或构造分页游标。

真实 reducer 始终拥有同 entryId 的行和 revision。预览行只在视图内补足实际页尚未覆盖的范围，分页覆盖后撤下；完整历史或足够新水位的权威空历史清掉剩余旧行。缓存事件水位比已验证页面更新时，水位之外的行仍是只读预览，不能借 current 元数据宣称已经确认。旧快照不能降低已经验证的真实 revision；预览从不成为后续保存的输入。

同历史身份且有重合 entry 时复用对应行与阅读锚点，用户上读时不跳到底部，跟随最新模式才延续跟随。实时尾页与缓存锚点不重合时，可保留只读预览并通过正式分页寻找锚点；沿用既有分页恢复结束与失败规则，不能无限请求。权威空历史、身份变化、权威删除或更正必须替换失效旧数据，不能永久拼接旧缓存。成功接上实时内容后撤去预览标记；仍显示的未复核范围保留其身份提示。

显示源交接保留同目标框架、草稿和本地交互状态，不重新创建已有 client，不抢焦点。可选持久阅读锚点只在其完整身份有效且快照成功保存时参与恢复；不保证恢复从未成功写入的位置。

## 显示与新操作准入

显示可读与新操作可执行分别判定。完整绑定为 `ownerUserId`、`botId`、`sessionId`、`testExecutionId`；非空 `actionBinding` 必须完整等于当前 `displayBinding`。目标名称、列表状态、本地快照或缓存可读均不授予操作资格。

| 情况 | 新操作准入 |
| --- | --- |
| 回切驻留目标，当前选择代次尚未复核 | 关闭；原 pane、草稿和阅读继续保留。 |
| 当前目标详情有效确认且真实 Session 就绪 | 再与原有认证、能力、生命周期、执行身份及 pending 门禁合取。 |
| 同一已确认选择的普通后台轮询开始 | 保留原准入位，不因 busy 撤销，也不把 false 改为 true；真正 auth pause 仍关闭。 |
| 当前有效详情读取或解析失败 | 关闭，显示实际错误；当前有效重试成功后才能按原条件恢复。 |
| 仅本地快照或无可信绑定 | 关闭，不据快照创建可操作 client。 |
| 权威撤权、删除、账号 scope 失效或完整绑定变化 | 立即关闭旧准入并按身份规则撤下旧状态；仅新绑定可重新获得准入。 |

选择与操作准入必须同步更新：先关闭旧目标准入，再只为完整匹配的新目标开放；缓存命中的提前返回不能跳过更新，实际导航采纳后、React 提交前的旧 callback 也不能派发；同目标点击、未采纳或取消的导航不得使原目标永久冻结，不得等待周期检查后才禁发。每次选择代次变化重新复核，上一选择的成功不能直接开放本次操作。连续 A→B→C 的迟到响应必须匹配账号 scope、目标和请求代次，最多回到 B 自己仍有效的缓存，不能抢回选择、焦点或 C 的操作资格；淘汰、撤权和删除后不得重新插回缓存。取消或隐藏引起的 abort 不冒充业务失败，也不能凭此开放准入。

附加准入覆盖 send/steer、cancel、respond、updateSetting、executeCommand、refreshControls 和图片冻结派发。拒绝必须发生在生成 operationId 或交互提交身份、写入 unknown/submission/setting intent 之前；不排队、不自动重发、不制造不确定操作。所有实际派发入口都须检查，不能只禁用按钮或假设图片必经通用命令路径。

此准入只约束新命令，不替代认证暂停，也不改变 `active/current/runtimeReady/connected` 的含义。channel 事件、历史与资源读取、已发出命令的回执、原 operation 查询和本地草稿仍服从原有身份与 fence 合同。`client.refresh()` 是读取，与远端 `refresh_controls` 命令分开。非 Bot 调用方默认不增加此限制，原能力与只读门禁保持不变。

详情复核期间保留真实 Composer 草稿编辑、菜单浏览、Timeline 待处理请求导航和 InteractionCard 本地填写，仅关闭远端提交，不能把整个表单禁用。认证核验、页面失焦或可见性恢复仍服从既有身份合同；普通轮询不能使发送和 Interrupt 按钮周期闪烁。切换、后台响应与发送完成不向隐藏 pane 聚焦，触屏切换不自动弹出键盘。

## 生命周期与清理

切换、关闭视图或正常导航只按驻留策略释放浏览器连接，不停止或重启原生执行，也不清除成功保存的持久显示快照。删除或权威拒绝访问（403/404/410）必须清除对应的已挂载与已淘汰状态、持久显示快照、显示偏好和可访问的浏览器存储，即使新页面缓存尚未选择该 Bot，也要清除此前导航留下的状态并阻止陈旧选择重新打开它。账号失效、退出或切换还清除未挂载页面留下的 Bot 显示快照、草稿和回执；临时身份核验及恢复读取期间，已确认的同一助手会话持续展示原有 pane、消息、草稿、显示菜单、全屏和阅读位置；发送与结果发布按现有准入暂停。连接可复用时保持原 channel；超过既有暂停期限、缓冲上限或传输真正中断后允许必要重连，并在准入恢复后按 cursor 重放。此过程保留原 client 和阅读状态，不能用替代缓存掩盖状态丢失。

浏览器拒绝删除时，同页使用跨缓存实例的失效标记阻止旧磁盘值重新进入内存及旧实例补写，新授权实例仍可保存新状态；不能证明无法访问的存储已物理删除。新账号不能访问旧账号缓存；身份重新核验期间不能重新恢复隐藏缓存，已显示内容按稳定呈现规则保留，真实失权立即撤下。页面重载不保证恢复未能持久写入的内容，成功保存的显示快照及可选阅读锚点按上述恢复规则处理。

跨标签更新在同一历史身份内按已观察序列防止旧快照覆盖新快照；不同身份不能仅凭 `savedAt` 判新旧。撤权、删除或账号失效同步撤销对应读取、已排定写入与跨标签缓存，并以失效代次阻止迟到写回。存储删除失败时至少先撤销当前页面的读取与写入资格；账号确认和权威读取仍是最终隔离边界，不能承诺不可访问存储已物理清空。

删除提交尚未确认时，缓存只可逆地阻止目标选择并关闭客户端，保留轻量恢复状态与尚未权威失效的显示快照，但屏障期间禁止恢复展示或迟到写回；明确拒绝与权威未删除共同确认后才解除。已确认删除标记在同账号 scope 的页面重挂间保留，不能通过导航重新打开旧绑定。

已打开的独立 Session，包括旧 Test URL 和归档阅读页，每三秒核对权威 current。已认证的 current 409/resource_conflict 表示该独立入口不再允许访问，立即撤下历史并清除可识别的本地 Session 状态，不回退到归档。普通 Task 和资源/操作的版本冲突不属于此条件；网络失败也不冒充已删除。
