# Goal 容器需求

Goal 是具有独立身份、标题、描述、负责人、状态、Thread 和附件的项目资源。普通 Task 可归属于同项目的一个 Goal，也可不归属；Goal 不嵌套，也不属于普通 Task 依赖图。现有 Task、资料和依赖不因引入 Goal 而迁移。

Goal 的描述与附件保存当前有效的整体 spec、架构、任务拆解、关键决策、阶段成果、交付和整体验收结论，并记录已达成结果、剩余范围及重要阻碍。无论这些结论由 Session 直接形成，还是由子 Task 讨论、调研、设计或拆解产出，形成有效结论后都应更新 Goal 并核对保存结果。子 Task 保留自身的工作定义、责任、状态、成果和证据，并引用 Goal 的共享材料；临时操作和原始日志留在 Session。该归属约定由使用者维护，服务不会因子 Task 完成而自动汇总材料；子 Task 的数量进度不能代替整体交付与验收。CLI 和 MCP 的材料手册说明通用规则，各项目自行确定阶段、文件和确认要求。

HTTP 和 MCP 创建接受 `type=goal`；省略类型创建普通 Task。类型创建后不可更改。普通 Task 的 `parentId` 可在创建时指定，更新时省略保持、null 移出、Goal ID 转移；目标必须是同项目中未删除的 Goal。归属变化使用子 Task 的精确版本，不改变依赖、状态或其他 Task 的版本。父 Goal 的状态不限制归属和普通 Task 的手动修改。

Goal 默认 `todo`，负责人默认创建者；显式 `assignedTo:null` 表示未分配。Goal 可在 `todo`、`in_progress`、`done`、`cancelled` 间转换，同状态在版本检查后不写入。存在 Goal 验收依赖时，进入 `done` 要求所有直接前置 Goal 为 `done`；已有已完成的下游 Goal 依赖它时，拒绝离开 `done`。取消的前置不能满足完成条件。进入 `in_progress` 记录新的 startedAt；返回 `todo` 清空三个状态时间；进入 done 或 cancelled 保留可空 startedAt，分别记录 completedAt 或 cancelledAt 并清空另一终态时间。Goal 的 ready 始终为 false，不支持普通 Task 依赖、Steps、自动执行、平台要求或 Worker claim；可使用 `pullRequests`、Thread 和附件。

Goal 验收关系由下游持有，与普通 Task 依赖和 Parent 分开管理。同项目或当前 owner Team 相同的跨项目 Goal 可以建立关系；有权编辑下游且可读新增前置才可添加。拒绝自依赖、普通 Task 端点、不可用目标、跨 Team 和环。直接前置最多 30 条，编辑和完整替换原子生效；替换必须显式给出整个集合，空集合表示清空。已完成下游只能保留或新增已完成前置。

关系读取在同一只读快照取得修订、完成阻塞、前置和直接下游。可读前置含 Project、Goal、标题、状态与项目内／外部类别；不可读前置只表示存在关系，编辑者取得不暴露目标身份的 edge UUID，可单独移除。不可读下游在分页前排除，不泄露身份或数量。下游默认每页 20 条、最多 50 条，每页重新授权。关系修订为独立的正 int64；首次实际修改从逻辑值 1 推进为 2，清空后保留，空操作不推进。写入先比较调用者的原修订，冲突和提交未知都不自动重放。关系变化不修改 Task 元数据版本，旧 detail、sync、图和 ready 投影保持原合同。公开读取与编辑见[Goal 依赖 REST 协议](goal-dependencies.md)，事务机制见[Goal 关系设计](../design/goal-dependencies.md)。

普通子 Task 实际从其他状态进入 `in_progress` 时，无论由人工状态修改还是 Worker 领取触发，若其当前 Parent Goal 为 `todo`，服务端在同一事务中将 Goal 推进为 `in_progress`，按 Goal 自身生命周期更新起点、终态时间、更新时间和版本；任一写入失败时两者均不提交。Goal 已为 `in_progress`、`done` 或 `cancelled` 时保持原状态。没有 Parent 的 Task 正常开始；同状态请求、运行中修改其他字段或归属不触发该规则。子 Task 后续回退、完成、取消或释放领取不自动改变 Goal 状态，也不扫描或补改历史数据。Goal 的变更可由正常读取和增量同步观察，不产生执行 Task Webhook。

Goal 按直接可见普通子 Task 汇总真实总数、done、cancelled 和未结束数量；Web 完成进度使用 done / (total - cancelled)，统计本身不派生 Goal 状态。完成进度的零分母及轨道遵守 [Web 进度规则](daynight-web.md#项目整体进度)。完成或取消 Goal 不改变、隐藏或停止孩子，但阻止后续自动领取；已有 claim 沿用自身规则。被其他未删除 Goal 引用的 Goal 不能直接删除。无入边时，删除 Goal 同事务移除其验收出边、推进实际变化的关系修订，软删除容器并轮换项目缓存 epoch；保留孩子的 Parent、状态、版本、普通 Task 依赖和执行归属；孩子及其资料从正常入口不可见，原执行由下次成功库存观察进入既有停止和归档流程。删除成功只表示删除已提交，不表示进程已停止。

MCP 复用现有 Task 工具管理 Goal，`task_list` 可按类型及 Parent 选择，`task_ready` 保持普通 Task 并可按 Parent 选择。查询 Parent 省略表示不限、null 表示未归属、UUID 表示直接孩子；续页绑定筛选条件。Goal 状态写入不需要额外确认凭证。

读取、权限、错误和不确定写入沿用 Task 资源合同。独立 Goal 的图、子 Task 及外部 Goal 对话框支持浏览器前进和后退；项目页的图、详情及 Goal 子层也可按阅读顺序前进和后退。两类 Goal 入口打开任务链图时，图内普通成员及直接外部前置均沿用[执行计时需求](daynight-task-timing.md)的耗时、样本和阈值规则；带执行起点的任务不能导致图或页面渲染失败。时间或设置样本更新保留已打开图的浏览状态。详细事务与调度机制见[服务端设计](../design/daynight-server.md)，阅读历史、关闭和草稿行为见[任务浏览需求](daynight-task-inspection.md)。

项目 Goal 列表按 Goal 自身负责人和四态筛选、排序及每页 20 个顶层 Goal 分页。Goal 页签数字按自身负责人匹配统计状态为 `todo` 或 `in_progress` 的 Goal 容器，不受状态筛选或分页影响，孩子负责人和进度不决定其是否计入；孩子进度保持完整范围。桌面同字体、等价未换行内容的 Goal 标题行与任务链标题行等高；长标题或信息换行时由内容自然撑高，窄屏保持紧凑间距和内容完整。标题行及外框按 Goal 自身状态使用[共享状态配色](daynight-web.md#任务条目状态背景)，与子任务进度无关。每个 Goal 初始收起；标题行保留箭头、图标、标题、进行中数量、暂停数量、负责人、自动执行提示、任务数量、完成时间及进度。标题是独立的原生按钮，在收起和展开时均打开对应 Goal 详情而不切换展开，并在悬停和键盘聚焦时提供可见反馈；箭头按钮、图标、静态摘要及非交互空白切换该 Goal 的内联内容。状态及其 Session 入口独立于展开按钮，交互控件不相互嵌套。标题显示“共 N 个任务”／“N tasks”，N 为直接可见普通子 Task 的总数，包括取消的成员；完成进度仍为 `done / (total - cancelled)`，零分母遵守[进度规则](daynight-web.md#项目整体进度)。独立的 Goal 详情和整体图按钮在收起及展开时均可用，分别打开对应阅读器而不切换展开；关闭后焦点返回实际入口，入口失效时使用可见回退。

每个 Goal 标题旁在收起和展开时显示完整、可手动选择的 UUID 及独立复制按钮。按钮遵守[统一复制控件规则](../design/daynight-web.md#复制控件的职责)，名称、成功与失败提示和重试沿用 Goal 详情；复制值逐字等于 Goal ID。等待时阻止重复提交，切换资源或卸载后的结果不影响新行。点击、拖选 ID 或操作复制与反馈不切换展开、打开详情或图；普通空白及其他入口保持原有行为。只读权限、空 Goal 和所有可读状态均可复制；长标题、UUID 与反馈自然换行，在 320px、390px 和桌面宽度保持可读且按钮可达。

同宽卡片内，Goal 与任务链的箭头 viewport 和可见路径分别对齐：卡片内容宽度大于 600px 时 viewport 距内边缘 15px，600px 及以下为 11px。Goal 箭头为 14×14px；内容宽度大于 740px 时显示 20×20px 的装饰性同心圆图标，箭头、图标和标题列之间各留 8px。740px 及以下隐藏图标并收回其空间；展开按钮保留 22×至少 34px 的独立命中范围及可见焦点，且不覆盖标题。紧凑布局的进度左沿与标题列对齐，轨道最大宽 145px、空间不足时可收缩，计数完整显示。ID 与复制按钮保持同一组；空间不足时完整可选的 ID 文本在自身区域换行，按钮紧邻最后一行，反馈可另排且不挤走按钮。内容自然换行且不产生横向溢出。

展开后以单层列表直接展示所有 `parentId` 等于该 Goal ID 的可见普通 Task，不显示独立任务或任务链分区、链汇总或第二层展开。全部五态及较早结束的孩子均可达，不受顶层筛选或日期裁剪，不增加子项分页；范围内代表、多起点合流成员和跨 Goal 链的单个成员各出现一次，其他 Goal、未归属 Task 与范围外前置不因依赖加入列表。只有真实子 Task 总数为零的 Goal 展开后显示空态；全取消的 Goal 仍展示其子 Task。

成员整行背景及边框按[项目普通 Task 行](daynight-web.md#项目普通-task-行)的展开列表规则，在所有视口宽度下贴齐展开内容区的左右内边缘；成员内容在行内增加层级缩进，缩进区域由成员自身状态背景覆盖。

收起和展开的 Goal 卡片均保持连续的 8px 外层圆角轮廓，卡片之间保留 8px 间距。展开时标题与内容以单条分隔线相接，末个可见成员的背景直接接到卡片内侧底边，内容不溢出外层圆角；空 Goal 和子项筛选无匹配时的空态保留内边距。标题背景取 Goal 自身状态，展开容器保持中性，每个成员按自身状态着色。焦点轮廓保持可见，完成时间提示在卡片边缘也能完整显示。

成员从完整项目快照按原次序取得，再整体按 `in_progress`、`todo`、`proposed`、终态稳定排序；前三组保留快照次序。`done` 与 `cancelled` 混排，分别按 `completedAt` 或 `cancelledAt` 的完整时间精度倒序，未知时间在末尾，相同时间或均未知时保留快照次序。创建时间、ID、负责人、就绪、暂停、链归属和依赖拓扑不增加排序优先级。

每个成员采用[项目普通 Task 行](daynight-web.md#项目普通-task-行)，显示自身标题、完整 ID、创建时间、五态、负责人、自动执行许可、平台、机器记录和 Tag，并在适用时显示耗时、完成时间、暂停、就绪、阻塞、卡住提醒和 Session 状态。Task 标题及行空白打开详情，可用的 Session 控件独立打开该任务的 Session；复制 ID、文本选择及两种阅读动作均不切换 Goal。成员行的 Session 状态、时效和启动宽限遵循项目列表要求。

标题旁显示直接普通子 Task 的“X 进行中”／“X in progress”，包括零；每个 ID 只计一次，独立 Task 与链内成员均计入，人工执行和暂停中的 `in_progress` Task 也计入。Goal 自身、其他 Goal 的孩子、未归属 Task、链外 external 前置及跨范围链的范围外成员不计入。进行中数量之后显示直属子 Task 的暂停汇总，资格遵循[暂停规则](daynight-web.md#暂停展示与解除)；零数量隐藏，子项标签筛选和展开状态不影响范围。非零数量属于展开按钮的可访问描述。负责人之后、任务组成之前，当任一直接孩子的 Worker claim 为 `active` 时显示采用[共享活动角色](../ui-design.md#attention-activity-health-and-policy)的状态点及“自动执行中”／“Automatic execution active”；`allowAgents` 许可、released／completed／缺失 claim 或仅 Session working 均不触发。提示表示 active claim，不表示 Agent 当前正在输出；子链的完整分量提示不用于推导 Goal 提示。数量和提示在收起与展开时均可读，文字属于展开按钮的可访问内容，装饰点对辅助技术隐藏，不新增独立操作。暂停属性、状态、claim 或 Parent 随已有项目快照变化时更新摘要；无变化核验保留已显示内容和阅读状态，不增加逐 Goal／Task 请求或轮询。

Goal 自身生命周期状态旁汇总全部直接普通子 Task 的可展示 Session 状态，按 `warning > notice > working` 显示英文角标；无可展示状态时隐藏角标与状态入口。颜色及准入遵循[任务链 Session 状态](../design/task-session-status.md)，不从 Worker claim 或 `allowAgents` 推断。Goal 自身、范围外成员及前置不参与，子任务 Tag 筛选和 Goal 展开状态不缩小集合。Goal 标题可见时收起和展开均可观察；移出视口或页面隐藏按共享生命周期释放观察。状态、归属和可见性变化时更新汇总。可用状态入口展开 Goal，不选择任意 Session；Goal 状态文字、底色和进度仍表达 Goal 自身及其完成进度。全部 Goal 生命周期状态均可显示子任务角标，长标题与窄屏不遮挡内容或产生横向溢出。

多个 Goal 独立展开；收起卸载成员，再展开直接显示全部成员。展开按钮、标题、独立详情及整体图均可通过 Tab 到达并遵循原生按钮的 Enter／Space 语义；展开状态与内容可见性一致，收起后焦点不留在隐藏内容。Task 与 Session 控件只执行自身动作，不切换父 Goal。详情、图和无变化的后台核验保留展开、焦点和滚动；真实归属、依赖或状态变化更新实际内容，已消失入口不可操作。Session 时效或可见性变化使已聚焦的 Session 控件消失时，焦点回到仍可见的对应 Task 主体；详情或列表外的有效焦点不被抢走。筛选、翻页或离开导致行卸载后再次进入可恢复初始收起。跨资源跳转不改变背景筛选、页码和展开，关闭后恢复原入口或可见回退。原生键盘控件、双语、长文本及窄屏遵守[任务浏览需求](daynight-task-inspection.md)和 [UI 原则](../ui-design.md)。加载失败、后台失败与空 Goal 区分，现有错误和重试保持可用，身份或权限失效撤回内容并拒绝晚到响应。

项目页顶部依次提供“新建 Task”和“新建 Goal”／“New Goal”入口，宽屏两者相邻并使用相同的 primary 视觉和尺寸；窄屏收进项目操作菜单，顺序与交互遵守[项目标题区要求](daynight-web.md#项目分区导航)。Goal 列表不另设创建入口。Goal 入口不依赖任务类别、搜索、筛选、分页、空列表或图快照的加载和读取结果；Task 保留原有快照准入。Task 表单可选择 Goal 和负责人；Goal 表单使用当前项目身份，成功创建后同步项目内容，不强制切换类别或清空搜索筛选。切换类别、搜索、刷新列表或断点变化不关闭已打开的表单或丢失草稿，取消不提交；关闭后焦点按当前布局返回相应入口，入口不可用时回到项目标题。项目身份、访问权限和表单写入规则保持不变。

Goal 详情提供名称、描述、负责人和四态修改。详情状态入口与负责人位于同一控制行，使用与 Task Detail 一致的紧凑色点菜单，显示当前语言的状态文字及箭头，不另设状态字段标签。菜单只提供 `todo`、`in_progress`、`done`、`cancelled`；已取消 Goal 仍可选择其他状态。Goal 自身、项目列表内的 Task 和任务链的完成时间遵守[完成时间需求](daynight-completion-time.md)，详情独立显示 Goal 自身精确完成时间。菜单支持键盘操作，弹窗、独立页、全屏及手机宽度下保持可用。

Goal 详情标题栏在全屏按钮后提供“更多 Goal 操作”菜单，复制当前 Goal 的绝对链接。链接打开默认描述页，不包含当前页签或附件；只读、空 Goal 和所有可读状态均可复制，未取得详情或失去访问时不显示。复制关闭菜单并恢复焦点，成功或失败显示反馈，失败可重试；切换资源、失权或关闭后的晚到结果不影响其他详情。菜单支持键盘操作和 Escape，后台核对保留已显示控件，复制不改变阅读位置、草稿或服务端数据。

Goal 详情在弹窗、独立页及全屏依次提供“描述 / 附件 / 讨论”三个页签，默认选择描述。子任务列表属于项目 Goal 列表，详情不重复列出。描述页签始终可用，以 Markdown 展示描述；非空描述与 Task 概览使用[一致的阅读容器](daynight-web.md#描述与附件引用)，空描述显示现有空态；相对附件链接和图片归属于该 Goal，并沿用附件导航。描述区域右侧的信息栏首先展示只读的“Goal 验收依赖”：直接前置、直接下游、可读 Goal 的真实状态、项目内／外部类别和外部 Project 名称。不可读前置仅显示无法访问，不显示其身份或个别状态；下游按游标提供上一页／下一页。可推进完成的 Goal 按服务返回的 `completionBlocked` 提示受阻，原有状态操作仍可提交；依赖拒绝保留真实状态并刷新关系。关联使用真实 Project/Goal 链接，应用内导航保护草稿；弹窗中的关联指向背景根 Goal 时，打开无遮罩的目标详情并保留原弹窗供后退恢复，相同地址也能生效。从任一下游分页进入关联 Goal 后返回，恢复来源浏览器条目最近确认的下游分页，并在重新授权读取后恢复关联入口焦点。原生前进／后退多次往返保持此行为；返回后翻页更新该条目的位置。同一 Goal 的新页签条目继承当前阅读坐标，回到已知条目恢复其独立位置，各条目重新读取当前授权的关系。入口已消失时回退 Goal 标题；返回读取瞬时失败时，重试仍读取原分页。首次加载、空集合、能力不可用和读取失败分别呈现；瞬时刷新失败保留仍获准的关系并提供重试，账号、项目权限或资源变化撤回不再获准的信息并忽略旧响应。只在可见描述页按现有同步节奏独立读取，不把关系写入 Task 投影或持久缓存。旧服务 router 返回无 principal 的 JSON 404 时显示关系能力不可用并保留源详情。信息栏随后在“常规信息”首项显示当前 Goal 的完整 UUID，标为 `Goal ID`，旁边提供遵守[统一复制控件规则](../design/daynight-web.md#复制控件的职责)的图标按钮。按钮的可访问名称和提示按当前语言为“复制 Goal ID”／“Copy Goal ID”；鼠标与键盘均可触发，复制内容逐字等于当前 Goal ID。等待剪贴板写入时禁用重复提交，成功显示“已复制”／“Copied”；拒绝或剪贴板不可用时显示“无法复制 Goal ID，请选中并手动复制。”／“Could not copy the Goal ID. Select and copy it manually.”，完整 ID 仍可选择，后续可重试。反馈不改变信息栏布局，切换资源或卸载后的晚到结果不影响新资源。复制属于阅读操作，在只读权限、Goal 各可读状态、空 Goal 和统计加载或失败时均可使用；资源不可用时继续遵守既有阅读边界。信息栏还显示 Goal 自身的创建时间、修改时间，以及直接可见普通子 Task 的独立任务数、任务链数、总数、已完成、已取消和未结束数量。日期按当前语言及浏览器本地时区显示，包含年份并精确到秒。任务分类先使用完整普通依赖图，再按 Parent 取范围；跨 Goal 的多成员链即使在当前范围只有一个成员仍计为任务链，external 边不合并普通链。进展区区分完成与取消，不把取消数量计为成功交付。桌面使用描述与信息栏两列，窄屏按阅读顺序堆叠，长描述、完整 UUID、日期和数值在 320px、390px 及桌面宽度下不产生横向溢出，ID 完整可读且复制按钮可达。统计尚未加载、零任务和读取失败须可区分；失败保留已显示统计并提供重试。

三个面板支持键盘导航，各自保持挂载；切换、全屏和后台刷新保留滚动、附件选择和讨论草稿，统计更新不重置阅读状态。普通 Task 不增加描述页签。Task 详情的概览只读展示所属 Goal，提供进入真实 Parent 的链接，不提供归属选择或保存；跨 Goal 的任务 Details 跳转在目标 Goal 下直接打开对应 Task；链外“展开”对多成员目标在目标 Goal 下直接打开完整链图，对单成员目标打开 Task 详情。两种跳转保持既有浏览器历史和草稿保护，具体展示与导航遵守[任务浏览需求](daynight-task-inspection.md)。完成或取消 Goal 前确认 Task 状态保留、后续自动领取被排除且已有领取继续；删除前确认 Goal 及其 Task 不可见、Parent 保留，执行中的 Task 在后续成功观察中开始停止。取消或 Escape 关闭确认不提交，未结束 Task 不阻止确认。非终态选择与终态确认均使用已审阅详情的精确版本；确认期间详情发生实质变化须重新审阅。

新建 Goal 和项目页新建 Task 使用一致的表单弹窗：标题与关闭按钮同排，正文和字段有清晰间距、边框、圆角、聚焦及禁用外观，底部操作靠右并可换行。桌面及手机的弹窗保持视口内安全边距；长名称、UUID 和错误不产生横向溢出，正文和恢复操作可滚动，标题、关闭及底部操作保持可达。弹窗约束焦点，Escape 仅关闭最上层并恢复入口焦点。

表单失败时保留输入并显示错误。版本冲突后应先核对当前资源再作决定；写入结果未知时只能核对当前状态，不能自动重放或把当前值当作原请求成功的证明。归属和状态变化更新实际列表与进度，并保留详情的阅读、展开和草稿状态。

## Goal 整体依赖图

每个项目 Goal 行最右侧提供独立的“查看整体依赖图”按钮，收起和展开时均可使用，不触发详情或展开控件。图一次展示全部直接成员，包括五态、独立任务和断开的多条链，不受背景筛选或分页裁剪；空 Goal 显示明确空态。成员每个出现一次。成员直接依赖的范围外可访问 Task 按 ID 去重各显示一张外部卡片，不继续加入其祖先、所在链或仅反向依赖成员的后续。只展示指向成员的真实前置边，普通依赖与 external 依赖分类保持原值；外部卡片区分成员并显示可访问的所属 Goal，无 Parent 时不虚构归属。不可访问的依赖沿用现有权限和阻塞约定，不制造节点或泄露内容。

项目地址 `/projects/{projectId}?tab=tasks&goalGraph={goalId}` 可直接打开当前可读 Goal 的整体图，并在登录回跳及刷新后保持打开。地址只接受一个规范 Goal UUID 和 `tab=tasks`；与 `chain` 同时出现或格式无效时提示目标不可用并清除定位参数。完整当前项目快照确认目标为 Goal 后才打开，空 Goal 和被筛选或分页隐藏的 Goal 同样可打开；首次读取失败保留地址供重试，缺失或类型错误的目标清除地址并提示。关闭图以替换当前历史条目移除参数，前进后退、详情和草稿保护沿用项目阅读规则；Goal 删除或失权时撤下图和详情。背景列表的筛选、分页和偏好不因地址入口改变。

整体图页头右上角提供关闭按钮，操作行依次提供带文字的“复制链接 / Copy link”和“Goal 详情 / Goal details”；窄屏操作行位于标题下方。复制当前站点的规范绝对地址，提交期间保持焦点并防止重复写入；成功提示已复制，失败显示错误并可重试。复制和反馈不改变图尺寸、视口、选择或焦点，切换目标或关闭后旧结果失效。详情是原生按钮，声明打开对话框，打开当前图所属 Goal 的现有详情，不打开子 Task；空 Goal 和保留有效图内容的刷新失败态也提供该入口。普通及全屏采用同一结构，长标题与窄屏让标题区收缩换行，按钮、焦点和工具栏保持完整可达。关闭详情或在详情普通模式按 Escape 后返回该按钮，保留原图方向、有效选择、平移缩放、全屏及背景列表状态；浏览历史、草稿保护、读取失败和权限失效沿用现有详情规则。该入口同样适用于从任务链视图导航到的 Goal 整体图；普通链图和嵌入式图不提供此页头按钮。

内部和外部卡片共用[任务图卡片尺寸](daynight-task-inspection.md#必须交付的行为)，随根字号增大按比例扩展，保留状态、外部归属、暂停、自动执行许可、平台和执行时间。主体是切换依赖检查的原生按钮，独立“详情 / Details”是其兄弟原生按钮；两者均可通过 Tab 到达，并遵循 Enter／Space 语义及各自的可访问名称。主体仅选择或取消检查，Details 打开对应 Task 的既有详情，以该 Details 按钮作为关闭后的焦点恢复目标；浏览器历史及草稿保护沿用既有详情行为。外部卡片不跳图或展开，状态和 Details 不重叠。

选择任务后，从完整项目索引追溯所选任务及全部普通或 external 上游 H；只高亮当前投影中的 H 节点，以及两端均属于 H 的真实可见边和箭头。选中项和前置使用任务链现有的不同强调，无关节点及边淡化并保持文字和状态可辨。完整 H 中不在当前投影的任务按 ID 去重，以任务链现有的双语隐藏上游提示显示，零数量时隐藏。同卡片或画布空白清除，另一卡片替换选择。同 Goal 快照更新时，仍可见的选中项保留并按新索引重算；选中项离开投影或切换 Goal 时清除。方向切换、全图适应、详情开关和全屏切换保留仍可见的选择。检查自身不增加请求，不改变投影、几何、缩放或视口；Details 沿用既有详情读取，不增加额外的图读取或刷新。

图支持水平与垂直、平移、缩放、适应视口、全屏及分层 Escape，方向按项目和 Goal 独立保存，默认水平。独立任务与断开的依赖组利用画布宽高紧凑排列，并行层可以换行；卡片不重叠，真实连线不穿过其他卡片。首次以最高 1 倍显示；缩放下限通常为 0.8，在画布过窄时按卡片宽度降低至不小于 0.2，超出画布的部分可平移阅读；显式“适应全图”按当前画布重新排列并完整显示节点和连线，不以渐进展开或静默截断缩减集合。图标题和状态来自 Goal，成员进度及暂停数量不包括外部前置。

后台相同数据、状态及内容更新、检查、详情、全屏切换和被动尺寸变化保留几何与视口；真实归属或依赖变化可进行必要重排，状态变化更新卡片，外部 Task 转为成员后不重复显示。重排须遵守[界面连续性规则](../ui-design.md#preserve-interface-continuity-when-data-changes)：图在更新全过程保持打开，保留有效视口和交互状态，不得因重排自动重置视口。首次读取失败不得显示为空 Goal；后台读取失败保留有效内容，并在图内提供错误与重试。图内打开 Task 详情并删除该 Task 后，退出已删除任务的详情，持续保留有效 Goal 图并更新成员和关联信息；删除最后一个成员后在同一弹窗及画布宿主显示空 Goal 图。删除及后台同步全过程不以加载占位替换页面或图，也不显示自动刷新进度；显式 Refresh/Retry 保留原有进度与错误语义。读取失败保留已显示内容和重试入口，重试成功后原位更新。项目历史与数据准入仍遵守既有安全规则；旧详情与写入资格退休，迟到响应不能覆盖新数据。主动导航遵循其交互规则，不覆盖其他阅读选择。Goal 本身删除、失权或身份变化时关闭图，旧详情及迟到响应不能恢复内容。关闭图恢复有效原入口或同 Goal 的可见控件，再回退可见列表或页签，不主动改变筛选、分页或展开。入口、工具栏、空态和错误支持中英文与键盘，窄屏保持控件可达且页面不横向溢出。普通链图的渐进阅读、检查和外部跳转规则继续适用于链图，见[任务浏览需求](daynight-task-inspection.md)。

验收和压力验证最多使用 1,000 个去重 Task（含外部前置），并检查完整节点、布局、检查、详情和阅读交互。正常与外部卡片、分叉及汇聚依赖、投影外祖先、取消与换选、同步重算及移除、删除成员（包括最后一个）全过程保持图及有效视口、Goal 切换、详情关闭和焦点恢复均须验证；空图、已有失败和重试、长标题、中英文、320px／390px 及桌面和键盘阅读均保持可用。该规模是验证边界，不增加产品输入限制或截断行为。
