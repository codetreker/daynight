# Goal 容器需求

Goal 是具有独立身份、标题、描述、负责人、状态、Thread 和附件的项目资源。普通 Task 可归属于同项目的一个 Goal，也可不归属；Goal 不嵌套，不属于依赖图。现有 Task、资料和依赖不因引入 Goal 而迁移。

Goal 的描述与附件保存当前有效的整体 spec、架构、任务拆解、关键决策、阶段成果、交付和整体验收结论，并记录已达成结果、剩余范围及重要阻碍。无论这些结论由 Session 直接形成，还是由子 Task 讨论、调研、设计或拆解产出，形成有效结论后都应更新 Goal 并核对保存结果。子 Task 保留自身的工作定义、责任、状态、成果和证据，并引用 Goal 的共享材料；临时操作和原始日志留在 Session。该归属约定由使用者维护，服务不会因子 Task 完成而自动汇总材料；子 Task 的数量进度不能代替整体交付与验收。CLI 和 MCP 的材料手册说明通用规则，各项目自行确定阶段、文件和确认要求。

HTTP 和 MCP 创建接受 `type=goal`；省略类型创建普通 Task。类型创建后不可更改。普通 Task 的 `parentId` 可在创建时指定，更新时省略保持、null 移出、Goal ID 转移；目标必须是同项目中未删除的 Goal。归属变化使用子 Task 的精确版本，不改变依赖、状态或其他 Task 的版本。父 Goal 的状态不限制归属和普通 Task 的手动修改。

Goal 默认 `todo`，负责人默认创建者；显式 `assignedTo:null` 表示未分配。Goal 可在 `todo`、`in_progress`、`done`、`cancelled` 间自由转换，同状态在版本检查后不写入。进入 `in_progress` 记录新的 startedAt；返回 `todo` 清空三个状态时间；进入 done 或 cancelled 保留可空 startedAt，分别记录 completedAt 或 cancelledAt 并清空另一终态时间。Goal 的 ready 始终为 false，不支持依赖、Steps、自动执行、平台要求或 Worker claim；可使用 `pullRequests`、Thread 和附件。

普通子 Task 实际从其他状态进入 `in_progress` 时，无论由人工状态修改还是 Worker 领取触发，若其当前 Parent Goal 为 `todo`，服务端在同一事务中将 Goal 推进为 `in_progress`，按 Goal 自身生命周期更新起点、终态时间、更新时间和版本；任一写入失败时两者均不提交。Goal 已为 `in_progress`、`done` 或 `cancelled` 时保持原状态。没有 Parent 的 Task 正常开始；同状态请求、运行中修改其他字段或归属不触发该规则。子 Task 后续回退、完成、取消或释放领取不自动改变 Goal 状态，也不扫描或补改历史数据。Goal 的变更可由正常读取和增量同步观察，不产生执行 Task Webhook。

Goal 按直接可见普通子 Task 汇总真实总数、done、cancelled 和未结束数量；Web 完成进度使用 done / (total - cancelled)，统计本身不派生 Goal 状态。完成进度的零分母及轨道遵守 [Web 进度规则](daynight-web.md#项目整体进度)。完成或取消 Goal 不改变、隐藏或停止孩子，但阻止后续自动领取；已有 claim 沿用自身规则。删除 Goal 只软删除容器并轮换项目缓存 epoch，保留孩子的 Parent、状态、版本、依赖和执行归属；孩子及其资料从正常入口不可见，原执行由下次成功库存观察进入既有停止和归档流程。删除成功只表示删除已提交，不表示进程已停止。

MCP 复用现有 Task 工具管理 Goal，`task_list` 可按类型及 Parent 选择，`task_ready` 保持普通 Task 并可按 Parent 选择。查询 Parent 省略表示不限、null 表示未归属、UUID 表示直接孩子；续页绑定筛选条件。Goal 状态写入不需要额外确认凭证。

读取、权限、错误和不确定写入沿用 Task 资源合同。独立 Goal 的图、子 Task 及外部 Goal 对话框支持浏览器前进和后退；项目页的图、详情及 Goal 子层也可按阅读顺序前进和后退。两类 Goal 入口打开任务链图时，图内普通成员及直接外部前置均沿用[执行计时需求](daynight-task-timing.md)的耗时、样本和阈值规则；带执行起点的任务不能导致图或页面渲染失败。时间或设置样本更新保留已打开图的浏览状态。详细事务与调度机制见[服务端设计](../design/daynight-server.md)，阅读历史、关闭和草稿行为见[任务浏览需求](daynight-task-inspection.md)。

项目 Goal 列表按 Goal 自身负责人和四态筛选、排序及每页 20 个顶层 Goal 分页。Goal 页签数字按自身负责人匹配统计所有状态的 Goal 容器，不受状态筛选或分页影响，孩子负责人不决定其是否计入；孩子进度保持完整范围。桌面同字体、等价未换行内容的 Goal 标题行与任务链标题行等高；长标题或信息换行时由内容自然撑高，窄屏保持紧凑间距和内容完整。标题行及外框按 Goal 自身状态使用[共享状态配色](daynight-web.md#任务条目状态背景)，与子任务进度无关。每个 Goal 初始收起；标题行主体以原生按钮包裹箭头、图标、标题、进行中数量、负责人、自动执行提示、任务组成、完成时间、进度及状态，点击主体或其空白只切换该 Goal 的内联内容。独立的 Goal 详情和整体图按钮在收起及展开时均可用，分别打开对应阅读器而不切换展开；关闭后焦点返回实际入口，入口失效时使用可见回退。只有真实子 Task 总数为零的 Goal 展开后显示空态；全取消的 Goal 仍展示其子 Task。内容先显示独立 Task，再显示任务链；先按完整普通依赖图分类，再取该 Goal 的直接孩子，因此跨范围链即使只剩一个成员仍是链。全部五态及较早结束的孩子均可达，不受顶层筛选或日期裁剪，不增加子项分页。范围内成员恰好出现一次，链摘要和完成进度只计算范围内成员，取消成员保留在列表但不计入完成进度；真实代表可作为链名，范围外成员与 external 前置不成为孩子。排序沿用 [Web 列表规则](daynight-web.md)的状态及精确时间规则。

标题旁显示直接普通子 Task 的“X 进行中”／“X in progress”，包括零；每个 ID 只计一次，独立 Task 与链内成员均计入，人工执行和暂停中的 `in_progress` Task 也计入。Goal 自身、其他 Goal 的孩子、未归属 Task、链外 external 前置及跨范围链的范围外成员不计入。负责人之后、任务组成之前，当任一直接孩子的 Worker claim 为 `active` 时显示采用[共享活动角色](../ui-design.md#attention-activity-health-and-policy)的状态点及“自动执行中”／“Automatic execution active”；`allowAgents` 许可、released／completed／缺失 claim 或仅 Session working 均不触发。提示表示 active claim，不表示 Agent 当前正在输出；子链的完整分量提示不用于推导 Goal 提示。数量和提示在收起与展开时均可读，文字属于展开按钮的可访问内容，装饰点对辅助技术隐藏，不新增独立操作。状态、claim 或 Parent 随已有项目快照变化时更新摘要；无变化核验保留已显示内容和阅读状态，不增加逐 Goal／Task 请求或轮询。

每个 Goal 和链独立展开；收起 Goal 卸载隐藏内容但保留该 Goal 的链展开选择，重新展开后恢复。主体、详情及整体图均可通过 Tab 到达并遵循原生按钮的 Enter／Space 语义；展开状态与内容可见性一致，收起后焦点不留在隐藏内容。子 Task、链和 Session 控件只执行自身动作，不切换父 Goal。详情、图和无变化的后台核验保留展开、焦点和滚动；真实归属、依赖或状态变化更新实际内容，已消失入口不可操作。筛选、翻页或离开导致行卸载后再次进入可恢复初始收起。链的独立图入口打开完整依赖图，Task 行打开普通详情；跨资源跳转不改变背景筛选、页码和展开，关闭后恢复原入口或可见回退。原生键盘控件、双语、长文本及窄屏遵守[任务浏览需求](daynight-task-inspection.md)和 [UI 原则](../ui-design.md)。加载失败、后台失败与空 Goal 区分，现有错误和重试保持可用，身份或权限失效撤回内容并拒绝晚到响应。

Web 的 Goal 列表提供创建入口；详情提供名称、描述、负责人和四态修改。项目页提供新建 Task 入口，表单可选择 Goal 和负责人。详情状态入口与负责人位于同一控制行，使用与 Task Detail 一致的紧凑色点菜单，显示当前语言的状态文字及箭头，不另设状态字段标签。菜单只提供 `todo`、`in_progress`、`done`、`cancelled`；已取消 Goal 仍可选择其他状态。Goal 自身、项目列表内的 Task 和链段的完成时间遵守[完成时间需求](daynight-completion-time.md)，详情独立显示 Goal 自身精确完成时间。菜单支持键盘操作，弹窗、独立页、全屏及手机宽度下保持可用。

Goal 详情在弹窗、独立页及全屏依次提供“描述 / 附件 / 讨论”三个页签，默认选择描述。子任务列表及任务链展开属于项目 Goal 列表，详情不重复列出。描述页签始终可用，以 Markdown 展示描述，空描述显示现有空态；相对附件链接和图片归属于该 Goal，并沿用附件导航。描述区域右侧的信息栏在“常规信息”首项显示当前 Goal 的完整 UUID，标为 `Goal ID`，旁边提供复制图标按钮。按钮的可访问名称和提示按当前语言为“复制 Goal ID”／“Copy Goal ID”；鼠标与键盘均可触发，复制内容逐字等于当前 Goal ID。等待剪贴板写入时禁用重复提交，成功显示“已复制”／“Copied”；拒绝或剪贴板不可用时显示“无法复制 Goal ID，请选中并手动复制。”／“Could not copy the Goal ID. Select and copy it manually.”，完整 ID 仍可选择，后续可重试。反馈不改变信息栏布局，切换资源或卸载后的晚到结果不影响新资源。复制属于阅读操作，在只读权限、Goal 各可读状态、空 Goal 和统计加载或失败时均可使用；资源不可用时继续遵守既有阅读边界。信息栏还显示 Goal 自身的创建时间、修改时间，以及直接可见普通子 Task 的独立任务数、任务链数、总数、已完成、已取消和未结束数量。日期按当前语言及浏览器本地时区显示，包含年份并精确到秒。任务分类先使用完整普通依赖图，再按 Parent 取范围；跨 Goal 的多成员链即使在当前范围只有一个成员仍计为任务链，external 边不合并普通链。进展区区分完成与取消，不把取消数量计为成功交付。桌面使用描述与信息栏两列，窄屏按阅读顺序堆叠，长描述、完整 UUID、日期和数值在 320px、390px 及桌面宽度下不产生横向溢出，ID 完整可读且复制按钮可达。统计尚未加载、零任务和读取失败须可区分；失败保留已显示统计并提供重试。

三个面板支持键盘导航，各自保持挂载；切换、全屏和后台刷新保留滚动、附件选择和讨论草稿，统计更新不重置阅读状态。普通 Task 不增加描述页签。Task 详情的概览只读展示所属 Goal，提供进入真实 Parent 的链接，不提供归属选择或保存；跨 Goal 的任务 Details 跳转在目标 Goal 下直接打开对应 Task；链外“展开”对多成员目标在目标 Goal 下直接打开完整链图，对单成员目标打开 Task 详情。两种跳转保持既有浏览器历史和草稿保护，具体展示与导航遵守[任务浏览需求](daynight-task-inspection.md)。完成或取消 Goal 前确认 Task 状态保留、后续自动领取被排除且已有领取继续；删除前确认 Goal 及其 Task 不可见、Parent 保留，执行中的 Task 在后续成功观察中开始停止。取消或 Escape 关闭确认不提交，未结束 Task 不阻止确认。非终态选择与终态确认均使用已审阅详情的精确版本；确认期间详情发生实质变化须重新审阅。

新建 Goal 和项目页新建 Task 使用一致的表单弹窗：标题与关闭按钮同排，正文和字段有清晰间距、边框、圆角、聚焦及禁用外观，底部操作靠右并可换行。桌面及手机的弹窗保持视口内安全边距；长名称、UUID 和错误不产生横向溢出，正文和恢复操作可滚动，标题、关闭及底部操作保持可达。弹窗约束焦点，Escape 仅关闭最上层并恢复入口焦点。

表单失败时保留输入并显示错误。版本冲突后应先核对当前资源再作决定；写入结果未知时只能核对当前状态，不能自动重放或把当前值当作原请求成功的证明。归属和状态变化更新实际列表与进度，并保留详情的阅读、展开和草稿状态。

## Goal 整体依赖图

每个项目 Goal 行最右侧提供独立的“查看整体依赖图”按钮，收起和展开时均可使用，不触发详情或展开控件。图一次展示全部直接成员，包括五态、独立任务和断开的多条链，不受背景筛选或分页裁剪；空 Goal 显示明确空态。成员每个出现一次。成员直接依赖的范围外可访问 Task 按 ID 去重各显示一张外部卡片，不继续加入其祖先、所在链或仅反向依赖成员的后续。只展示指向成员的真实前置边，普通依赖与 external 依赖分类保持原值；外部卡片区分成员并显示可访问的所属 Goal，无 Parent 时不虚构归属。不可访问的依赖沿用现有权限和阻塞约定，不制造节点或泄露内容。

内部和外部卡片主体均只打开对应 Task 详情，关闭详情返回同一图并保留方向、视口和阅读状态；外部卡片不跳图或展开。图支持水平与垂直、平移、缩放、适应视口、全屏及分层 Escape，方向按项目和 Goal 独立保存，默认水平。初始视口适应全部节点，不以渐进展开或静默截断缩减集合；缩放和平移用于阅读细节。图标题和状态来自 Goal，成员进度及暂停数量不包括外部前置。

后台相同数据、详情和全屏切换保留浏览状态；真实归属、依赖或状态变化更新节点与边，外部 Task 转为成员后不重复显示。首次读取失败不得显示为空 Goal；后台读取失败保留有效内容，并在图内提供错误与重试。资源删除、失权、身份变化及迟到响应沿用既有读取围栏。关闭图恢复有效原入口或同 Goal 的可见控件，再回退可见列表或页签，不主动改变筛选、分页或展开。入口、工具栏、空态和错误支持中英文与键盘，窄屏保持控件可达且页面不横向溢出。普通链图的渐进阅读、检查和外部跳转规则继续适用于链图，见[任务浏览需求](daynight-task-inspection.md)。

验收和压力验证最多使用 1,000 个去重 Task（含外部前置），并检查完整节点、布局、详情和阅读交互。该规模是验证边界，不增加产品输入限制或截断行为。
