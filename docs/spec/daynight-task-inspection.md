# 任务依赖追踪与详情阅读

一层 external 前置上下文、渐进概览、完整上游检查、独立详情与链外卡片跳转入口和平滑路线已实现。Markdown 描述、附件导航与 bundled skill 指引已实现。本文拥有行为要求；[设计](../design/daynight-task-inspection.md)拥有机制。

## 目的与适用范围

在任务图中直接查看一个任务依赖哪些前置任务，再通过 Details 入口阅读完整内容。图内卡片承担依赖追踪，默认详情使用居中浮层；标题栏的新标签入口可独立打开同一套完整详情。任务的 `description` 作为 Markdown 展示，公开 `using-daynight` skill 同步描述写法和实际附件链接。

图内卡片的选择规则适用于任务依赖画布。独立任务列表及展开后的子任务行直接打开普通 Task 详情。普通任务链代表行的展开与依赖图入口独立；typed Goal 行的展开控件单层展示全部直接孩子，独立按钮打开 Goal 详情及整体依赖图。独立任务与任务链的分类、过滤、计数和浏览偏好沿用项目任务视图规则。

图与详情严格保留必填 `externalDependsOn`。普通依赖弱连通分量提供链成员，成员直接声明的 external 前置提供一层链外上下文；
箭头虚线来自关系的外部标识，卡片虚线表示链外前置。两种角色分别计算，遵守
[外部依赖需求](daynight-external-dependencies.md)，并保留检查、Details 和布局交互。

## Markdown 图表

语言标记为 `mermaid` 的 fenced code block 支持以下 15 类稳定图表：流程图
（`flowchart`、`graph`、`flowchart-elk`）、时序图 `sequenceDiagram`、类图
`classDiagram`、状态图 `stateDiagram` / `stateDiagram-v2`、实体关系图
`erDiagram`、甘特图 `gantt`、用户旅程 `journey`、饼图 `pie`、象限图
`quadrantChart`、需求图 `requirementDiagram`、XY 图 `xychart`、块图 `block`、
数据包图 `packet`、看板 `kanban` 和事件建模 `eventmodeling`。标题、中文和英文
标签、关系及数据保持各类型的语义；默认流程图使用 Dagre，显式 `flowchart-elk`
使用内置 ELK。实验性或 beta 类型、GitGraph、ZenUML 和第三方插件不纳入支持。
同一文档可混排多张图，流程图的节点、箭头、条件分支及 TD/LR 方向保持可读；
普通 Markdown、代码块、链接及相对图片保持原有语义。

每个图块独立显示当前语言的加载状态、结果、错误和源码入口。无效语法、不支持
的类型、受限资源、配置、超限或渲染失败只影响所属图块，源码保持可检查，其他
正文和后续合法图继续可读。图块最多接受 50,000 个 UTF-16 代码单元；各类型的
节点、边、参与者、消息、任务、分组、数据点或其他结构分别受 500 项限制，
具体计数规则见[设计](../design/daynight-task-inspection.md#mermaid-图表)。
Block 的空间展开、跨度和列数在构建前受限；绘制前根据实际块层级估算的尺寸计算
调用量另以 50,000 次为上限，超限显示局部复杂度错误并保留源码。Gantt 的日期计算
另受每次读取累计 50,000 次实际日历步进限制。普通形状 metadata 和标签中的
字面量 `@{` 按语法处理；图片资源或 `imageSquare` 节点在绘制前拒绝，显示当前语言的资源不可用
提示和源码，不得阻塞后续图块。

图表采用当前浅色阅读配色，标签、关系和数据保持可辨。宽图保持可阅读的文字
尺寸，通过可聚焦的图块局部横向滚动访问；320px 窄屏下页面、阅读容器、标题和
固定操作不得被图形撑宽或遮挡。切换任务或附件、更新内容、关闭或重新打开入口
后，只显示当前内容；旧异步结果不得覆盖新图或产生重复图形，被释放的图块不得留下临时 DOM
或对象 URL。

图表内容不能执行任意脚本或注册可执行点击行为。配置指令和 frontmatter 不能
改写应用的安全设置及主题，须显示局部错误和源码。结果作为静态 SVG 图片展示，
保持原有 Markdown 的 HTML 转义与 URL 策略；该机制不承诺完整网络隔离。

## 生命周期与刷新

任务创建默认 proposed，可显式选择 todo，详情五状态读取和提交、自动执行许可、暂停解除、平台与[任务软删除](daynight-task-deletion.md)共享一个写入会话。两种详情容器的删除入口均需确认，成功后退出当前任务；独立页保留已删除状态和返回项目入口。精确 int64 版本、冲突及未知结果 GET 核对
遵守[看板要求](daynight-web.md)与[状态要求](daynight-task-status.md)。图检查不新增写请求，不把 graph projection
当作状态版本；刷新保留本文 S、选择、视口、详情和附件保证，图内选择不扩大权限。

Task 属性、状态、删除、claim 与 Steps 写入共用原操作的结果所有者。身份请求暂停时，准备阶段取消不派发写入；已派发而没有可信回执的结果保持未知，可信确认不因后续安装失败或暂停而降为未知，也不补造未取得的提交版本。本地 busy 和操作 promise 在取消或结果确定后结束，不等待暂停的展示准入。暂停期间保留已有正文和草稿，不自动读取、重试或重放；旧 404/410 不清除保留内容。恢复准入后，原操作的结果可继续发布，较新的编辑、确认层或导航选择不能被旧结果清除、重置或关闭。新写入仍须通过原有版本、权限、新鲜度和操作身份检查。

## 独立完整任务详情

`/projects/{projectId}/tasks/{taskId}` 对普通 Task 默认显示概览，对 Goal 默认显示描述；已有
`/projects/{projectId}/tasks/{taskId}/attachments/{path...}` 显示同一完整详情，默认激活
附件并选中文件。`tab=overview|description|attachments|steps|discussion|session` 进入共享导航；Goal 的 `description` 和 `overview` 均显示默认描述页签，详情只提供描述、附件和讨论，普通 Task 的 `description` 回退概览。Discussion始终存在，Session不可用时回到概览。没有选中文件的附件
页签使用任务入口加 `?tab=attachments`，已选文件切回概览时可以保留文件路径并使用
`?tab=overview`，使隐藏附件选择也能恢复。任务、页签与文件状态使用已有合法 ID、
相对路径和编码约定，无效的页签或文件路径显示不可用状态。登录后返回保留导航查询
参数；临时登录失败参数 `authError` 不进入返回目标。

完整详情共用描述、状态菜单、关系、PR、元数据、自动执行许可、执行平台和
附件上传/覆盖/下载/删除；公共头部的暂停展示与解除沿用[Web 要求](daynight-web.md#暂停展示与解除)，不随阅读页签切换消失。平台选择位于状态行，选择不同值后经过与状态、许可共用
的确认流程，显示当前值直到提交成功；概览没有单独的平台保存表单。独立页提供返回
项目与语言入口；普通模式保留页面焦点、Tab 和 Escape，不安装任务弹窗的背景 inert、
滚动锁或 iframe 键盘桥。全屏阅读按 TI16 暂时启用当前阅读容器的键盘所有权，退出后
恢复普通模式。状态/许可/平台确认与附件删除确认继续承担各自
当前层的模态规则。

普通 Task 的概览在关联信息栏首段显示“所属 Goal” / “Current Goal”。详情中的 `parentId` 非空时恰好显示一个指向同项目真实 Parent 的 Goal 概览链接；可用且类型为 Goal 的当前摘要提供标题并表示截断，否则显示真实 Parent UUID。图加载、失败或缺少摘要不隐藏该链接或编造名称。`parentId` 为 null 时只显示“未归属 Goal” / “No Goal”，详情尚未读取时沿用加载状态。链接支持键盘 Enter、普通点击和浏览器原生修饰键及中键行为，普通导航遵守草稿离开确认；目标读取失败沿用现有错误展示。刷新后的已确认详情或摘要变化须更新链接及标题。该区域只在概览出现，不提供 Parent 编辑、保存或写入；长标题及 UUID 可换行，在 320px 和 390px 下不造成横向溢出。弹窗、独立页和全屏共用这一行为。

同任务、同宿主的页签与文件导航保留详情主体、附件状态和编辑器；真正离开编辑器前沿用草稿保护，身份或资源历史失效仍隔离旧内容和操作结果。项目页与独立页阅读选择不包含业务数据、草稿或 DOM，不为旧身份或失效资源提供访问资格。项目图提供关系标题、后续任务和新鲜度，图的可见页面刷新继续触发完整
详情的重新读取，即使图投影没有变化也不能跳过。刷新等待或同内容成功不得移动焦点、
重置表单或改变标题/面板几何。账户变化等待刷新保留界面并暂停远程操作。

独立页适应整个视口，公共标题、页签与操作保持可用。概览和附件分别沿用既有正文
及分栏滚动；320px 窄屏、短横屏、长标题/描述/路径及中英文遵守相同可访问性规则。
页面登记沿用 GET/HEAD、方法限制、未知路由与现有附件路径守卫，业务接口、权限和
数据格式保持原有职责。

## 验收与规模

独立验证 50/100 临界、稳定后续优先 BFS、只遍历接纳节点、实际诱导边预算、小链位于大项目、双向 20 项直接邻居、普通多起点唯一成员、无关外部后续排除、todo/in_progress/done/cancelled 状态及无手动边上限。浏览器覆盖准确批次计数、展开锚点、重置 framing/focus、实际集合刷新连通修剪、失败保留和打开详情时不抢焦点。

API 完整读取保存的任务与依赖，不设置存储图节点或边容量复查。固定性能输入仍使用 1,000 任务及原有 999/5,000 边，每图五次；浏览器验证有界概览、全部可见诱导边与显式展开/重置，不要求所有输入同时进入 DOM。每次保留完整有序 visibility 记录、选中任务和隐藏上游数。`openMs ≤ 3000`，选择/详情/缩放/平移反馈均 ≤300ms。普通详情→关闭→立即缩放/平移后，可信选择可见任务，再执行高亮态同序列；各项取两态较慢值，网络时间独立记录，关闭与缩放间不插入重置、适应或等待。完整容量和性能验证独立于常规 CI；模块浏览器使用受控 API 验证界面行为，真实产品组合验证另行承担。原 native/container 浏览器容量入口与 combined-auth runner 已移除，其历史结果不证明当前源码；Web 独立图/几何压力测试不证明生产浏览器时延。结果须保留实际环境、源码身份与超时，覆盖率、自然失败传播及资源清理不得省略。

TI16 验收普通/全屏几何，以及 320×240 下 active 长归属内容在弹窗和独立页两种模式中的概览、附件正文实际 clientHeight、滚动及内容绘制，检查完整归属和撤回入口的键盘可达，不能只检查标题栏按钮；同时覆盖两次 Escape 与焦点恢复、图/菜单/确认的分层、同一 DOM 与 iframe/文件输入/写入会话、草稿及中间和近文末滚动保持；真实 HTML 的相对资源和计数器证明无重载，PDF 单独核对原生 reader、绘制和显式退出。覆盖独立页已加载 frame 的 owner 安装/释放、关系导航、关闭重开、前后台刷新与账户变化等待刷新，记录无法由原生 PDF document 观测的键盘边界。

TI6、TI12–TI14 验收所属 Goal 在弹窗、独立页及全屏的概览位置、无归属和摘要不可用回退、刷新、导航及草稿保护、其他页签隐藏，以及 320px 和 390px 长标题或 UUID 布局；并验收标题新标签、完整内容/操作、任务/页签/文件 URL 与历史、认证返回查询参数、项目页图、详情及其子层的连续前进后退、独立 Goal 图及子 Task/外部 Goal 的连续前进后退、关闭替换、同资源草稿保留、确认层键盘、普通前台核验和同投影详情重读，并覆盖初始/刷新错误、同任务状态及几何保留。

TI2–TI5 验收水平与垂直布局的单链、分叉、汇聚、跨层边、一层链外前置及混合卡片高度；核对多个直接 external 前置的去重、上下文祖先不进入当前 P、external 卡片进入所属 Goal 或独立任务、目标跨页/被筛选时独立打开、导航期间及关闭后的列表状态保留、连续 Goal 跳转的原入口焦点与失效回退、图 witness 消失或成为单成员时关闭及双语键盘动作；独立核对全部真实边、端点、箭头、曲线避卡片及虚线，切换保留可见集合和检查选择。TI3–TI5 验收独立复算完整 H/隐藏祖先、高亮同步、兄弟选择/详情控件、选择前后几何/视口稳定及实际曲线/paint/marker。Markdown 和 skill 验收覆盖描述到附件、分页/错误/取消、窄屏/双语、原始字符串读写、实际 npm bundle 与安装夹具。TI15 在三个阅读入口覆盖 TD/LR、中文、多图、长标签、普通形状 metadata 与字面量 `@{`、无效语法、配置拒绝、图片节点拒绝后后续图块可用、内容切换与重开；真实浏览器核对图像绘制、局部滚动与操作可用性，组件验证异步失效和资源清理。原型只证明原型行为；生产验收必须绑定被测源码。
