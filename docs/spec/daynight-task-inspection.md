# 任务依赖追踪与详情阅读

完整前置上下文、渐进概览、图局部依赖检查、独立详情入口和平滑路线已实现。Markdown 描述、附件导航与 bundled skill 指引已实现。本文拥有行为要求；[设计](../design/daynight-task-inspection.md)和[原型](../design/mockups/task-inspection/index.html)分别拥有机制与视觉。

## 目的与适用范围

在任务图中直接查看一个任务依赖哪些前置任务，再通过 Details 入口阅读完整内容。图内卡片承担依赖追踪，默认详情使用居中浮层；标题栏的新标签入口可独立打开同一套完整详情。任务的 `description` 作为 Markdown 展示，公开 `using-daynight` skill 同步描述写法和实际附件链接。

图内卡片的选择规则适用于任务依赖画布。独立任务列表、展开后的子任务行及 Goal 自身详情入口直接打开同一详情浮层；Goal 行主体仅展开列表，依赖图通过同一行的“查看依赖关系”按钮打开。独立任务与任务链的分类、过滤、计数和浏览偏好沿用项目任务视图规则。

图与详情严格保留必填 `externalDependsOn`。普通依赖弱连通分量提供链成员，沿全部依赖补齐上游上下文；
箭头虚线来自关系的外部标识，卡片虚线表示链外前置。两种角色分别计算，遵守
[外部依赖需求](daynight-external-dependencies.md)，并保留检查、Details 和布局交互。

## Markdown 流程图

语言标记为 `mermaid` 的 fenced code block 支持 Mermaid `flowchart` 与 `graph`
流程图，包括节点、连线、条件分支、中文标签和 TD/LR 方向。同一文档可以包含
多张图；普通代码块、CommonMark/GFM、链接及相对图片保持原有语义。普通形状
metadata 与标签中的字面量 `@{` 按 Mermaid 语法处理。包含图片资源或 `imageSquare`
类型的节点在绘制前被明确拒绝，显示当前语言的图片节点不可用提示和源码；这类
图块不能阻塞同文档或切换任务后的后续流程图。

每个图块独立显示加载状态和结果。无效语法、不支持的图类型或渲染失败在该图块
显示当前界面语言的明确错误，并保留可检查的原始源码；正文、普通代码块和其他
有效图块继续可读。成功图块也提供源码入口。每个图块最多接受 50,000 个 UTF-16
代码单元和 500 条连线，超过限制同样显示局部错误与源码。切换任务、附件、更新内容、关闭或
重新打开阅读入口后，只能显示当前内容；旧异步结果不得覆盖新图或产生重复图形，
被释放的图块不得留下临时 DOM 或对象 URL。

流程图采用当前浅色阅读配色，节点文字、箭头及分支标签可辨。长标签和较宽的
LR 图保持可阅读的文字尺寸，通过可聚焦的图块局部横向滚动访问完整图形；320px
窄屏下页面、阅读容器、标题与固定操作不得被图形撑宽或遮挡。

流程图内容不能执行任意脚本或注册可执行点击行为。图块不能通过 Mermaid 配置
指令或 frontmatter 改写应用选择的安全设置及主题；这类输入显示局部错误及源码。
渲染结果作为静态 SVG 图片展示，保持原有 Markdown 的 HTML 转义与 URL 策略。

## 生命周期与刷新

任务创建默认 todo，详情三状态、自动执行许可、平台与[任务软删除](daynight-task-deletion.md)共享一个写入会话。两种详情容器的删除入口均需确认，成功后退出当前任务；独立页保留已删除状态和返回项目入口。精确 int64 版本、冲突及未知结果 GET 核对
遵守[看板要求](daynight-web.md)与[三状态要求](daynight-task-status.md)。图检查不新增写请求，不把 graph projection
当作状态版本；刷新保留本文 S、选择、视口、详情和附件保证，图内选择不扩大权限。

## 独立完整任务详情

`/projects/{projectId}/tasks/{taskId}` 默认显示概览；已有
`/projects/{projectId}/tasks/{taskId}/attachments/{path...}` 显示同一完整详情，默认激活
附件并选中文件。`tab=overview|attachments` 可明确指定页签；没有选中文件的附件
页签使用任务入口加 `?tab=attachments`，已选文件切回概览时可以保留文件路径并使用
`?tab=overview`，使隐藏附件选择也能恢复。任务、页签与文件状态使用已有合法 ID、
相对路径和编码约定，无效的页签或文件路径显示不可用状态。登录后返回保留导航查询
参数；临时登录失败参数 `authError` 不进入返回目标。

完整详情共用描述、状态菜单、关系、PR、元数据、自动执行许可、执行平台和
附件上传/覆盖/下载/删除。平台选择位于状态行，选择不同值后经过与状态、许可共用
的确认流程，显示当前值直到提交成功；概览没有单独的平台保存表单。独立页提供返回
项目与语言入口；普通模式保留页面焦点、Tab 和 Escape，不安装任务弹窗的背景 inert、
滚动锁或 iframe 键盘桥。全屏阅读按 TI16 暂时启用当前阅读容器的键盘所有权，退出后
恢复普通模式。状态/许可/平台确认与附件删除确认继续承担各自
当前层的模态规则。

同任务的页签与文件导航保留详情主体和附件状态；跨任务或身份变化仍隔离旧请求和
操作结果。项目图提供关系标题、后续任务和新鲜度，图的可见页面刷新继续触发完整
详情的重新读取，即使图投影没有变化也不能跳过。刷新等待或同内容成功不得移动焦点、
重置表单或改变标题/面板几何。普通身份核验遵守当前静默前台机制。

独立页适应整个视口，公共标题、页签与操作保持可用。概览和附件分别沿用既有正文
及分栏滚动；320px 窄屏、短横屏、长标题/描述/路径及中英文遵守相同可访问性规则。
页面登记沿用 GET/HEAD、方法限制、未知路由与现有附件路径守卫，业务接口、权限和
数据格式保持原有职责。
