# Session 图片输入与草稿规格

本文定义待实现的图片输入、原生接收与草稿恢复要求。规格发布不表示功能已经可用；只有图片链路、真实 Provider 和整体验收完成后才能开放相应能力。图片显示与归档由[历史规格](session-image-history.md)拥有，容量和全部 R/A 追溯由[验收规格](session-image-acceptance.md)拥有。

开发者应能把截图和参考图作为真实图片交给编程 Agent，保留说明文字、多图顺序和可恢复草稿。输入区沿用现有文本框并增加有序图片附件区，不要求富文本编辑器、任意图文交错、轮播、图像编辑或跨设备草稿。

## 入口与既有行为

Task 详情弹窗、独立 Task 页、Test Session、Bot Session 及各自 Session 全屏对同一实际 Session 提供相同图片输入。Task 弹窗和独立页切换不得产生另一份草稿或重复发送。历史选择器及附件中的原生记录保持只读，不提供 Composer、上传、命令或来源重新采集。

上传和发送需要当前账户对目标 Session 的操作权限；只读用户仅能查看其读取权限允许的图片。Bot 使用当前真正选中的 Session，不能用显示名称或 botId 代替 Session 身份。隐藏或冷恢复的 Bot pane 不得接收其他目标的回执。

Herdr 终端输入和录像、普通任务附件、Thread、通用文件上传、网页文件工作台及任意主机文件浏览不属于图片输入。现有文本、审批、表单、斜杠命令、IME、取消及设置能力保持原有语义；图片不可用不等于文本不可用。

## 图片输入

### R1 添加、预览与编辑

- 输入区提供可聚焦的添加图片按钮，支持一次选择多张图片；粘贴剪贴板图片和将图片文件拖入输入区进入同一个草稿。普通文本粘贴、选区和输入法行为保持原有语义。
- 接受 PNG、JPEG、WebP。每条消息最多 8 张，单张最多 10 MiB，图片合计最多 20 MiB；1 MiB = 1,048,576 字节。原生模型有更小的明确限制时使用更小限制，并向用户说明实际限制。
- 验证真实字节、图片格式和可解码性。空文件、伪装格式、损坏图片和超过限制的图片不能进入可发送状态。失败应指向具体图片，保留已经接受的草稿内容；不得静默丢弃整个选择或发送剩余图片。
- 图片在输入区显示有序缩略图，可放大、移除，失败后可重试或重新选择。图片名称过长时不撑破布局，完整名称仍可访问。保留多图顺序；重新打开草稿不改变图片和说明文字的对应关系。
- 支持纯图片消息及文字加图片。发送前用户能够确认这条消息将包含哪些图片。图片不附加到斜杠命令、审批回答或表单提交；发生此类组合时保留草稿并明确提示适用操作。
- 在本次现有文本输入框上增加图片附件区即可满足输入组织要求；不要求复刻参考项目的富文本编辑器或任意文字与图片交错排版。

### R2 上传与发送状态

- 上传与消息发送是两个不同结果。图片进入草稿后可开始上传，显示逐图进度；取得服务确认且校验匹配后才算上传完成。上传本身不能启动 Agent 回合。
- 存在上传中、上传失败、缺少图片字节或失效资源的图片时，不能发送该条消息；修复或显式移除相关图片后才可发送。失败不能退化为仅发送文字。
- 上传失败保留文字和图片，提供重试。断线暂停上传与发送，保持本地编辑和预览；恢复后可继续准备图片，但不得自动重发消息。
- 发送遵守现有 Session 操作状态和原生回执。只有原生接受或确认的同一草稿版本可以清空；发送期间新增的文字或图片不能被旧回执清除。
- 发送结果未知时保留原操作身份和对应草稿，提供查询或现有恢复入口。超时、断线、刷新和重连不能导致重复的原生输入。
- 更换 Session、执行代次、账户或原生会话身份后，旧上传结果不能自动成为新目标的图片输入。权限复核没有变化时，不重置草稿或可见内容。

### R3 原生 Provider

- 图片字节必须以所选 Provider 的原生图片输入形式交付，并与本条文字和图片顺序对应；仅在提示词中写入路径、Markdown 或图片名称不满足要求。
- 当前图片支持范围为 Codex 与 Copilot，分别支持其原生允许的图片输入，并逐一验证纯图片和图文混合输入。Claude Code 不属于当前图片交付与验收范围；已有适配与保存记录继续遵循既有权限和兼容合同。模型明确不支持图片、能力未知或原生限制更小时，前端与执行端使用一致的拒绝行为，不猜测支持。
- 空闲发送和回合中的输入分别遵守原生能力。当前 Provider 不支持带图片的 steer 时，保留草稿并提示等待当前回合结束；不扩大现有队列能力，不隐式取消当前回合。
- 运行中更换模型或权限后重新核对图片资格；不能使用旧模型或旧 Session 的能力判断继续发送。

## 草稿恢复

### R7 草稿恢复

- 未发送的文字与图片草稿属于明确账户和 Session；刷新、页面离开后重开能够恢复可用草稿。不能把图片归属到仅有相同显示名称的其他会话，也不跨账户展示。
- 本地保存失败或可恢复的图片字节缺失时明确说明实际状态，提供重新选择或移除；不得声称已经保存。恢复时重新核对图片与当前发送目标的资格，旧上传凭证不能自动复用到新的目标。
- 移除图片、清空草稿和成功发送后释放不再需要的草稿资源。清理不影响已发送消息或尚有有效引用的图片。

## 身份、冻结与恢复要求

草稿归属必须包含规范化服务 origin、真实认证账户和稳定 Session 身份。发送资格还绑定当前执行：Task 的 claimId、Test/Bot 的 testExecutionId、executionGeneration、原生 Session 身份，以及当前 Provider 和有效模型能力。显示名、路径、相同 botId 或相同 native ID 均不足以授权跨目标复用。

同一目标的普通连接恢复或没有权限变化的复核不得重置草稿、预览、消息 DOM 或阅读位置。真实账户、Session、执行代次或原生身份变化后，旧上传确认不得进入新目标；对仍有访问权的原冻结操作，只能按原身份查询历史事实，不能把代次变化当作丢弃 unknown 或重发的理由。首次原生身份为 null 时，仅原唯一初始化 operation 可以绑定真实 native ID；null 不能成为任意后续 Session 的通配符。

发送必须冻结完整文字、全部有序图片及 draftId/revision。存在任意未成功准备图片、拒绝项、缺失 Blob 或持久化失败时，整条含图消息不可发送；界面不得静默排除失败项。多个标签页不得同时取得同一冻结草稿的派发权，暂停或失联标签页不能被强行接管后再次发送。缺少可靠互斥能力时禁用图片网络变更，保留可用的文本能力。

冻结持久化失败必须产生零次原生调用。请求可能派发后，刷新、重连、页面离开重开、超时、HTTP 错误、操作查询 404 或空历史均不构成未发送证明。服务接纳、排队投递、SDK 消费、本地回显和内容摘要相同也不构成原生接受。只在与原 operation、目标、有序内容及原生调用精确关联的接受证据持久确认后，才清理该冻结 draftId/revision；编辑产生的后继草稿保留，不能绕过尚未结算的冻结屏障发送。

只有可信、精确关联且证明原生未接受的结果才允许修复后由用户显式发起新 operation。确定尚未调用与已调用但确定未接受必须分开记录；通用错误码或 SDK 异常不能赋予重发资格。已经接受后发生部分附件交付失败，保留原发送事实及消息中的具体失败，停止使用有问题的能力 profile；不能把原操作降为普通未发送错误。

## 原生能力资格

图片 send 与 steer 分别判定 supported、unsupported 或 unknown，并与现有 Session 操作门禁取交集。资格同时覆盖原生 backend/model/profile、格式、字节、几何和帧数，以及上传、验证、保存、历史、读取、归档和权限。能力未知或任何必要环节未就绪时拒绝对应图片操作，保留草稿并解释原因，不以一次识图成功推断完整支持。

已证明的更小模型限制必须同时用于前端、上传完成及最终原生派发，并显示实际限制。限制须考虑原生累计历史和工具图片上下文；不能把本条图数当作完整上下文。若上下文不可观测，仅可使用已证明覆盖所有可达分支的保守限制，否则为 unknown。模型、权限或上下文变化后重新核对；旧 capability/provider revision 不得继续派发。

几何使用原始存储画布宽高、像素和完整容器帧数；静态图为一帧，EXIF 方向不能用于绕过限制。浏览器本地预览不证明全帧合格，发送资格必须依赖完整验证结果。没有已确认的几何资格时不能宣称支持图片。

Codex 与 Copilot 均需分别通过纯图、图文混合及顺序验收。现有 Claude 图片适配保持关闭未知资格，不允许图片回合中 steer、排队或隐式中断；文本补充能力保留。受支持 Provider 的图片 steer 只有真实同回合接收证据、且不存在隐式排队或取消时才能开放。初次模型未知时不得用隐式文本探测替代用户的纯图首发。

## 持久化与资源清理

草稿文字、图片字节、引用和版本须作为同一可恢复内容保存，只有持久事务整体成功才显示已保存；单项写入完成而事务失败不算保存。保存失败保留此前成功版本和当前可见编辑，并明确当前内容可能无法在刷新后恢复。恢复缺图、摘要不符、配额不足或存储不可用时提供重新选择或移除，不声称恢复完整。

图片上传进度不改变草稿正文 revision，也不更换稳定的预览身份。移除后的迟到上传结果不能复活图片。冷 Bot pane 淘汰仅释放页面连接、DOM、读取和预览 lease，不删除仍由 editable/frozen 草稿持有的持久 Blob。移除、清空和已确认发送只释放对应草稿引用；unknown、已发送消息、原生恢复或归档仍有效的引用不受草稿清理影响。

账户变化、退出或权威撤权使旧敏感预览与异步结果失效，旧磁盘值和迟到写入不得重新进入新授权实例。无法访问或删除的浏览器存储须报告真实限制，不能谎称物理删除；新账户不能读取旧账户内容。
