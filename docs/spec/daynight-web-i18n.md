# Web 英语与中文支持

状态：语言运行时与现有完整 Web 界面的英语、简体中文接入已实现，包括生产首屏、导航、项目、图、居中详情对话框、PR 分页、附件与安全提示。组件及定向生产浏览器场景已实现；功能实现不等同于完整 L1–L10 的源码绑定组合验收已经完成。

本文拥有英语 `en` 和简体中文 `zh-CN` Web 界面的行为要求。[语言机制设计](../design/daynight-web-i18n.md)解释当前基础机制及后续接入约束；[看板需求](daynight-web.md)继续拥有图、统计、详情和部署基线。交互原型的演示控制区不属于产品界面。

## 语言覆盖

完整双语界面覆盖已交付的项目列表、项目概览与任务列表导航、项目任务统计、独立任务与任务链、依赖图及全屏工具栏、任务详情、PR 引用分页、附件管理、内嵌预览与独立完整阅读页，以及相应的导航、加载、空态、错误、通知和无障碍文案。切换语言后保留正在查看的内容和浏览状态。

项目名、任务标题与描述、PR 标题与 URL、附件路径及附件正文属于用户数据，保留原值；描述按 Markdown 呈现，语言切换不翻译或改写其中的字节。描述空态、附件引用的加载、清单/路径/缺失及预览错误使用当前语言的界面消息，切换语言保留控制器、当前附件和待完成操作的身份。API 字段、状态值、请求 ID、时间戳、排序输入和文件字节保持原值。CLI、服务日志、API 协议与第三方登录提供方页面保持各自的语言行为。生产[鉴权界面](daynight-auth.md)已将登录、设备授权、项目创建、账户、成员、邀请和令牌接入同一语言机制；`AuthenticatedApp` 与原有看板共用常驻 LocaleProvider。provider discovery、用户会话失效及项目错误保留各自的本地化状态。

## 语言选择与保存

顶部导航提供可见标签为 `语言 / Language` 的选择器，选项始终使用自称 `English` 与 `简体中文`。窄屏允许导航和选择器合理换行。全屏图提供同源的选择器，使底层页面处于模态隔离时仍能切换；独立完整任务详情页在自己的标题区提供同一个选择器。任务详情继承应用当前语言，其顶栏保留任务标题、全屏、“…”菜单及关闭入口，新标签链接位于“…”菜单；当前状态菜单位于标题下的公共状态行，与平台切换相邻。所有语言入口共享同一状态，遵守现有焦点圈定、Escape 分层和关闭后的焦点恢复规则。

启动时按以下顺序确定语言：

1. 有效的显式保存值 `en` 或 `zh-CN` 优先。
2. 没有有效显式值时，按 `navigator.languages` 顺序选择第一个支持的语言族。`en` 及其地区变体映射为 `en`；`zh` 及其地区或文字变体映射为 `zh-CN`。浏览器没有提供语言列表时使用 `navigator.language`。
3. 没有支持的浏览器语言时使用英语。所有中文变体均使用简体中文，包括 `zh-TW`。

自动检测不写入显式偏好。手动选择立即生效，并在当前 origin 的 localStorage 键 `daynight.web.locale` 中保存原始字符串 `en` 或 `zh-CN`。刷新、相同 origin 的直接项目地址、跨项目访问及关闭后重新打开均读取该显式选择。语言不进入 URL、任务、项目或服务配置；现有每项目浏览偏好的键、JSON 格式和默认行为保持原样。

读取失败或已保存值无效时，使用浏览器语言规则并显示当前语言的安全提示。保存失败时保留本页已经选择的语言，明确说明重新打开可能无法恢复，并允许重试保存。任意保存成功后清除当前语言偏好错误，包括启动时产生的读取失败或无效值提示。错误保留原始原因以便诊断，页面不展示其原始正文。无显式选择时，下次启动重新解析浏览器偏好；跨标签页实时同步和账号跨设备同步不在当前保证内。

## 文案与格式

集中消息目录同时约束固定文本和带具名参数的完整句子。两个目录满足同一个 TypeScript 接口，缺少消息键、参数不符或遗漏领域消息在类型检查或测试中暴露。组件读取消息与格式化器，不散落语言分支，不拼接零散词语形成英文句子。目录按实际调用方划分为公共状态和请求 ID、语言偏好、工作空间、图、任务检查与
鉴权消息，两个语言实现相同契约。鉴权的校验、已有错误、通知、一次性秘密对话框
和正在执行的管理操作遵守相同的当前语言渲染及状态/请求保持规则。

日期、时间、数字和必要的复数规则使用显式 locale 的原生 `Intl` 接口。保留现有时区语义、24 小时制、精确字节值和排序规则。单位和计数由完整消息或格式化器组织，验证 0、1 与多项。HTML `lang`、页面标题、`title`、placeholder、按钮可访问名称、状态播报、跳转链接、分页、节点和 React Flow 控件说明随当前语言更新。

生产 `main.tsx` 在绘制正文前解析语言并设置初始 HTML `lang` 与页面标题，防止先显示整页中文再切换为英语。后续路由变化与语言切换同步更新文档信息。

API 层继续保留结构化错误类型、错误码、图规模详情与请求 ID，展示层根据当前语言生成安全文案。已经显示的网络、协议、资源不存在、图规模、附件与存储错误在切换后更新；重试继续调用原有操作。长期状态和异步回调保存结果语义，渲染时按当前语言取文案，不冻结已经翻译的字符串，也不以服务原始错误正文替代安全映射。

## 浏览状态与布局

语言只影响展示。Provider 不以 locale 作为 `key` 重建应用、项目页、图或详情；语言不进入业务请求与图结构布局的依赖。切换保留路由、项目、页签、完成项筛选、打开的图浮层、滚动、全屏、图平移和缩放、选中任务、详情、预览、附件选择、输入及正在执行的上传或删除。语言切换本身不得触发、取消或重复业务请求；项目定时刷新按自身可见性与请求生命周期独立运行。

节点保留现有尺寸与图几何规则，英文状态和工具栏文案在这些约束下可读。长用户内容遵守原有显示与访问规则。1440px 与 320px 下均保持产品视觉；320px 页面无整体横向溢出，图保留正常平移与缩放。选择器具备键盘操作和可见焦点，切换保留操作焦点，不主动关闭模态、移动滚动或重设视口；浏览器验证英文换行导致的自然高度变化仍然可用。

页签徽标继续表示完整快照中的未完成任务数：独立任务按自身状态计数；链内任务按 ID 去重。它不表示任务链条数，完成项显示开关不改变数字含义。
