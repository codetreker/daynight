# Webhook Web 管理与投递排错

## 用户结果与范围

已登录用户通过 `/webhooks` 管理个人专属或团队共享的出站 Webhook。页面提供显式归属选择、服务端搜索与分页、配置和订阅详情，以及新建、编辑、启停、删除、订阅确认、独立签名秘密读取与轮换。投递页签提供历史筛选、Delivery 与 Attempt 详情、原目标、独立载荷读取及显式重投；历史资料权限、配置管理权和发送准入分别判定。

页面保留现有工作区侧栏、页头、账号、Setup 和页面级语言选择器。宽屏并列列表与详情，窄屏可返回列表；弹窗继承当前语言，通过原生dialog提供键盘隔离、Escape关闭、入口焦点恢复和可滚动操作区。

显式选中的详情在加载、当前不存在或读取失败时仍保留返回列表入口；当前 Team 读取权限明确丧失后，错误在可见详情区表达，同时撤下私有资料，不把此状态当成未选择 endpoint。返回列表保留原显式 owner，不能自动切换到个人或默认 Team。

固定页面标题、数字徽标、新建按钮及空范围摘要沿用对应原型的样式和内部几何；数字徽标只含计数，分隔空格位于徽标之外。无订阅时配置范围显示“—”，订阅页明确显示“还没有订阅”及选择项目和事件的说明；该空集合不能被描述为无可访问项目。新建表单保持原型的 fieldset 固有最小尺寸，同时保留长项目名称、事件选择与小高度操作区的可达性。

状态筛选、Team 归属、订阅 Project 及投递事件和状态使用公共原生选择组件，保留可访问名称、焦点、鼠标和键盘操作。状态和 Team 使用 32px 筛选变体，表单使用 38px 全宽变体；箭头与文字不重叠，点击箭头区域仍操作选择框。长内容在可用宽度内截断展示，不新增横向溢出。

## 归属与读取

个人归属固定为当前账号；团队归属通过页面明确选择，不由侧栏默认团队推断。导航保留owner、teamId、endpointId和configuration/subscriptions/deliveries页签；Delivery深链还保留deliveryId，必须同时指定endpoint和deliveries页签。重复、矛盾或非法查询显示错误，不自动读取另一个归属。筛选草稿与历史页只存按当前账号、owner和endpoint隔离的内存，不放入URL。

接收端点搜索与状态筛选共同作用：全部状态不发送 `enabled`，已启用发送 `enabled=true`，已暂停发送 `enabled=false`。更改筛选时按新查询读取服务端分页，旧查询响应不能覆盖新结果。

全局入口只有当前服务和主体的catalog验证成功后才可用。未取得有效catalog的直接访问区分加载、读取失败与协议错误，并可重试；不能开始私有读取或写入。dispatchEnabled=false不禁止按当前权限浏览和收缩配置。已知配置扩展不可用时，编辑器与提交入口同时限制目的地变化、新订阅/事件扩大、范围确认和启用；名称、收缩、暂停和删除仍可按权限操作。重投另要求发送准入可用。

所有读取严格验证媒体、主体、归属、资源、完整DTO和nullable字段；正int64版本和generation以规范十进制字符串保存。历史可读资格与管理资格分别跟踪；Team成员持续由admin降为member时仍保有其Team Project读权，不能把管理降权当作资料撤权。错误、部分分页或重复cursor不冒充完整集合，背景失败保留已验证数据并可恢复。成员仅显示服务端脱敏目的地，不能沿用旧完整URL。catalog背景核验暂停新请求准入，保留已挂载页面、打开的dialog、草稿、选区、焦点、滚动与已经显示的合法资料；确认身份、权限、资源或期限变化后及时撤下对应内容。

## 配置与订阅

接收方式为HTTP，使用已支持的HTTPS目的地和adapterVersion。创建使用真实可访问项目及六类任务事件目录；不隐式订阅所有资源。创建的原提交或回执核对确认成功后，页面选中新 endpoint，并按当前归属、endpoint 和筛选读取详情；无需重新加载页面即可继续配置。确认后的刷新不能重新采用提交前的列表选择或让迟到的旧详情覆盖新路由。个人可选择当前有权访问的团队或直接共享项目，团队只选择其当前拥有项目。创建草稿中已选项目若从权威目录消失，保留仅显示原ID的可取消选项，不保留旧项目名称或归属标签，也不自动移除或重放；用户明确取消后，新提交不包含该ID，名称、目的地及事件选择保持不变。

PATCH只提交明确变更与原ifVersion。订阅保存完整数组；保留同一订阅ID和project，换项目以id:null新增。范围恢复须明确确认，不自动恢复撤销的资格。名称变化不修改目的地代次，目的地变化推进destinationRevision。

管理、秘密读取和历史资料权限相互独立。当前归属与权限代次下，已验证的秘密GET或管理写入403 forbidden立即撤下旧完整目的地、签名秘密、管理员摘要及编辑器，并刷新权威Team目录；该拒绝不证明成员失去脱敏配置或历史读取权。配置及原回执读取的已验证403按owner撤权处理，原已确认回执仍保留，unknown不转为成功或回滚。旧归属或旧权限代次的迟到拒绝不能撤销当前权限；媒体、主体或错误DTO损坏的403保留合法数据与草稿，并显示可恢复错误。

已获准管理的提交若因所选 Project 的当前资格失效而被拒绝，返回 `403 webhook_project_ineligible`；该结果不撤销归属管理权限，保留草稿、合法配置及其他管理入口。用户可调整订阅范围后明确提交新意图，不能自动重放原请求。

删除通过匹配回执或最小墓碑确认，旧名称、目标、订阅和秘密随墓碑撤下。正常配置GC在仍有Delivery行引用时保留endpoint墓碑，投递页签继续按当前历史权限只读浏览。HTTP还支持endpoint已经缺失但Delivery仍保留的历史形状：有效归属和endpoint的投递地址在配置GET返回真实404后，独立读取历史；只展示endpoint ID及历史上下文，不补配置名称、版本或capabilities。墓碑和缺失配置上下文均不能重投，历史GET自身的403/404仍按实际结果处理。单独配置404不能证明原删除成功，也不能否定独立保留历史。

已建立的授权历史上下文独立于配置GET成败：管理投影撤下后或配置已确认404后，后续配置500等非权威读取失败只显示独立配置错误，保留已有配置核验/缺失事实、Delivery/payload请求及详情交互。新权威配置观察、真实owner读权丧失、历史404、已知载荷期限或导航变更才按对应范围更新或清理；不凭配置故障恢复管理能力。

## 历史、尝试与原目标

Delivery按eventType、state、projectId、from、to筛选，Attempt可按generation筛选；limit默认50、最大100，cursor作为opaque值原样续读。时间筛选使用有效UTC Z时间，from包含、to不包含，from不得晚于to，比较遵循服务端纳秒精度。Delivery按occurredAt/id升序，Attempt按generation/number/id升序；跨页不声称共同冻结快照。改变筛选不允许旧响应覆盖新查询；同一查询刷新保留已读页数，后续页失败保留合法内容。页面明确显示historyMayBeIncomplete及载荷、元数据保留策略。

pending无尝试显示待发送，已有尝试显示待重试；leased表示处理中，不能证明HTTP已经发出。delivered、failed、suppressed分别表达接收确认、失败和停止。lastAcknowledgedAt与最新lastResult分别展示，较晚手动失败不抹掉过去确认。配置摘要使用最新保留Attempt的真实投影；最新尝试尚未结束时，null结果不能回退成较旧成功。HTTP 2xx确认不代表外部业务已经完成。

详情展示原Delivery目标与destinationRevision，不能拿当前endpoint目标替代。Attempt保留claimedAt、admittedAt、dispatchedAt、finishedAt、outcome及安全错误；未发生的时间、HTTP状态和耗时显示缺少观测，不能补0。recoveredUnknownAt与lateResult分别展示，旧执行者的晚到结果只属于原Attempt，不能覆盖新generation或推断exactly-once。

metadata_only只显示当前允许的关联、时间和结果；eventType、resourceVersion、资源名称和标识、敏感目标保持null或隐藏。目的地还可以独立收缩为target.url=null及脱敏displayUrl，同时保留获准的full事件资料与独立payload资格。较新的限制性观察覆盖这种仅URL收缩，立即更新列表、详情、载荷显示依据和当前操作投影，即使generation/configVersion不变。旧列表、详情或载荷响应不能恢复被撤下的字段；重新获权后必须通过新读取确认完整视图。payload资料拒绝保持在对应Delivery范围内。full事件的target.url=null还构成管理权收缩事实：撤下该owner旧endpoint管理投影、签名秘密、管理员缓存与Admin标签，独立可读成员资格继续保留允许的Delivery及已显示payload。不能将管理权收缩解释成整个owner或Project资料撤权；配置核验中的ID-only上下文与配置真实404后的保留历史上下文分别显示，不补名称、版本或capabilities。

## 独立载荷与期限

仅用户明确打开载荷时请求独立payload GET。响应仍为application/json包装；核验owner、endpointId、deliveryId、已观察eventId、mediaType=application/cloudevents+json、encoding=base64、规范Base64、精确bytes、最多65,536字节、SHA-256与有效UTF-8后才显示。合法边界保留原字节，错误和超界明确失败，不截断。展示使用安全文本节点，不执行HTML或脚本，不从当前Task或endpoint重建历史。

载荷资格由当前资源授权与原保留期限决定：task.deleted锚定原Project，其余五类要求父Task仍可读；Steps本身删除不阻断可读父Task对应的历史。403、410 payload_expired与404当前历史不可用分别显示。同一scope所选Delivery的详情、Attempt或payload GET返回已验证的404时，撤下该Delivery详情、已显示载荷、重投确认与控制器当前投影，保留原已确认回执；此前开始的详情或列表响应不能恢复它。配置GET404仍按独立保留历史上下文处理。确认失权、已知payloadExpiresAt到期或权威读取确认历史不可用时，撤下对应字节或私有详情；跨已知载荷期限迟到的响应不能重新展示正文。元数据保留取决于服务端活动、Attempt及保留状态，不能由occurredAt加固定秒数推算历史删除时间；在页面准入可用且投递页签可见时保持GET核验：所选pending/leased每两秒读取，终态详情及未选择详情的列表每30秒读取；focus/visibility也触发核验，以实际结果撤回。404不能证明事件从未发生，客户端撤回不声称已经执行数据库物理GC。

## 写入、重投与未知结果

一次提交固定服务、主体、归属、操作种类、目标、版本、operationId、原issuedAt、最终UTF-8请求字节及SHA-256。重复按钮或Enter不能产生第二个意图。原回执核对期间不能把新的提交静默丢弃或返回旧结果，应明确阻止写入并保留草稿。确定拒绝保留草稿；冲突要求新的明确决定，不自动取最新版本重放。查看当前版本不得把未修改的字段变成修改意图；双方改动的字段必须明确解决后才可提交，名称修改不能回写他人新目的地。

重投使用delivery.redeliver和原endpoint/Delivery、已观察ifVersion/ifGeneration与原目标revision。提交前固定已验证的owner、endpointId、deliveryId、ifVersion、ifGeneration及destinationRevision；在operationId生成前、认证准入恢复后和实际fetch前，按同一个原目标重新核验当前资格。切换到另一条可重投Delivery不能代替原意图的准入。当前管理能力、启用状态、发送准入、full资料、原目标、载荷期限、lease和手动次数共同限制入口，服务端裁决实际准入。202只确认原operation与新generation已经登记，后续GET读取实际尝试；不能显示发送完成。manualOperationCount只在首次接受原意图时增加一次。原eventId、occurredAt、body、目标和历史Attempt保持，自动最多10次/原72小时，手动最多3次/原7天；成功关闭剩余自动计划，失败只恢复原尚有效计划，不开启新的72小时周期。busy、版本/代次冲突、目标变化、停止、过期、维护拒绝及提交未知分别可辨。

已派发后传输失败、取消、损坏响应和可能已经提交的服务错误保留unknown状态；准备期间尚未派发的取消按本地拒绝结束，不推断服务器回滚。停止原操作时结束其等待，保留已经可信确认的回执；意图收尾在暂停期间不自动核对或启动后续读取，迟到结果不能影响新的操作或撤下已展示内容。恢复只GET原回执与当前资源，不自动重发。确认必须匹配原身份、时间、hash、种类、endpoint/Delivery和版本关系；当前字段相等、404、403或过期均不能证明成功或回滚。历史回执与当前资源分别表达；原generationAfter可以小于当前generation。首次已确认的回执保持其原效果；后续矛盾的服务端结果字段报告协议错误并保留原回执。当前资源读取或解析失败单独显示，不能把原确认改成回滚。

sessionStorage仅保存按服务、主体和归属隔离的最小操作元数据，不保存URL、正文、认证、秘密或载荷。重载缺少原body后只允许GET核对。存储失败明确说明跨重载恢复不可确认，仍支持当前文档的明确提交、原ID和GET核对，不把不可读记录当作已经回滚或清理；登出、身份失效与账号变化清理私有状态，清理存储失败不能阻止身份隔离，并须显示失败和重试。

签名秘密独立读取，普通列表、配置、回执和错误不含secret。离开秘密区域、轮换、降权或身份变化撤下旧明文。原轮换回执包含原keyId和nullable overlapUntil，不能从当前秘密推断原结果，也不自动读取新秘密。

## 验证

真实业务效果通过生产HTTP模块、认证和隔离PostgreSQL读回；接收与签名结果使用真实发送器及受控HTTPS接收方。验证固定意图、CAS、未知恢复、身份与独立资料权限变化、大版本、分页、原字节、重投计划及失效范围；网络故障只转发和损坏真实响应，不合成业务成功。客户端逻辑期限和只读撤回独立验证，完整应用生命周期与物理GC按各自实现验收。

Go 模块测试通过 DAO mock 验证来源锁后仍为 Team admin、Project 资格失效时不写入效果或回执，以及独立 HTTP 错误码映射。Web 模块测试用可控响应验证新建和订阅草稿、未变化的管理员目录与完整 URL 读取；权威团队项目目录刷新移除已选项目后仍可显式取消或换选，新提交省略旧ID并使用新operationId，且没有自动重放。真正管理拒绝仍在目录恢复前清除私有资料。

视觉验证在固定浏览器、字体、语言、dpr和viewport下比较Webhook内容区及dialog的完整computed-style、局部geometry和像素；单独验证生产shell并保留未裁剪截图及外层差异。320、390、768、1280、1440宽度和小高度均验证溢出、键盘与可见footer。背景请求barrier证明节点、草稿、选区、焦点、页签和加载页在权限未变时始终保持；并发限制和跨载荷期限迟到响应验证旧私有内容不会恢复。原型只作任务附件中的视觉输入，不进入产品或永久测试。

选择字段在真实生产页面以受控 API 响应验证中英文、桌面与窄屏几何、原生选择操作、归属隔离及筛选请求时序。投递筛选保留草稿，只有应用后才改变查询；订阅选择不自动提交。
