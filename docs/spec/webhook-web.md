# Webhook Web 配置管理

## 用户结果与范围

已登录用户通过 `/webhooks` 管理个人专属或团队共享的出站 Webhook。页面提供显式归属选择、服务端搜索与分页、配置和订阅详情，以及新建、编辑、启停、删除、订阅确认、独立签名秘密读取与轮换。投递诊断、载荷和重投使用独立的资料权限与代次规则，不混入配置权限。

页面保留现有工作区侧栏、页头、账号、Setup 和页面级语言选择器。宽屏并列列表与详情，窄屏可返回列表；弹窗继承当前语言，通过原生dialog提供键盘隔离、Escape关闭、入口焦点恢复和可滚动操作区。

## 归属与读取

个人归属固定为当前账号；团队归属通过页面明确选择，不由侧栏默认团队推断。导航保留owner、teamId、endpointId和页签；重复、矛盾或非法查询显示错误，不自动读取另一个归属。

全局入口只有当前服务和主体的catalog验证成功后才可用。未取得有效catalog的直接访问区分加载、读取失败与协议错误，并可重试；不能开始私有读取或写入。dispatchEnabled=false不禁止按当前权限浏览和收缩配置。

所有读取严格验证媒体、主体、归属、资源、完整DTO和nullable字段；正int64版本以规范十进制字符串保存。错误、部分分页或重复cursor不冒充完整集合，背景失败保留已验证数据并可恢复。成员仅显示服务端脱敏目的地，不能沿用旧完整URL。

## 配置与订阅

接收方式为HTTP，使用已支持的HTTPS目的地和adapterVersion。创建使用真实可访问项目及六类任务事件目录；不隐式订阅所有资源。个人可选择当前有权访问的团队或直接共享项目，团队只选择其当前拥有项目。

PATCH只提交明确变更与原ifVersion。订阅保存完整数组；保留同一订阅ID和project，换项目以id:null新增。范围恢复须明确确认，不自动恢复撤销的资格。名称变化不修改目的地代次，目的地变化推进destinationRevision。

管理、秘密读取和历史资料权限相互独立。删除通过匹配回执或最小墓碑确认，旧名称、目标、订阅和秘密随墓碑撤下。单独404不能证明原删除成功。

## 写入、未知结果与隐私

一次提交固定服务、主体、归属、操作种类、目标、版本、operationId、原issuedAt、最终UTF-8请求字节及SHA-256。重复按钮或Enter不能产生第二个意图。确定拒绝保留草稿；冲突要求新的明确决定，不自动取最新版本重放。查看当前版本不得把未修改的字段变成修改意图；双方改动的字段必须明确解决后才可提交，名称修改不能回写他人新目的地。

传输失败、取消、损坏响应和可能已经提交的服务错误保留unknown状态。恢复只GET原回执与当前资源，不自动重发。确认必须匹配原身份、时间、hash、种类和目标；当前字段相等、404、403或过期均不能证明成功或回滚。历史回执与当前配置分别表达。首次已确认的回执保持其原效果；后续矛盾的服务端结果字段报告协议错误，保留已知原回执和原密钥截止。

sessionStorage仅保存按服务、主体和归属隔离的最小操作元数据，不保存URL、正文、认证、秘密或载荷。重载缺少原body后只允许GET核对。存储失败明确说明跨重载恢复不可确认，仍支持当前文档的明确提交、原ID和GET核对，不把不可读记录当作已经回滚或清理；登出、身份失效与账号变化清理私有状态，清理存储失败不能阻止身份隔离，并须显示失败和重试。

签名秘密独立读取，普通列表、配置、回执和错误不含secret。离开秘密区域、轮换、降权或身份变化撤下旧明文。原轮换回执包含原keyId和nullable overlapUntil，不能从当前秘密推断原结果，也不自动读取新秘密。

## 验证

真实业务效果通过生产HTTP模块、认证和隔离PostgreSQL读回。验证固定意图、CAS、未知恢复、身份与权限变化、大版本、分页与失效范围；网络故障只转发和损坏真实响应，不合成业务成功。

视觉验证在固定浏览器、字体、语言、dpr和viewport下比较Webhook内容区及dialog的完整computed-style、局部geometry和像素；单独验证生产shell并保留未裁剪截图及外层差异。320、390、768、1280、1440宽度和小高度均验证溢出、键盘与可见footer。背景请求barrier证明节点、草稿、选区、焦点、页签和加载页在权限未变时始终保持。原型只作任务附件中的视觉输入，不进入产品或永久测试。
