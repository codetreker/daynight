# 助手列表、创建、详情与删除

## 范围

`/bots` 和 `/bots/{botId}` 提供当前账号的助手列表、搜索、创建、会话选择、详情和删除。助手不绑定项目，普通目录可作为运行目录。页面复用[共享助手会话](bot-session-view.md)，不能以页面打开、切换或关闭作为停止、重启或删除原生执行的指令。

正式导航入口在完整助手组合前保持关闭，页面不显示未实现的设置或操作。

## 创建

正常创建只要求名字，去除首尾空白后为 1–40 个 Unicode 字符，拒绝控制字符。Worker、目录和 Agent 在默认折叠的高级设置中，初值来自服务端 defaults。表单未修改的初值不得成为显式覆盖；仅提交用户明确干预的字段。切换 Worker 后清除目录及 Agent 的显式选择，并重新获取该 Worker 的默认值，迟到的旧响应不能覆盖当前选择。

目录允许普通绝对路径，不要求项目或 Git。无可用 Worker、离线、不支持托管、观测过期和 Provider 不可用分别显示实际原因；不可用的明确选择不得自动换机。修正目录或选择可用 Provider 后，可以提交给服务端重新解析。取消表单不创建、不保存偏好。偏好只由服务端在真实启动确认后保存。

提交前生成 Bot ID。已发出但未确认的创建保留该 ID，后续只读取同一个 Bot，不以重新 POST 或新 ID 求证。关闭弹窗、离开再回到页面仍保留核对入口；可用的 `sessionStorage` 允许重载后继续核对。存储不可用时只保证当前文档内保留，界面显示 ID 供用户保留。404 不等于原请求永远未提交，仍维持未确认状态。已确认的拒绝允许修改后新建请求。

成功响应代表定义已受理。`pending` 显示正在启动，`failed` 显示启动错误；只有服务端确认的 `ready` 显示已启动，不能宣称当前在线或成功保存偏好。

## 列表与会话

搜索覆盖已完整读取的当前账号列表。读取所有分页后原子更新，翻页失败、重复 cursor 和协议错误不能成为空列表。刷新失败保留旧列表并标明错误。Worker 状态采用服务端独立 defaults 观测；该读取失败或认证暂停时不可继续宣称可用。

选中助手必须通过当前目标的权威详情读取，未知或失败时不准入旧目标输入。切换期间保持共享 SessionHost 和有界缓存；关闭对话返回列表，重新选择同一个助手恢复缓存。删除责任、403、404 或 410 清除该 Bot 的历史缓存；账号失效清除本页私有内容和未确认创建身份。普通瞬时读取失败保持可重试，不伪装成删除。

桌面列表与对话并列；窄屏选择对话后提供返回列表入口。创建使用原生模态对话框，支持键盘打开、提交、Escape 关闭及返回入口焦点。提交期间防止重复操作。中英文切换不清除表单或未确认请求。

长列表和长会话在各自区域内滚动，不能撑高页面并把输入框推离可用视口。切换助手后恢复时间线阅读位置和草稿；未主动滚动时，历史分页只按真实可见区域补齐内容，不因页面随历史增长而读完整个归档。

## 删除与结果核对

列表每行提供更多菜单、右键和键盘菜单入口，窄屏通过同一列表操作。确认框明确显示目标名称及对话历史清理范围；取消与关闭对话不发删除请求，不改变当前选择。键盘取消返回原菜单按钮。目标身份固定于打开确认框的行，不随当前对话切换。

确认后立即禁止目标发送并撤下其历史，保留草稿与原操作身份直到权威结果确认。DELETE 使用原 `ifVersion` 和 `deletionId`，响应身份必须一致。任何提交失败先查询原 Bot；传输、解析和响应未知后即使 GET 暂时返回未删除，也不能证明在途删除永远不会提交，因此继续禁发。明确拒绝后只有权威读取仍为未删除才恢复使用；再次删除需要用户重新确认。未知和失败状态允许核对，显式重试先查询并沿用同一删除请求，不自动重新提交。

只要权威状态包含删除责任，就不可逆地清除目标已挂载、已淘汰及可访问的浏览器草稿、回执、显示和阅读状态，拒绝迟到列表、详情、消息和资源重新展示历史。即使用户已离开助手页，随后收到的权威删除结果仍须清除目标存储，不得等到再次打开页面。另一助手及 Task 内容保持。两个清理阶段都 completed 才显示完成；pending、failed 与结果未知分别显示，403/404/410 仅证明不可访问，不证明清理完成。页面可见且身份有效时自动核对未决状态。

原请求及最小删除状态在同账号范围跨导航保留；可用的 sessionStorage 支持重载后继续核对，失败时只保证同文档内存保留。退出、切账户或身份失效清除该账号删除记录。浏览器无法证明不可达页面、无法删除的存储或用户导出副本已物理清空。

## 详情与全屏

当前助手名称是详情入口，默认收起。面板只显示当前助手名称、启动及 Worker 观测状态、托管 Worker、冻结工作目录和 Agent。`ready` 仍只表示已启动；离线、不可用或读取失效不能显示为已确认在线。Worker 名称不可读时保留绑定 Worker ID，不能猜测机器或取另一助手的配置。

切换助手时保留展开意图，标题、详情和 Session 绑定消费同一目标的权威读取。新目标尚未返回时详情只显示局部加载，不能保留旧助手名称或配置；权威拒绝访问、删除、离开对话或失去读取准入时收起面板。

宽度大于 1000px 时，详情在对话右侧作为非模态区域显示；不超过 1000px 时使用原生模态抽屉。名称和关闭按钮均可键盘操作，打开后焦点进入面板，显式关闭返回仍可用的当前名称入口。抽屉内 Tab 由模态层限制；Escape 一次只关闭当前详情层，不能同时退出 Session 全屏。关闭或跨断点调整必须释放本层滚动锁与模态状态，不留背景不可交互状态。

Session 全屏包含助手名称和详情区域，面板在全屏中仍可打开、关闭。详情开关、断点变化和全屏仅改变布局，不重建 Session client、连接或关键 DOM，不刷新或重放对话。桌面开关侧栏造成的宽度变化沿用共享时间线的文字阅读锚点与跟随意图。普通 Task/Test Session 的独立全屏行为保持原有规则。

Webhook、MCP 的未来设置归属详情区域；当前不显示空设置页、配置开关或接入框架。

## 验证

API 测试覆盖身份、字段、版本和未知创建/删除提交；DOM 测试覆盖默认值竞态、显式选择、失败与分页、目标切换、认证失效及原 ID 保留、删除前后反序读取、失败清理和定向失效。真实浏览器在桌面和 390px 检查键盘、布局和管理请求，包括详情切换同源、开关前后实际 Session DOM 身份及阅读锚点、全屏与抽屉的 Escape/Tab 层级、返回焦点和断点变化后的模态清理。受控 HTTP 与 Session 证据只证明 Web 消费行为，真实 Worker、Provider、偏好持久化和完整助手组合另行验收。
