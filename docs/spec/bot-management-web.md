# 助手列表、创建、详情与删除

## 范围

`/bots` 和 `/bots/{botId}` 提供当前账号的助手列表、搜索、创建、会话选择、详情和删除。助手不绑定项目，普通目录可作为运行目录。页面复用[共享助手会话](bot-session-view.md)，不能以页面打开、切换或关闭作为停止、重启或删除原生执行的指令。

正式导航提供助手入口，与现有项目、Worker 和独立 Test 并列；页面不显示未实现的设置或操作。

## 工作区与单栏切换

助手页占满应用工作区，不再附加页面级居中最大宽度限制或大块外侧留白。沿用全局导航的展开/折叠偏好、Team、账号入口和原有路由；助手页的布局不改变其他页面。

桌面助手列表宽度为 256px。按扣除实际导航、外侧间隔和内容内边距后的可用宽度决定列表与会话是否并列：能同时容纳列表、间距和可用会话宽度时并列，否则只显示列表或当前对话。单栏选中助手进入对话，顶部返回入口关闭当前阅读选择并回到列表；关闭不停止或删除助手。恢复足够宽度后重新并列，搜索、已加载列表、Session 缓存、草稿和阅读位置不因宽度或导航变化被重建或清空，也不启动、停止、切换 Agent 或发送消息。

列表、消息和详情在各自区域内滚动，不能撑高页面并把输入操作推离可见视口。矮屏中创建、高级项、详情关闭及输入操作仍可通过各自区域到达。切换助手后恢复时间线阅读位置和草稿；未主动滚动时，历史分页只按真实可见区域补齐内容，不因页面随历史增长而读完整个归档。正文与输入的排版和能力约束由[共享助手会话](bot-session-view.md)规定。

## 创建

列表标题旁提供创建入口，打开最大宽度 492px 的轻量模态弹窗，不挤占列表或当前会话。默认只显示名称、实际 Worker/Agent/默认配置摘要、调整设置和操作按钮。打开后聚焦名称；已有未确认请求时聚焦核对入口。摘要可用键盘展开完整主机、路径、有效模型、effort 及来源，不能只靠 hover 读取长内容。

正常创建只要求名字，去除首尾空白后为 1–40 个 Unicode 字符，拒绝控制字符和非良构 Unicode。Worker、目录、Agent、Model 与 Reasoning effort 默认折叠；仅输入名字时请求只含 id/name。查看预览、展开设置和取消菜单不得产生显式覆盖。使用默认删除对应覆盖；恢复全部默认同时解除明确 Worker。默认表示不覆写，有效值及其成功偏好、本地、云端、原生或未知来源保持区别，不能将本地配置误称原生默认，也不能猜测默认 effort。

首次默认读取保留名称编辑，取得可用配置前禁止提交；后台读取不增加多余状态行，不清空草稿或重建表单。中英文切换、认证暂停与布局变化保留名字和已选设置；准入暂停时本地输入仍可编辑，禁止提交和新的机器操作。实际错误有准确原因及恢复入口，重试不丢失输入。不可用 Worker、离线、不支持托管、观测过期和 Provider 不可用分别表达；显式目标不可用不得自动换机。修正目录或选择可用 Provider 后，可以由服务端重新解析。

明确选择依赖机器的目录、Agent、Model 或 effort 时绑定当前解析到的 Worker。切换 Worker 清除旧机器的 cwd、Agent、Model、effort 覆盖并重读默认；切换 Agent 保留目录，清除 Model 和 effort；切换 Model 清除旧表单 effort，再按当前模型解析默认。失效成功偏好可按服务端规则回退；当前 Worker 明确 effort 不兼容时仍须显示错误，不能把它丢弃后冒称使用默认。迟到响应不能覆盖新目标。

Model 与 effort 选项来自目标 Worker 的真实原生能力，在需要调整时读取，不能用静态枚举填充未知或不支持的列表。分页结果保持同一 Worker、Provider、连接、配置及目录快照身份；读取失败、未知默认和不兼容选择保持真实含义。有效默认及成功偏好以服务端 Bot defaults 为准。仅当服务端明确委托原生且值为 null 时，成功的同目标能力结果可补充已观察的默认模型与对应 effort 摘要及选项；能力结果不得替换明确选择或服务端已解析的值。隐藏的默认模型也可提供真实 effort 能力，但不作为新模型选择项展示。只明确选择 effort 时绑定 Worker，请求不附带 model；仅查看已发现默认仍不产生覆盖。未知默认、选择错误和迟到结果不能补成已确认默认，不借用其它模型的默认 effort。桌面 Model 与 effort 并列，窄屏单列；单项恢复默认与全部恢复默认均不修改运行中的助手。

Browse 在同一个弹窗内切换到绑定 Worker 的只读目录视图，保留原表单草稿。起点为显式目录或已解析有效默认 cwd，显示目标机器、当前路径、上一级、默认目录、当前层已加载条目筛选、隐藏目录开关及分页。父路径和子目录路径由 Worker 返回，浏览器不得拼接 HOME 或按本机平台解释远端路径。身份暂停时路径及筛选文本仍可编辑和复制，不能读取或确认远程目录。目录单击仅导航，默认目录按钮仅导航，只有确认目录才写回并绑定 Worker；取消、Escape 和浏览页关闭先返回表单，焦点恢复到 Browse。

浏览能力不支持时说明原因并保留默认目录和手动绝对路径；离线、权限拒绝、路径不存在及超时不能伪装空目录。取消、换 Worker 和账号失效后丢弃旧请求及迟到响应。浏览不读取文件内容、不创建目录、不启动助手；真实启动前仍须核验目标目录，不把浏览成功当作未来启动保证。工作目录不要求项目或 Git。

Worker、Agent、Model 与 effort 使用统一的原生选择外观；窄屏或粗指针下选择控件至少 44px 高、16px 字号。长选项保留完整文本，不能造成横向溢出。打开原生选项菜单时，Escape 先取消菜单，不能关闭弹窗或丢弃草稿。

弹窗跟随可见视口限制高度，标题和操作区可达，中间内容独立滚动；窄屏左右至少 12px，粗指针控件目标至少 44px，输入字号至少 16px。键盘可打开、提交和取消；IME 组合不得触发提交或关闭，Escape 只处理当前视图。取消后恢复仍可用的创建入口焦点；提交期间防重复操作，明确失败显示原因并保留输入。取消不创建、不保存偏好，偏好只由服务端在真实启动确认后保存。弹窗开关及子视图切换不改变已打开助手 Session 的实例、草稿、阅读位置或生命周期。

提交前生成 Bot ID。已发出但未确认的创建保留该 ID，后续只读取同一个 Bot，不以重新 POST 或新 ID 求证。关闭弹窗、离开再回到页面仍保留核对入口；可用的 `sessionStorage` 允许重载后继续核对。存储不可用时只保证当前文档内保留，界面显示 ID 供用户保留。404 不等于原请求永远未提交，仍维持未确认状态。已确认的拒绝允许修改后新建请求。创建或核对取得可信结果后，本地等待状态立即结束；身份准入恢复前保留结果和草稿，不自动核对或重发。恢复后可显式打开已确认助手，旧结果不能关闭或覆盖提交后修改的草稿。

成功响应代表定义已受理。`pending` 显示正在启动，`failed` 显示启动错误；只有服务端确认的 `ready` 显示已启动，不能宣称当前在线或成功保存偏好。

## 列表与会话

列表标题与创建入口同行，名称搜索下直接展示列表；刷新位于列表小标题同行，以按钮 busy/disabled 表达进行中，真实失败仍可见。列表按服务返回的稳定顺序展示，不新增置顶、消息摘要或最近活动排序。行内保留头像标记、名称、需要关注的数量和必要状态，Worker 主机名、目录与诊断细节在详情读取；离线或错误助手仍可选中查看原因。零助手提供创建入口，搜索无匹配单独表达，不能混为零助手。

搜索覆盖已完整读取的当前账号列表。读取所有分页后原子更新，翻页失败、重复 cursor 和协议错误不能成为空列表。刷新失败保留旧列表并标明错误。Worker 状态采用服务端独立 defaults 观测；该读取实际失败时不可继续宣称可用；临时认证检查保留已显示的观测。

选中助手立即更新选择和目标标题；显示与新操作准入分离。当前账号确认后，优先恢复目标自己的驻留 pane，其次读取该账号的本地近期显示快照，只有两者均未命中才显示稳定骨架和不可提交的输入占位。刷新、重新打开和 pane 淘汰后的快照读取不等待本次权威详情或 Session channel；账号未确认时不能展示历史。驻留三席连接与本地六份近期快照是不同上限，完整的尺寸、恢复、资源和失效要求见[共享助手会话](bot-session-view.md#切换与缓存)。

新操作必须通过当前选择代次的权威详情复核，并与真实 Session 身份、能力、生命周期及未决操作门禁合取；缓存可读不能开放操作。回切复核期间保留原 pane、草稿编辑、菜单、审批本地填写和阅读，仅限制远端提交。同一已确认选择的普通轮询保留原准入位，不因 busy 关闭或擅自开放；账户变化时 auth pause 停止新的业务请求、发布和发送，真实刷新前不自动读取或恢复。详情失败或解析失败关闭新操作准入，当前有效重试成功后再按原门禁恢复。

后台检查和恢复读取的全过程保持已显示的列表、目标详情、Session DOM、草稿、菜单、全屏与阅读位置；已有内容的普通失败局部显示实际错误与重试，不隐藏整个 Session 区域。完全无缓存的失败保留标题、返回及实际可用的重试，不能无限骨架，也不伪造网络超时。关闭对话返回列表，重新选择同一助手按缓存层级恢复；正常离开不清除已保存的显示快照。

连续 A→B→C 只允许当前目标结果影响前台；迟到 B 响应最多更新 B 自己仍有效的缓存，不抢回选择、焦点或覆盖 C，不复活已淘汰、撤权或删除的目标。删除责任、403/404/410、账号失效按原规则立即清除对应驻留与本地历史，撤销已排定写入并阻止跨标签迟到写回；权威详情确认绑定变化或明确无 Session 时撤下旧快照。账号失效同时清除本页私有内容与未确认创建身份，普通网络失败不冒充删除。

## 关注标记

列表行的计数表示该助手有多少需要用户关注的事项，不是逐条聊天消息的未读数。新异常报告、升级、直接处理结果未知、助手间提问无回应、认领被接手或失效的事件在尚未看到时计入；直接处理成功、附录新增、事项已解决和定时触发不计入。事件是否投递与用户是否看到相互独立。

该助手当前负责任务中每个待决定的手册修订提案额外计入一次，不重复计算提案通知。打开对话不能清除提案；只有提案决定或不再属于该助手负责的任务后，才从该助手计数中移除。任务暂停或认领过期不代替用户决定，删除的助手任务不再计入。

用户打开助手对话即将该助手当前需要关注的普通事件标为已看到。列表后台轮询、搜索、读取详情或隐藏的缓存会话不等于打开对话；打开操作必须遵守当前账号身份、目标确认及删除屏障。清除后重新读取权威计数，不在浏览器直接归零；失败保留已显示计数并提供实际错误及重新核对入口；核对只重新读取计数，不自动重放未知结果。首次确认计数为零也完成本次打开的已看到处理，后续轮询不能将新到报告自动标为已看到。关闭后重新打开对话才发起新的已看到请求。新事件由后续读取反映。

零计数不显示徽标；正数徽标使用可访问名称说明需要关注的数量，不只依赖颜色。计数不改变列表排序，也不挤出名称和原有操作。

## 统一标题与状态

助手标题与共享 Session 工具栏组成一个标题区，显示当前名称、Agent 和真实 Session 连接状态，提供显示、专注、详情和更多操作。单栏顶部保留返回列表入口，窄屏无需重复专注按钮，关闭对话仍可从更多操作到达。原有错误、审批、取消和能力控制必须在组合后的界面可达，不能通过隐藏重复标题一并隐藏其唯一入口。

目标名称只来自同账号 scope 下该目标自己的已认证列表或详情，可在本次详情返回前显示；没有可信名称的深链使用中性的“助手”，局部表达加载，不借用前一助手名称、状态或正文。名称可单行省略，完整名称在详情中可读取，不依赖鼠标悬停。返回、显示、详情、更多与展开标记不能被长名挤出或相互重叠。长名称、不可分割标识符、主机名、目录和状态原因在详情或对应异常区域允许断行；不能横向溢出或通过裁切隐藏业务错误。图标控件有可访问名称，hover 说明同样可通过键盘 focus 读取；窄屏关键触控区域至少 44px，焦点可见，并尊重 reduced-motion。

各层状态分别消费其真实来源，不用一种“在线/离线”概括所有结果：

| 信息 | 位置与要求 |
| --- | --- |
| Bot 启动阶段 | 列表简要状态与详情；`pending` 为启动中，`failed` 为启动失败，`ready` 仅为已启动，不证明当前连接、可发送或偏好已保存 |
| Worker 可用性 | 详情，影响当前使用时在会话内提示；分别表达在线、离线、过期或未知，读取失败不得继续宣称可用 |
| Session 连接与同步 | 统一标题内的状态行；连接中、同步中、已连接和断开依真实会话状态显示，发送仍受真实能力准入 |
| Session 启动与恢复 | 异常区域与详情显示启动报告未知、明确失败或恢复受阻，不归入 Bot 启动结果 |
| 本地历史预览 | 低干扰标明“上次保存的对话”；不据旧快照宣称当前连接、模型、能力或活动，不显示缓存 Working 或继续旧计时，接上实时内容后撤去已复核范围的预览提示 |
| Agent 活动与命令结果 | 原生活动和操作附近显示执行、等待输入、审批，以及 pending、明确失败、结果未知及对应操作，不从连接颜色推断 |
| 删除、撤权和账号状态 | 按相应准入及清理规则显示替代状态；身份验证暂停、归档只读和恢复受阻不能笼统显示为离线 |

正常状态不重复说明，异常靠近受影响的动作。数据读取失败保留仍可安全显示的旧内容并标明失效或过期；历史分页失败不抹空会话。账户变化等待刷新保留已确认的观测和界面，同时暂停新的业务请求。

## 删除与结果核对

列表每行提供更多菜单、右键和键盘菜单入口，窄屏通过同一列表操作。确认框明确显示目标名称及对话历史清理范围；取消与关闭对话不发删除请求，不改变当前选择。键盘取消返回仍可用的原列表菜单按钮或详情删除入口。目标身份固定于打开确认框时该入口所属的 Bot，不随当前对话切换。后台检查不关闭确认框或改变目标；确认删除仍须通过当前准入。

确认后立即禁止目标发送并撤下其历史，保留草稿与原操作身份直到权威结果确认。DELETE 使用原 `ifVersion` 和 `deletionId`，响应身份必须一致。提交失败且身份准入仍有效时查询原 Bot；暂停期间不自动查询或重新提交。准备阶段被暂停取消且尚未派发时结束原操作并解除其屏障；已派发的传输、解析和响应未知后即使 GET 暂时返回未删除，也不能证明在途删除永远不会提交，因此继续禁发。明确拒绝后只有权威读取仍为未删除才恢复使用；再次删除需要用户重新确认。未知和失败状态允许核对，显式重试先查询并沿用同一删除请求，不自动重新提交。

只要权威状态包含删除责任，就不可逆地清除目标已挂载、已淘汰及可访问的浏览器草稿、回执、持久显示快照、显示和阅读状态，拒绝迟到列表、详情、消息和资源重新展示历史。即使用户已离开助手页，随后收到的权威删除结果仍须清除目标存储，不得等到再次打开页面。另一助手及 Task 内容保持。两个清理阶段都 completed 才显示完成；pending、failed 与结果未知分别显示，403/404/410 仅证明不可访问，不证明清理完成。页面可见且身份有效时自动核对未决状态。暂停后原操作须结束 busy 和等待；可信删除结果保留，取消网络不表示服务端回滚。旧操作的收尾不得重放或改变较新的删除操作。

同一助手通过旧 Test URL 打开的独立 Session 服从相同删除屏障：提交中或未知时不能读取历史或发送操作，即使 current 暂时返回 active；导航、页面重挂和可用存储支持的重载不能解除屏障。该入口保存的草稿与回执也属于目标清理范围；即使旧页面已关闭，删除确认后仍清理已识别 Session 的对应记录，保留其他 Session 和普通 Task 的输入。

原请求及最小删除状态在同账号范围跨导航保留；可用的 sessionStorage 支持重载后继续核对，失败时只保证同文档内存保留。退出、切账户或身份失效清除该账号删除记录。浏览器无法证明不可达页面、无法删除的存储或用户导出副本已物理清空。

## 详情与全屏

统一标题提供明确的详情入口，面板默认收起。详情显示当前助手完整名称、Bot 启动阶段、独立 Worker 观测、托管 Worker、冻结工作目录、Agent 及当前 Session 的连接与启动恢复信息；模型和权限仅展示已有确认值及明确的 pending，不推断原生默认值。`ready` 仍只表示已启动；离线、不可用或读取失效不能显示为已确认在线。Worker 名称不可读时保留绑定 Worker ID，不能猜测机器或取另一助手的配置。详情提供删除入口，服从同一目标确认、准入与删除屏障。

切换助手时保留展开意图，标题、详情和 Session 始终属于同一目标；标题可先用该目标已认证名称，正文按缓存优先显示，实际操作绑定仍须权威详情确认。新目标没有可用的同目标详情时只在详情区局部加载，不能保留旧助手名称或配置，不能因此隐藏已有目标对话；权威拒绝访问、删除、离开对话或账号范围失效时收起面板；临时读取准入暂停不收起已打开的面板。

详情同时满足以下条件时，在会话右侧使用非模态侧栏：`window.innerWidth >= 1280px`，且扣除列表和外部间隔后、共同分配给会话与详情的稳定容器内容宽度 `>= 760px`。侧栏占用 340px，会话至少保留 420px；边框或额外间距不能侵占这两项分配，760px 等号条件仍须实际容纳二者。任一条件不满足时使用视口内的原生模态抽屉。两个阈值均包含等号；共同容器的测量不随详情开关减去 340px，不能改测已被侧栏压缩的会话区而造成反复切换。

桌面非模态详情打开时，会话仍可阅读和操作。详情入口和关闭按钮均可键盘操作，打开后焦点进入面板，显式关闭返回仍可用的当前详情触发点。抽屉背景不可交互，Tab 限制在当前模态层；Escape 一次只关闭最上层，不能同时退出 Session 全屏。关闭、卸载或跨断点调整必须释放本层滚动锁与模态状态，不留背景不可交互状态；打开意图仍有效时跨断点保持详情展开并维持有效焦点。抽屉受可见视口约束，长内容内部滚动，矮屏中关闭和删除确认仍可达。

Session 全屏包含助手名称和详情区域，面板在全屏中仍可打开、关闭。详情开关、断点变化和全屏仅改变布局，不重建 Session client、连接或关键 DOM，不刷新或重放对话。桌面开关侧栏造成的宽度变化沿用共享时间线的文字阅读锚点与跟随意图。普通 Task/Test Session 的独立全屏行为保持原有规则。

Webhook、MCP 的未来设置归属详情区域；当前不显示空设置页、配置开关或接入框架。

## 验证

API 测试覆盖身份、字段、版本和未知创建/删除提交；DOM 测试覆盖默认值竞态、显式选择、失败与分页、目标切换、认证失效及原 ID 保留、删除前后反序读取、失败清理和定向失效。创建测试通过实际弹窗入口操作，验证名字默认请求、显式 Worker 绑定和级联重置、目录/模型分页、迟到响应、失败保留、后台检查、语言切换、关闭及导航后原 ID 核对，不将表单容器外形作为上述保障的替代。

真实浏览器使用生产组件，在 320px、390px、768px、960px、1024px、1280px、1440px 以及 390×300 短视口检查中英文、长名称/目录/状态原因、搜索无匹配与零助手、创建、标题和详情。创建弹窗覆盖默认、展开、Browse、无 Worker、能力失败/不支持和未知回执，测量按钮/输入的实际边界与可达性，核对目录目标及创建 payload；实体手机与软键盘证据另行记录。分别展开、折叠全局导航，按实际容器检查单栏/并列；关键动作实际点击和键盘操作，正常正文对比度、可访问名称、焦点可见及减弱动画可验证。

详情边界覆盖 1279/1280px 窗口与 759/760px 稳定共同容器的交叉组合；仅两个条件同时满足时非模态，打开后实际详情为 340px、会话至少 420px，反复开关不振荡。标题几何使用实际 DOM 边界，确认返回、显示、详情、更多和展开标记可达、不重叠；名称省略后打开详情可读全名，状态和错误不被裁切。验证非模态详情与会话可同时操作、模态背景与 Tab 限制、Escape 顶层顺序、返回焦点及跨断点/卸载后的滚动锁清理。

在宽屏、320px/390px、详情开关、全屏、导航宽度变化及 reduced-motion 下，分别验证驻留命中、本地命中和完全无缓存。挂起第二次 A 详情，A→B→A 响应前核对原 Timeline/Composer、草稿、文字锚点和 client/channel 数量；逐段延迟 getBot、current、channel 同步与历史首屏，不能出现全区域空白、前一助手内容或可用按钮。触屏切换不自动聚焦输入或弹出键盘，窄屏返回入口始终可达；逐阶段保存截图、DOM 身份、焦点、阅读锚点和请求次数。

覆盖刷新/重开/淘汰后的持久恢复、权威空历史、更正、绑定及账号变化、存储损坏/禁用/超限、跨标签失效与迟到请求、失败及重试；普通轮询不造成内容或发送/Interrupt 控件闪烁，历史审批不复活，纯预览资源请求及下载为零。

在详情开关、全屏、导航宽度变化及 A→B→A 切换前后核对实际 Session DOM、client 身份、草稿和文字阅读锚点，不得重放请求或消息。覆盖后台身份暂停、归档只读、启动与连接分层、未知结果核对和删除屏障。受控 HTTP 与 Session 证据只证明 Web 消费行为；原型交互不证明产品实现，桌面仿真尺寸不证明真机软键盘行为，真实 Worker、Provider、偏好持久化和完整助手组合另行验收。
