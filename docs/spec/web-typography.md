# Web 公共字号标准

[UI 设计原则](../ui-design.md#web-typography)要求全站只从同一套字号档位选档或继承。本规格定义档位、适用边界和可验收行为。

## 公共字号档位

[`typography.css`](../../packages/daynight-web/src/styles/typography.css) 是公共档位在实现中的唯一数值来源，所有 Web 入口都必须加载它。档名只表达大小，不绑定用途。

| CSS 变量 | 值 | 16px 根字号下 |
|---|---:|---:|
| `--text-xs` | `0.75rem` | 12px |
| `--text-sm` | `0.875rem` | 14px |
| `--text-base` | `1rem` | 16px |
| `--text-lg` | `1.125rem` | 18px |
| `--text-xl` | `1.375rem` | 22px |
| `--text-2xl` | `1.75rem` | 28px |

例如，Markdown 段落与控件都可以使用 `font-size: var(--text-sm)`。单独调小某处文字应改选档位；修改集中定义才会改变该档位的所有使用者。页面正文容器默认继承 `--text-sm`。普通正文建议使用 1.75 行高，控件与列表建议使用 1.5 行高。

禁止字面字号、局部覆盖字号变量、用途别名、自定回退值，以及通过相对值、关键字或算式推导私有字号。规则同时约束 `font` 简写、内联样式、运行时写入及渲染器配置。公共组件可以接收档位选择，不得接收任意长度或再定义一套字号。

## 适用范围与缩放

凡是 Daynight 决定字号的 Web UI 文字都适用，包括公开网站、Setup、认证、工作区、弹窗、Markdown、附件、会话和 Bot，以及图表、字符图标和图示里的文字。应用无法控制的 PDF、图片等外部素材的内在字号不在范围内，外围 UI 仍须遵循公共档位。

浏览器控制根字号和页面缩放。窄屏通过换行、重排或滚动容纳内容，保留所选档位。现有触屏输入和粗指针 Task 筛选选择 `--text-base`，公共无障碍规则为其保留 16 CSS px 下限及既有触控区域尺寸；窄屏细指针 Task 筛选保留所选字号和触控大小的命中区域。终端使用 `--text-sm` 作为基础档位，用户主动缩放可调整呈现。这些调整不提供额外档位，也不允许组件自设下限或倍率。

## 验收

字号检查覆盖生产 CSS、TS 和 TSX，包括未引用的源文件。应接受公共档位和继承，拒绝自定字号、局部定义、用途别名及无效回退，即使后续规则覆盖它们也应拒绝。可识别的动态字号必须能追溯至允许的选档或公共渲染调整；静态检查范围之外的实际渲染仍须遵守规格。[Web 验证说明](../../packages/daynight-web/README.md#typography-validation)拥有检查入口和覆盖细节。

在桌面和 320px 视口验证长文本、有关交互状态及更小、更大的浏览器根字号。根字号小于 16px 时，验证粗指针输入与筛选不低于 16 CSS px；根字号大于 16px 时，验证其随 `--text-base` 放大。验证终端缩放从所选基础档位开始，以及图表和图示的实际渲染字号遵循选档。局部换档不波及其他使用者；修改公共档位值影响所有使用或继承该档位的文字。
