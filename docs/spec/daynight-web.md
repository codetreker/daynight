## 目标与使用环境

用户登录后通过 `/projects` 查看 `daynight-server` 中的项目、任务进度和执行依赖。
公开 `/` 的介绍与演示由[推广页要求](daynight-landing.md)拥有；进入工作台后的完整路径为：
项目列表 → 项目概览 → 任务列表 → 独立任务或任务链 → 查看任务详情。再次进入项目时
恢复上次选择的概览或任务列表。

沿用[服务端要求](daynight-server.md)的 project、task 和全依赖执行语义，不引入父子任务模型。
任务链是普通依赖的弱连通分量；多起点通过普通边合流时属于同一条链，外部边不合并成员。
代表任务取普通入度为零且在精确服务顺序中最早的成员。没有普通前置及普通后续的任务进入独立任务列表，
但仍可能被外部前置阻塞。分类不依赖状态，已完成前置仍保留普通关系。
页面展示当前用户可访问的数据；项目创建由鉴权工作空间提供，任务的创建、修改继续使用现有 API。

## 工作空间导航

桌面工作空间侧栏默认展开为 190px，可折叠为 68px 竖条。项目入口属于主导航，
账户设置入口始终位于底部并进入 `/account`，当前账户页具有明确选中态。
正文长页面滚动及短窗口都保持账户入口和侧栏切换按钮可达。折叠后保留图标、
中英文可访问名称、悬停提示与键盘操作；顶栏账户入口继续可用。

当前站点以 `daynight.web.sidebar.collapsed` 保存 JSON boolean。没有记录时展开，
不为默认值主动写入；刷新、重新打开、跨项目与账户切换恢复同一浏览器的外观偏好。
读取失败、非法格式和写入失败分别显示可理解的提示，保留本次内存切换，并提供保存当前
值的重试。成功保存才清除提示；错误不伪装成已保存，也不自动循环重试。

740px 及以下保留 60px 导航竖条，展开时使用覆盖导航，不挤压正文。手机导航的开关
是临时状态，不修改桌面偏好。覆盖导航具有模态语义、背景交互隔离、焦点约束和滚动锁；
Escape 或遮罩关闭后焦点回到展开按钮，选择路由则沿用正文聚焦规则。路由变化、进入
桌面断点、开始身份核验、身份阻塞或卸载均结束临时导航并清理其隔离与滚动锁，保留其他
活动层及原有状态。导航处于工作空间认证屏障内，不遮挡身份恢复对话框。

侧栏宽度变化保留项目、缓存、任务详情和图的挂载身份、浏览位置及图视口，不发起额外
数据读取或建立第二套同步。跨标签实时同步、服务端同步与跨设备偏好不属于本地保存保证。

## 日常使用引导

顶栏语言选择器前提供书本图标及可见的“使用引导 / Setup guide”链接，普通点击在
新标签页打开公开静态 `/setup`，保留原页面的地址与内容。项目列表、项目和账户等
工作空间页面都能进入；链接采用浏览器原生行为并隔离 opener。面包屑与文档标题使用
当前语言。未登录直达、带 query 访问和刷新均直接显示该页，页面提供进入 `/projects`
项目列表的入口。

引导采用全部展开的五步布局，供首次操作和重复查阅。每步说明执行位置、必要前置条件、
可复制内容与成功标志，命令遵循实际发布的 CLI：

1. 安装 CLI：准备 Node.js 22 及以上版本的最新补丁，在终端运行 `npm install --global @codetreker/daynight`，
   再运行 `daynight --version`，以版本输出确认可用。
2. 登录账户：运行 `daynight login`，核对终端与浏览器的短码、当前账户和访问范围后批准。
   远程终端可使用 `daynight login --no-browser`，终端明确报告登录成功。CLI 默认连接
   `https://daynight.cc`，日常使用无需先配置服务地址。
3. 创建或找到仓库项目：在具有 Git `origin` 的目标仓库运行
   `daynight project create "项目名称"` 和 `daynight task list`。单个匹配项目直接返回，
   多个匹配明确报错并由使用者选择项目 ID；没有本地绑定写入。新项目的空任务列表是正常结果。
4. 安装 Agent skill：至少已安装一个受支持的 Agent launcher，在交互终端运行
   `daynight skill install`，选择 Agent 和 User/Project 范围；Project 范围要求位于
   Git worktree。按安装输出中的 Agent 专属提示加载指令，以识别 `using-daynight` 确认可用。
5. 开始使用：以当前语言提供 Agent 请求示例，登记一个具体任务，然后通过 Web 或
   `daynight task list` 查看。自然语言请求与终端命令明确区分，登记任务不隐含自动执行许可。

页面展示 `window.location.origin` 作为当前服务地址；它只是地址信息，不生成服务配置
命令。引导随构建发布，不接收凭据输入，不发起任何 API 请求，包括身份核验、provider
发现、项目、任务、令牌和完成度读取。直接访问、刷新、语言切换、命令复制及窗口焦点或
可见性恢复均遵守零 API 请求要求；显式返回项目列表后才进入正常认证流程。
CLI、项目发现和 skill 安装的完整契约由各自的
[客户端需求](daynight.md)、[项目任务需求](daynight-project-task.md)与
[Agent skill 需求](daynight-agent-skill.md)拥有。

命令始终可选择，复制使用同一份实际字符串并保留真实换行与参数引号。当前复制等待时
禁用复制按钮并阻止重复提交；成功和失败均以浮动状态反馈呈现，不改变步骤几何。
剪贴板不可用或拒绝访问时说明手动选择复制。卸载或语言切换使旧结果失效，切换不重发
复制和业务请求。中英文覆盖步骤、按钮、提示与可访问名称；320px、390px 和桌面宽度下，
在公开阅读布局内保持命令与主要操作可达，整页无横向溢出。

Go 以现有 HTML handler 注册精确 `/setup` GET/HEAD，沿用 `no-store`、405、Allow 和
请求日志。`/setup` 根及后代路径属于认证 callback 保留命名空间，冲突须在配置或启动
验证阶段明确拒绝。既有 callback 占用该命名空间时，改为其他路径并同步 UniAuth 的精确
登记值；配置不得进入重复路由注册 panic。独立验证页面行为、配置拒绝和实际发布 CLI 的
完整日常使用流程，原型或静态命令断言不能替代真实流程。

| W3 | 项目没有已保存的外层选择时进入“概览”，显示任务总数、已完成、待处理、进行中、可开始和被阻塞数量，以及完成比例。项目左侧以“概览 / 任务列表”切换右侧内容，窄屏转为上方横向页签；键盘方向与实际方向一致。两个外层页签始终关联稳定面板，空项目也可切换。每个面板的标题与说明在同一行按文字基线对齐，保留各自字号；标题完整显示，说明空间不足时省略，并通过原生提示保留完整文案，页面不得因此横向溢出。外层选择按项目保存在当前浏览器，重载及返回项目直接恢复上次选择，不先显示概览再跳转；不同项目互不影响，不改变 URL 或 history。读取、格式或写入失败显示对应的本地化偏好提示，保留当前页的切换能力，不声称已保存。所有数字来自一个完整项目快照，按任务 ID 去重。统计卡片下的进度行及定位遵循“项目整体进度”。 |

成员的未拆分 Goal 继续按独立任务分类。代表任务已经完成时，只要组内仍有未完成成员，
该行仍显示；整组全部完成才隐藏。成员按 ID 去重，链外前置不计入进度，排序与任务链
列表相同。列表的完成显示偏好不改变概览的行集合或计数。

所有独立任务汇总为最后一行，仅在仍有未完成独立任务时显示。其口径为：

```text
近期完成数 = 状态为 done 且 completedAt 位于最近 7 × 24 小时内的独立任务数
总数 = 全部未完成独立任务数 + 近期完成数
完成百分比 = floor(近期完成数 × 100 / 总数)
```

最近七天为按完成时间计算的滚动窗口，包含窗口起点。未完成项不受创建时间限制；
更早完成或完成时间未知的 done 项不进入分子和分母。行内说明“未完成任务 + 最近 7 天
完成的任务”，防止与全历史统计混淆。示例：未完成 6 项、最近完成 6 项、更早完成 12 项，
显示 `6 / 12`、`50%`。既有六张统计卡、两类任务列表与完成开关仍使用原有全量语义。

窗口使用服务端观察时间及单调时钟推进，不随设备日期偏差改变，也不依赖成功轮询来
过期。概览可见时到达时间边界会更新；页面隐藏或离开概览时释放该显示计时，重新可见
时重新计算。截止时刻仍纳入完成项，越过后同时从分子和分母移除。刷新失败时仍展示
上次成功数据和失败信息，保留数据上的近期时间窗口继续推进。

点击任务链进度行切换到“任务列表 → 任务链”，滚动并聚焦对应条目，短暂高亮，不触发
打开图。点击独立任务汇总切换到“任务列表 → 独立任务”，定位并聚焦列表开头。显式定位
覆盖该次历史滚动恢复，返回概览保持概览位置，此后普通切换恢复定位后的任务位置。
定位期间刷新改变代表时按原 task ID 解析当前分组；目标已删除、成为单成员或被完成筛选
隐藏时，提供目标不可见提示并回到对应类别入口，不切换完成偏好或选择其他任务链。
定位请求消费后，后续同步不重复滚动。切换本身不增加 API 请求或修改 URL/history。

空项目显示“还没有任务”；所有任务完成时显示“所有任务均已完成”。长标题自然换行，
320px 窄屏保持标题、完成数与百分比可读，整页无横向溢出。中英文覆盖行说明、空态、
操作及可访问名称；目标高亮结束或卸载后释放相应资源。

## 任务条目状态背景

概览整体进度行、独立任务整行、任务链标题行及展开子任务行按生命周期状态着色。
待处理使用浅灰 `#F1F3F6`，进行中使用浅蓝 `#EBF2FF`，已完成使用浅绿 `#EAF6EF`；
悬停分别加深为 `#E8ECF1`、`#DFEAFF`、`#DDEFE5`。底色覆盖完整可点击行，保留原有
状态文字、布局和入口。已完成行不降低整体透明度。依赖图画布、任务详情和统计卡片
沿用各自样式。

独立任务与子任务使用自身状态；任务链标题及其概览行使用普通分量的现有整体状态，
外部前置不参与聚合。全部完成才是已完成；否则存在已完成或进行中成员即为进行中，
其余为待处理。已有成员完成而没有成员正在执行的链仍使用进行中底色。
概览独立任务汇总对该行当前计数范围使用同一规则；过期、未来或完成时间未知的
完成项不影响其底色。汇总的显示条件及七天窗口沿用[整体进度](#项目整体进度)。

阻塞任务保留待处理底色和橙色阻塞标签。独立任务的既有卡住提醒优先使用
`#FFF7E8` 橙色底，悬停为 `#FFF0D6`，同时保留进行中标签；提醒不传播为整链或概览
汇总的橙色底，也不为子任务新增提醒。键盘焦点和概览跳转定位使用独立紫色轮廓，
不覆盖生命周期底色。展开容器保持中性，每个子任务独立着色。

正文及辅助文字在默认和悬停背景上均满足至少 `4.5:1` 对比度。桌面及 `320px` 窄屏下
保留长标题换行、状态及操作入口，不出现遮挡或横向溢出；空、加载、失败和禁用场景
保留现有含义和可访问性。

## 统计与链外前置

```text
total = todo + inProgress + done
todo = ready + blocked
blocked = status 为 todo 且至少一个直接前置未完成的任务数
完成比例 = done / total；total 为 0 时展示“暂无任务”
```

“待处理”包含“可开始”和“被阻塞”，三者不能相加作为总数；进行中与已完成不计入 todo。
创建默认 todo，ready 仅在全部普通/外部直接前置完成时为 true。状态设置不完成其他前置，
也不授予执行权。[三状态要求](daynight-task-status.md)拥有状态、版本、依赖与计时规则。

独立任务不显示单节点任务图，也不显示 0/1 式链进度。列表工具栏中的任务链条目数是多成员普通分量数，继续显示可见/全部条目数。页签数字统计未完成任务，两者相加等于项目待处理数与进行中数之和；链页签数字不表示链条目数。

每条任务链的进度和聚合状态只计算其普通分量成员，不计算额外展示的链外前置。各链的成员集合互不重叠，递归上下文只补齐前置，不扩大成员。相同前置可以出现在多个链的上下文中，但不会重复成为这些链的成员。

## 渐进图生命周期

画布保存实际可见 S，不持久化，项目/链/页签变化或卸载后清除。显式展开重新布局，在当前缩放居中操作卡片并聚焦主体；reset 重算概览并 framing，焦点保留 reset 控件。同一成员/代表作用域的成功刷新保留仍属于新 P 的实际可见 ID，加代表任务后只保留相应诱导无向连通部分，不自动加入新基线或新任务；刷新保持视口，失败保持旧数据/S/视口。显式重置重算概览；代表不变而成员变化时，仅重置 S、检查和旧动作并重新 framing，保持画布、全屏、活动详情及其 inert/滚动锁。代表变化才按链切换替换行和画布。自动合并、拆分或代表变化使已聚焦控件消失时，由稳定列表层恢复至存活链入口或列表控件；没有条目和筛选控件时回退到带可访问名称的列表区域，不能落到 BODY；已有详情和列表外焦点不被抢走。打开详情时刷新不抢焦点，消失入口使用原关闭回退。详情、附件面板、请求及 locale 生命周期保持，语言变化只重译新控件/计数。

主体检查、完整上游高亮、隐藏上游计数、独立 Details 与平滑曲线由
[任务检查要求](daynight-task-inspection.md) TI3–TI5 拥有，已与当前渐进概览集成。
选择及 Details/关系导航不展开、不布局、不编译几何或移动视口。

## 一致性与读取边界

完整项目图 API 响应必须包含同一快照中的图和统计；Web 以原子合并的完整摘要集合派生同等的图与统计。首次挂载成功在线同步前不显示磁盘私有内容。图节点和完整详情均保留必填可空的 `startedAt`、`completedAt`。
图还提供必填数据库 `observedAt`；未知起止为 `null`，缺失或无效时间字段按协议错误拒绝，不能使用浏览器墙钟或旧元数据补值。
图节点与完整详情还必须提供 `externalDependsOn`，它是完整 `dependsOn` 的无重复外部子集；
共享解码器校验 UUID、去重和子集，缺失或 null 拒绝。图等价及详情新鲜度包含该数组，
仅性质变化也不能继续复用旧内容；仅时钟变化仍保留身份。归组使用普通分量，关系标签和边虚线消费显式性质，节点上下文角色分别计算，
遵守[外部依赖需求](daynight-external-dependencies.md)。
时钟样本在每次成功读取时更新，但其单独变化不得重建图索引、改变画布或焦点。
不得把现有任务列表的多个分页响应当作共同快照，也不得用筛选后的列表推断根节点。

切换项目或选中任务时立即显示新资源的加载状态，不短暂显示旧资源内容；仅同一资源且同 cacheGeneration 的刷新允许保留上次成功数据。定时读取仅覆盖当前项目摘要同步与打开的任务详情，项目列表、附件列表及内容继续使用各自的刷新和写入后更新机制。页面隐藏不取消已发出的请求；重新可见时若已有图读取则沿用它。手动刷新立即取代当前图读取，自动时钟不会中断它。详情刷新期间保留同一任务的正文；普通后台读取不在标题区插入或移除进度提示，数据未变化时标题、页签和当前正文或附件区域的位置与可用尺寸在请求前、等待中和成功后保持稳定。真实读取错误、必需核对和已知陈旧信息使用限时气泡明确展示，不挤压正文；气泡关闭后，未解决的恢复操作保持可达。已有详情请求未完成时合并一次后续读取。页面隐藏时详情自动读取与排队的后续读取等待，已发出的请求可以完成。首次读取失败后自动重试仍保留错误，直到成功恢复。

节点详情在本挂载项目同步准入后可以显示匹配业务版本的持久正文；每次打开都记录该 opening 的 live GET 要求，包括操作 pending/unknown/核对阻止读取的期间；解除后完成必要 GET，磁盘、写结果或重开前核对不授予本次写权限。cacheGeneration 改变立即清除旧正文、PR 和已加载观察，即使新 GET 挂起或失败也不能显示旧历史。后续按任务摘要业务版本、项目 generation 和恢复需要读取，重复成功时钟 receipt 不触发未变化详情 GET。原始详情的状态、依赖、外部依赖、阻塞或更新时间与画布数据不一致时，保留差异证据并提示“任务信息已有变化，刷新任务图”，避免局部更新后产生错误的全图统计。ready/blockedBy 从当前完整本地图物化，不能用物化覆盖消除原始差异和禁写限制。详情持久化的版本、LRU 与失败恢复遵守[缓存需求](daynight-task-sync.md)。PR 属性随完整详情读取，属性更新沿用 task 的更新时间；图响应不携带属性。

MVP 支持一个项目最多 1,000 个节点、5,000 条依赖边。这是产品保护上限；固定拓扑的生产验收不保证任意 DAG 都具有相同耗时。超过任一上限时显示规模和限制，拒绝返回部分图或部分统计。项目及任务仍可通过既有 API 管理。

## 自动执行许可与平台要求

`allowAgents` 是独立于状态和 ready 的持久布尔值，详情与图严格读取。新任务为 false，存量迁移为 true；显式任务执行接受两种许可值。Web 开关只表达是否允许自动选取，不选择实际用户、机器、agent 或模型，也不代表 worker 已启动。服务的字段、版本和运行锁由[服务要求](daynight-server.md)拥有；worker与唯一 claim 仍按[worker 要求](daynight-worker.md)独立交付。

确认窗口展示完整任务名称和开启/关闭后果，取消为初始焦点并保留既有模态、Escape、焦点恢复规则。确认冻结目标值、project/task、源状态和精确 version；已知内容或版本变化后重新审阅，不自动换版本。成功响应验证身份、目标许可、未变生命周期与单次版本增长，再安装完整详情并刷新图；错误、冲突和未知结果遵循与状态设置共用的请求归属及读取核对。

requiredPlatform 的 null/三个枚举、缺失拒绝、创建默认与设置/清除由服务要求拥有。详情状态行的下拉框同时展示已确认值和修改入口；选择不同平台先确认当前/目标转换，确认后才以所审阅完整详情的精确版本提交枚举或 null，Any platform 对应清除。当前值不打开确认，取消、Escape、关闭或遮罩关闭不写入并恢复入口焦点。确认或提交期间保持已保存值，概览没有独立平台编辑区或保存按钮。

平台确认与状态/许可共用互斥写入和 GET 核对；后台已知变化使原确认失效，不替换新版本静默提交。成功不改变状态、许可、执行时间、PR 或边，其他操作省略该字段仍保留要求。平台不改变 ready、统计或任务执行授权；不将客户端筛选平台当作实际执行环境证据。

## 状态设置与读写一致性

完整详情在标题下的公共状态行提供 todo、in_progress、done 三项状态菜单，菜单后紧邻平台切换，当前状态项明确标记且可选择。
普通成员和管理员均可设置。菜单支持方向键、Home/End、Enter/Space、Escape 和焦点恢复。
选择后确认完整任务名、当前→目标及计时后果；同状态说明状态与时间不变，取消初始焦点，
取消/关闭/Escape 不发送请求。入口位于页签之外，长标题与确认正文可键盘滚动，320px 无页面横向溢出。

状态、allowAgents、requiredPlatform 与软删除共用一个按 project/task 隔离的写入会话和确认 union；陈旧、读取失败、pending、
unknown、核对中或失败都阻止任务写入。确认冻结身份、源状态、目标、精确版本与审阅历史的 cacheGeneration，实质读取或历史变化使它失效。操作接受时同步捕获审阅 generation 和所有者，每次异步准备完成及发送前复核；新历史 ticket 或相同 ID/版本不能使旧确认继续派发。失效准备零写入，只 GET 当前历史并在 fresh GET 后要求新确认；被取代的准备不能改变较新反馈或释放共享写锁。仅关闭详情不取消仍有效的已接受意图。同用户身份核验暂停时准备与普通结果等待 gate，恢复后重新检查原审阅历史、所有者与身份生命周期，再读取当前准入或推进阶段；再次暂停继续等待，身份结束丢弃旧操作。失效且未发送的准备转为本地冲突或拒绝并只读刷新，已发送的旧历史结果进入 unknown/GET 核对；不得因 getter 的暂停异常形成未处理异常或永久 pending。可信已提交 404 的项目撤权在普通等待之前立即清私有正文，持久清理等待 gate，旧 ticket 不能撤回新历史。
无变化的可选周期 GET 不废弃当前版本。图没有任务 version，不能发起状态写入。
version 以 bigint 无损保留正 int64 数字；请求 PUT status 只含 version/status。
成功必须匹配身份、目标、精确 +0/+1：当前同状态 +0，实际改变 +1。
同状态可返回最新 ready/blockedBy，不能深比较整个旧 Task。保留字段和计时按状态规则验证。

每键一个操作，关闭、重开、切换任务或项目不释放进行中防重。成功发布确认详情、提升版本下界并刷新图；
旧读取或旧图不能倒退已确认状态。冲突保留错误并 GET 重读后重新决策；网络、5xx、协议错误、丢响应
或取消先标记 unknown，只 GET 核对，不重发写入，不将读到的目标值归因于原请求成功。
核对失败保留写错和读错，继续阻止任务写入；可信 404 按已有项目准入规则清除私有正文和面板但保留未知结果与 GET 重试。当前历史中的 `410 task_deleted` 是任务局部终态，移除该任务并同步项目，不撤回项目访问。终态与项目缓存 generation 绑定；既有配套历史恢复后的新授权快照重新包含活动节点和摘要时，强制 GET 后可重新打开该任务，状态、许可、平台与删除的所有旧历史结果都不能修改恢复后的详情、覆盖较新操作反馈或解除较新操作的共享写锁；身份及项目撤权仍遵守既有 scope/ticket 检查。
原请求结果仅属于原身份、project/task；登出、失权或身份 generation 改变不泄漏旧内容。

状态更新保留图选择、实际 S、视口、全屏、详情页签、附件 controller、阅读与焦点。
详情 ID 及其复制保留在概览，标题复制位于共享标题栏；普通与成功提示显示 3 秒，错误和带操作提示显示 8 秒，均可手动关闭。鼠标悬停或键盘焦点位于气泡时暂停超时，离开后继续；超时只影响展示，未解决的错误和核对可通过紧凑入口重新打开，保持禁写与 GET 核对语义。语言切换及普通刷新不重置计时，重开不重播已确认成功。
不提供旧状态或任务审批。生产组件夹具验证双语、桌面/320px、长标题、失败、依赖拒绝、
冲突、并发、未知及读取失败；真实服务验收独立验证数据库、鉴权和持久化。
[状态要求](daynight-task-status.md)拥有九组合、依赖、计时、迁移和执行范围。

## 项目执行提醒设置

表单保留精确 settings.version，草稿独立于已保存 Project；保存期间禁用重复提交，错误、冲突、权限变化和恢复均有双语反馈，窄屏可访问。
冲突或权限拒绝后重新读取 Project 和成员，展示当前权威值与角色，不自动重发 PATCH。
明确拒绝与未提交/取消的草稿不覆盖权威值；网络、协议或 5xx 导致写结果未确认时，必须先重新读取 Project 和成员再允许下一次写入。
核对失败保留明确错误并阻止 Save，提供读取重试；取消或导航离开不证明服务已回滚。资源 403/404 或自身成员消失时清除不可访问的项目与草稿。

设置状态归当前用户和项目，切换项目、离开路由或换号使旧请求失效；同用户前台核验保留表单、焦点和输入，
新的读写继续遵守身份核验等待规则。保存仅修改项目阈值，不改变任务状态、时间或图布局。
CLI/Web 在 Project、列表和图中无损读取完整正 int64 settings.version；设置变化更新 Project 元数据，
相同任务和统计继续复用任务索引，版本大于 `2^53` 不丢精度。实时卡片、独立行及 Goal 子任务行共享[计时需求](daynight-task-timing.md)规定的时间事实，卡片与独立行同时消费项目阈值。

## 任务执行耗时与卡住提醒

图 Task 卡片、独立任务行及 Goal 展开区子任务标题后显示当前执行的耗时：已知起点的进行中任务自动更新，已知起止的完成任务使用持久差值固定结果，待处理、未知起点或完成态未知终点不显示推算值。
图卡片和独立任务行只有在 `allowAgents=true`、进行中且原始毫秒耗时严格超过已保存项目阈值时显示琥珀强调、图标和“可能卡住了”/“Possibly stuck”，保留进行中状态；完成后撤下提醒。
`allowAgents=false` 的进行中任务仍实时显示耗时，超过阈值也不显示提醒文字、警告样式或可访问提醒含义。
可见格式区分不足一分钟、分钟、小时和多天，向下取整只改变文字。原有按钮可访问名称保持，图卡片和独立行的精确起止、阈值和提醒含义通过描述与提示提供，不逐秒播报 live region。
子任务行仅展示自身耗时，提示不包含阈值或卡住提醒，保留原按钮名称、状态、排序、详情及展开交互；短标题后紧随耗时，长标题和多天耗时在 390px 窄屏自然换行且无横向溢出。链汇总不冒充个体耗时，卡片保持 220×96/136 几何、Details、检查、展开、虚线和选择强调；时钟与阈值变化不重建图布局或移走焦点。
服务端样本与单调接收时间成对构成页面共享时钟，只为已挂载运行消费者计时；隐藏页暂停，恢复可见立即更新并沿原图读取重新校准。
本机墙钟不决定执行提醒，服务端采样至接收的网络/解析延迟仍是估计精度边界。完整数据和项目设置规则由[计时需求](daynight-task-timing.md)拥有。

为基准，路径不能越过任务根。普通主键激活不带 query/hash 的有效相对附件链接时，

预览 URL；修饰键、非主键、上下文菜单、绝对/协议/根相对 URL、独立 fragment 以及
query/hash 链接保留现有 URL 策略与原生导航。本文不要求生成 Markdown 标题锚点。

只有完整分页清单才能判定文件缺失。加载、清单失败、非法路径、确认缺失与预览
失败分别显示；适用时提供重试。描述导航不能建立第二个清单或预览所有者。切换

## 附件区域

附件页签位于任务公共标题下，与概览并列；左右分屏在 320px 窄屏继续保留。左侧是
目录树、刷新与上传，每个文件条目右侧“…”菜单中的删除先打开完整路径确认框，
明确确认后才提交；右侧是所选文件预览及其下载、新标签页打开操作。菜单与确认框
优先处理 Escape，取消不改变文件或当前预览。概览保留描述、关联 PR、
关系与元数据。隐藏面板不参与键盘导航，切换页签保留选择、目录、预览和上传草稿；
切换 task/project 则重置页签和旧身份状态。每次选择一个文件，默认目标路径为该
文件名，用户可以修改为多层相对路径；相同路径直接覆盖。目录由完整文件路径形成。
加载、上传、删除及预览错误局部展示，续页失败保留已读取文件并明确标记列表
不完整；用户可以重试或手动刷新。切换 task、文件或关闭详情时，过期请求不能覆盖
当前选择。覆盖成功及刷新发现同路径 `updatedAt` 变化时重新读取所选内容；删除
当前文件清空预览，删除其他文件保留正在阅读的文档与位置。

Markdown 按 CommonMark 和 GFM（包括表格）渲染，`mermaid` 图块与描述共享静态
流程图、错误隔离、源码、安全及局部滚动规则；原始 HTML 作为文本显示。相对
图片与链接按文档目录指向 task 预览路径，独立 `#fragment` 保留。图片、PDF、文本、
HTML 和其他格式的展示及可信同源执行约定由[附件需求](daynight-task-attachments.md#web-管理与预览)
拥有。Markdown、文本/JSON/源码和大图仅由预览正文纵向滚动；HTML/PDF 仅由
占满正文的原生 frame 内文档或阅读器纵向滚动。对话框和右侧预览外壳不再叠加纵向
滚动，预览标题及操作始终可访问；844×390 短视口压缩间距以保留可用内容。HTML/PDF
的可用性错误与重试在原生 frame 加载前展示，frame 内的资源继续按浏览器规则加载；
HEAD 成功不能证明实际内容已经绘制。预览没有独立弹窗、会话或隔离执行机制。
独立阅读入口紧邻下载，链接到当前文件的完整页面，使用 `_blank` 与
`noopener noreferrer`，不改变来源详情。完整页面通过现有完整分页清单确认精确
文件路径，区分加载、不完整清单、请求失败、确认缺失与预览失败；沿用同一渲染器、
相对资源及文件接口。附件路径页面展示完整 Task Detail 并定位附件，复用其概览、状态、关系、任务操作及
完整附件面板。独立页的任务/页签/文件地址、历史、数据刷新和非模态行为由
[独立任务详情要求](daynight-task-inspection.md#独立完整任务详情)拥有。附件正文与
原生 frame 分别沿用唯一滚动所有者，删除确认保留自身原生模态交互。文件产品要求由
[独立页面完整阅读](daynight-task-attachments.md#独立页面完整阅读)拥有。
原完整阅读任务组已通过独立真实服务运行时验收；实际源码、产物、环境与清理的证明机制见
[附件组合验收决策](../../.agents/notes/archived/testing/2026-10-21-task-attachment-cross-layer-acceptance.md)，不将本机浏览器结果扩大为托管 CI 结论。

## 部署与测试隔离

日常部署继续使用 `deployment/localhost`，完整应用一并启动，正常重建保留项目及任务数据。测试使用独立的 `deployment/dev-ci`，复用相同生产镜像构建和转发配置，在专用项目、端口、数据库、卷与网络中执行；不修改日常 localhost 环境。

测试正常完成、失败或取消均清理本次资源，其他运行和日常数据保持可用。清理失败必须使验收失败，并保留诊断与原始测试结果。子命令进程组在主进程退出后
仍归当前 run 管理，清理必须终止遗留后代；中断恢复只接受已有回执的有效 run ID，
并保留原始回执。Go 与 web 的覆盖率规则不变。

源码构建使用固定 Node/pnpm 依赖生成真实页面，缺少产物时 Go 构建必须失败。
Docker 构建完成相同流程，宿主机只需 Docker；最终运行镜像不依赖 Node。HTML、
完整图和最新详情禁用缓存，哈希静态资源使用长期 immutable 缓存。未知 API 返回
JSON 404，缺失资源、资源目录与未知页面形状不得回退到 SPA HTML。已登记页面形状
中的无效 ID 沿用 index 加前端未找到页面的行为；附件原始路径守卫先拒绝非法路径。
