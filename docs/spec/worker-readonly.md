# Worker 只读目录浏览

## 目标与范围

用户可以浏览自己指定 Worker 上的目录，为助手工作目录选择提供输入。目录来源是目标 Worker 的有效启动 cwd 和文件系统，服务端仅认证、路由和转发。该能力不需要项目、任务 claim 或助手 Session；浏览不启动助手、不修改文件、不读取文件正文，也不提供任意命令执行。

Web 通过类型化客户端提交 `directory.list`。[原生模型发现](worker-model-discovery.md)通过同一操作映射的 `model.list` 提供，使用独立的输入、结果和资源限制。创建弹窗和目录选择交互由其产品组件负责。

## 身份与有效性

每次操作绑定当前用户、Worker、请求 ID、连接 ID 和能力代次。Worker 连接必须使用有效的 PAT，查询允许同一所有者的有效 Web Session 或 PAT。服务端在接入、投递与响应交付时核对权限，并持续复核长连接。

连接替换、断线、配置变化、账号切换、取消或超时后，旧结果不能作为新请求的有效响应。单个查询在鉴权期间取消、超时或因调用方凭证失效被拒绝，不得断开仍获授权的共享 Worker 通道或使其它有效查询失败。查询不自动改选其它 Worker，也不能回退到服务端或浏览器目录。旧 Worker 明确返回不支持；离线与不支持分别表达。

## 目录语义

省略 `path` 时，Worker 使用其有效启动 cwd。显式路径必须是目标平台的绝对路径；Windows 支持盘符和 UNC，不允许以当前盘符猜测相对路径。Worker 规范化并解析符号链接，校验真实目录和系统读/遍历权限，不增加项目根目录限制。

成功结果包含规范化路径、可进入的父目录或 `null`、当前层目录条目及下一页游标或 `null`。目录条目只有名称和路径；符号链接仅在其目标为目录时列出。没有父级或父级访问被系统拒绝时，父目录为 `null`。文件、失效链接不作为目录返回。

隐藏项按名称的点前缀识别，默认排除，`showHidden` 可显式显示。Windows 文件属性隐藏标记不属于这一名称过滤规则。`filter` 是当前目录层名称的不区分大小写匹配，不递归搜索。分页按名称稳定排序；游标绑定目录身份、修改时间和查询条件。目录变化、篡改或 Worker 浏览器实例替换使游标失效，消费者应重新读取当前层。

## 有界执行与失败

单次目录操作最长 5 秒，服务端转发最长 10 秒。每页 1–100 项，目录结果最多 64 KiB，传输帧最多 256 KiB。合法目录名称的 JSON 转义不能使已准入的页面在转发后超出消费者的响应字节上限。每次扫描最多 10,000 个当前层条目；超过上限返回 `limit_exceeded`，不能把未扫描结果当空目录。扫描仅保留有界的候选页，不将完整目录载入内存。

无法取消的系统调用保留占用名额直到调用和目录句柄关闭结束，最多四个并发未结束的目录操作；取消不能释放名额后无限积压系统调用。服务端限制每 Worker 16 个和全局 1,024 个待处理请求，连接和队列也有上限。

消费者必须区分 `offline`、`unsupported`、`permission_denied`、`not_found`、`timeout`、`cancelled`、`invalid_path`、`invalid_cursor`、`io_error`、`busy` 和 `limit_exceeded`。服务端转发期限到达且 HTTP 调用方仍连接时，返回 HTTP 504 和 `timeout` 错误正文。空目录是成功结果中的空列表，不是错误的替代形式。协议、认证或所有权错误沿用 HTTP API 错误。

## 验证边界

回归覆盖两个用户和 Worker 隔离、凭证撤销、重连旧响应、取消超时、断线、分页、长目录、隐藏项、无权限、空目录、符号链接和平台路径。真实临时目录的结果与磁盘对应，并比较操作前后文件内容。Windows 路径的受控文件系统检查必须与真实 Windows 运行证据区分。

目录浏览成功不保证稍后的启动仍能访问该路径。实际助手启动继续执行既有目录校验。目录内容不进入常规遥测、任务附件或持久化账本。
