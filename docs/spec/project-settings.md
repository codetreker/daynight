# 项目设置工作空间

项目设置按用途提供五个分组，所有有权访问项目的成员均可进入；操作权限和个人资源归属仍由各功能的现有规则决定。项目页只有一个“项目设置”入口，设置页提供返回当前项目的入口。侧栏在所有分组中保持所属项目的选中状态。

| 顺序 | 中文 | English | 内容 |
| --- | --- | --- | --- |
| 1 | 执行与提醒 | Execution & alerts | 执行提醒阈值、输入校验、保存与取消、冲突和结果 |
| 2 | Worker 提示词 | Worker prompts | 当前用户的项目个人提示词、预览与作用层次 |
| 3 | GitHub 集成 | GitHub integration | 仓库连接、安装、同步状态与管理 |
| 4 | 成员与邀请 | Members & invitations | 成员身份、有效角色、Team 继承、独立项目授权与邀请 |
| 5 | 项目管理 | Project management | 仓库地址、项目归属、转移和删除 |

## 地址与导航

`/projects/{projectId}/settings` 默认进入执行与提醒；`?tab=execution|prompts|github|members|management` 指定分组。`/projects/{projectId}/members` 直接显示同一项目的成员与邀请分组，不重定向。空、重复或非法 `tab` 显示导航错误和默认分组入口，保留项目上下文。其他查询参数及已有授权错误处理沿用现有规则。

分组链接支持直接访问、刷新、修饰键和新标签页；实际切换记录浏览器历史，重复选择当前组不新增条目。历史恢复相应分组，包括旧成员地址；URL 与历史不保存草稿、秘密或操作结果。刷新按身份和权限读取已保存资源，不保证恢复未保存内容或一次性链接。

桌面导航纵向排列，手机导航横向滚动，选中项保持可见；320px 页面不产生横向溢出，宽成员表格可在自身区域滚动。方向键按导航方向切换，Home/End 选择首尾，选中项和正文具有可访问关联。隐藏组及其浮层不可交互；打开模态时保留焦点约束，历史切换离开所属组时暂停浮层，返回后恢复。

选择或重复选择分组、切换语言、容器或导航内容尺寸变化后，手机导航仅做保持活动链接可见所需的即时横向滚动，保留 4px 内边距，允许不超过 1px 的取整误差。活动链接超过可用宽度时优先显示起点，用户仍可手动滚动到末端。调整不滚动正文、不转移焦点、不改变草稿或提交状态；无内容和几何变化的后台刷新不打断用户手动浏览导航。桌面竖向导航不产生水平偏移。

## 仓库地址

项目管理组在归属和删除之前展示当前仓库地址，长地址可换行。有效 Project admin 可通过卡片标题行的“修改”打开编辑弹窗；普通成员只读，不能打开编辑。卡片保留可信成功反馈和未知结果的只读核对入口。弹窗先聚焦新地址，展示格式提示和校验；Enter 与“预览更改”均只执行只读预览。确认在同一弹窗展示项目名称、当前地址、目标地址、分类及影响，焦点先落在返回操作。确认绑定预览返回的项目名称、当前地址、新地址、仓库版本、归属版本、仓库分类与目标 GitHub ID，版本保留完整十进制精度。

预览区分原样、同库、换仓与身份未知。原样保存不可用；同库说明 GitHub App 连接和 Worker 选择保留。换仓说明断开项目的 GitHub App 连接、停止旧仓库同步及保留旧 PR，并说明移除已有 Worker 云端选择、配置同步窗口内仍可认领，以及应用配置可能停止现有执行。身份未知还须显式选择“按更换仓库处理”才能保存。

返回编辑保留输入并使旧预览失效；取消、关闭或 Escape 返回卡片并恢复入口焦点，再次打开保留同用户同项目的草稿并要求重新预览。校验及预览错误可在弹窗内修正或重试，已取消或过期的预览不能覆盖新编辑。提交和结果发布期间禁止重复提交并占用共同写入保护。确定拒绝保留可修正草稿；409 使原确认失效，必须重新预览和确认。未知写入仅提供当前地址的只读核对，当前值与目标相同或不同均不能确认原操作，也不能解除原操作的防重复事实。

可信成功回执刷新当前项目与相关 GitHub、Worker 读面，保留其他设置草稿和各自的并发版本。刷新失败、取消及随后重试均不得丢弃独立草稿或重置其并发版本；恢复读取发现设置版本变化时保留草稿并显示冲突。组间切换保留改址草稿和结果；旧回执只能改变其所属的确认。中英文、桌面与 320px 窄屏均保持地址可读、按钮可达、确认焦点约束、Escape 取消及关闭后的入口焦点恢复。

## 项目归属布局

项目管理的归属卡片在空间足够时将转移按钮紧邻团队名称和完整 Team ID 的右侧，间隔 24 CSS px 并垂直居中；空间不足时按钮左对齐换行。团队名称和 ID 可以折行，页面不得横向溢出。无转移权限时，权限提示位于团队信息下方。

## 状态与操作

同一用户和项目的组间切换保留草稿、原始输入、校验、预览、展开内容、操作结果及各组阅读位置，不自动保存、取消或重发操作。首次进入从组顶部开始，返回时恢复有效位置及编辑上下文；内容变短时可限制到可用范围。非当前组以“未保存”“处理中”“需处理”表达各自实际状态，普通后台检查不标记为业务处理中。某一资源读取失败时显示其错误和重试，不阻止其他可访问资源。

进行中、确认、拒绝、冲突和未知结果属于原用户、项目及操作。隐藏不表示取消或回滚，旧结果不得覆盖较新编辑、关闭新的确认或抢走导航。设置、GitHub、仓库改址、转移和删除沿用共同写入保护；成员和邀请保持独立操作限制，个人提示词保持独立资源生命周期。未知写入通过只读核对处理，当前读取不证明原操作成功，也不自动重放。

同项目设置地址和旧成员地址之间切换不触发提示词放弃确认。离开整个工作空间时沿用提示词离开保护；取消离开后选择提示词组并恢复有效编辑焦点。普通后台身份检查保留界面；真实账号变化、项目删除或访问撤销撤回不可访问的私有内容和秘密，旧响应不得恢复它们。

成员组继续区分有效角色、Team 继承和独立授权。Project admin 可按现有规则管理独立授权及邀请；移除独立授权不改变 Team 关系，也不必然使成员失去访问权。普通成员不因此获得退出项目或管理 Team 角色的能力。邀请链接只在创建结果中展示，列表不含秘密；手动复制、复制失败恢复和关闭前的一次性提示仍可用。已展示的链接在暂离整个设置工作空间后返回时保留，直到明确关闭或真实主体、资源失效。邀请撤销的未知结果及重复操作限制按原邀请 ID 保留，不因列表读取、其他操作或切换分组清除。

有效 Project admin 可在成员标题栏按姓名或邮箱搜索已注册账号并直接添加为项目普通成员，包括仅获独立授权的管理员和 Personal 项目管理员；普通成员看不到入口。空查询不列举账号。候选显示头像、姓名和邮箱的可用资料，可展开完整账号 ID；完整成员名册中的账号显示已加入，不能重复添加。搜索支持分页、加载、无匹配、失败和重试；旧查询不得覆盖新查询。窄屏搜索位于标题下方，结果可用键盘操作和关闭，不改变邀请及已有授权操作。

提交只添加当前项目访问，不修改 Team、其他项目或邀请。确认结果就地更新可信名册；较新名册或待复核权限不能被迟到回执覆盖。搜索词、候选、焦点和位置在有效范围内保留。未知提交在同一身份与文档会话内保留目标和防重状态，离开页面、清空搜索、撤权及恢复权限均不能解除；当前成员核对独立于邀请读取，存在、缺席或读取失败均不能证明原写入或允许重发。确认失权撤下候选及私有反馈，身份失效或切换隔离旧状态。未知直加不阻止既有授权和邀请操作。

确认本人授权变更后按可信回执处理实际权限；隐藏成员组不延迟真实失权对其他设置组的撤回。失权后仍显示合法的本人成功反馈或已确认等待说明及返回入口，但不显示旧项目标题、名册或秘密。后续 404 不证明未知写入成功，也不能使结果导航到另一个项目。

各功能的具体权限、版本、错误和恢复规则由[认证需求](daynight-auth.md)、[执行提醒](daynight-task-timing.md)、[个人提示词](worker-prompts.md)及 [Web 需求](daynight-web.md)拥有；[工作空间设计](../design/project-settings.md)说明状态与展示的组织方式。
