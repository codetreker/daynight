# Handoff Goal

Identify all unfinished tasks in the user-specified task group and apply the [handoff workflow](../development-workflow/references/handoff.md) to each one. Proposed tasks retain their status and permission unless the caller explicitly selects todo; enabling `allowAgents` alone does not make them eligible for automatic execution.
